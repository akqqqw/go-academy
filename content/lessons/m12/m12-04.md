## Приём JSON

```go
func decode[T any](r *http.Request) (T, error) {
	var value T
	decoder := json.NewDecoder(io.LimitReader(r.Body, 1<<20))
	decoder.DisallowUnknownFields()
	if err := decoder.Decode(&value); err != nil {
		return value, fmt.Errorf("json: %w", err)
	}
	return value, nil
}
```

`LimitReader` защищает от гигантских тел, `DisallowUnknownFields` ловит опечатки в
полях. Проверяйте `Content-Type` и возвращайте `415` при чужом формате.

## Отправка JSON

```go
func writeJSON(w http.ResponseWriter, status int, value any) error {
	w.Header().Set("Content-Type", "application/json; charset=utf-8")
	w.WriteHeader(status)
	return json.NewEncoder(w).Encode(value)
}
```

Заголовок нужно ставить **до** `WriteHeader`. `Encoder.Encode` добавит перевод
строки в конце — это нормально.

## Валидация

Проверяйте данные до записи в базу:

```go
type CreateNote struct {
	Title string `json:"title"`
	Body  string `json:"body"`
}

func (n CreateNote) Validate() error {
	if strings.TrimSpace(n.Title) == "" {
		return errors.New("title не может быть пустым")
	}
	return nil
}
```

Ошибка валидации — `422 Unprocessable Entity` (или `400`), с деталями полей.

## Ответы

- Создание — `201 Created` и заголовок `Location`.
- Удаление — `204 No Content` без тела.
- Ошибка — единый конверт `{"error": {...}}`.

## Частые ошибки

- **Декодировать в указатель на указатель.** Обычно достаточно `&value`.
- **Забыть закрыть `r.Body`.** Внимание: сервер закрывает его сам.
- **Возвращать `nil`-срез как `null`.** Инициализируйте `[]T{}`.
- **Писать в ответ после `WriteHeader`.** Код уже отправлен.

## Практика

**Задание.** Прочитайте JSON `{"title":"Go"}` из запроса через `httptest`, верните `201` и напечатайте заголовок из структуры.

**Стартовый код:**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

type note struct {
	Title string `json:"title"`
}

func main() {
	handler := func(w http.ResponseWriter, r *http.Request) {
		var input note
		if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
			w.WriteHeader(http.StatusBadRequest)
			return
		}
		w.WriteHeader(http.StatusCreated) // верните JSON и 201
		fmt.Println(input.Title)
	}

	request := httptest.NewRequest(http.MethodPost, "/notes", strings.NewReader(`{"title":"Go"}`))
	recorder := httptest.NewRecorder()
	handler(recorder, request)
	fmt.Println(recorder.Code)
}
```

**Ожидаемый вывод:**

```text
Go
201
```

**Подсказка.** Используйте `json.NewDecoder(r.Body).Decode(&input)` и `httptest.NewRequest` с `strings.NewReader`.

**Решение:**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

type note struct {
	Title string `json:"title"`
}

func main() {
	handler := func(w http.ResponseWriter, r *http.Request) {
		var input note
		if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
			w.WriteHeader(http.StatusBadRequest)
			return
		}
		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusCreated)
		json.NewEncoder(w).Encode(map[string]string{"title": input.Title})
		fmt.Println(input.Title)
	}

	request := httptest.NewRequest(http.MethodPost, "/notes", strings.NewReader(`{"title":"Go"}`))
	recorder := httptest.NewRecorder()
	handler(recorder, request)
	fmt.Println(recorder.Code)
}
```

## Резюме

- Декодируйте тело с лимитом и `DisallowUnknownFields`.
- Заголовки ставьте до `WriteHeader`, ошибки — в едином формате.
- Валидация входа — до записи в хранилище.

Middleware: логирование, восстановление после паники и общие заголовки.
