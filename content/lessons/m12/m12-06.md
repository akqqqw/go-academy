## Подключение

```go
import (
	"database/sql"
	_ "modernc.org/sqlite" // чистый Go-драйвер, без cgo
)

func Open(path string) (*sql.DB, error) {
	db, err := sql.Open("sqlite", path+"?_pragma=journal_mode(WAL)&_pragma=busy_timeout(5000)")
	if err != nil {
		return nil, err
	}
	db.SetMaxOpenConns(1) // SQLite плохо переносит параллельную запись
	return db, nil
}
```

`sql.Open` не подключается сразу — первая проверка происходит при `Ping()` или
первом запросе.

## Запросы

```go
// запись
_, err := db.ExecContext(ctx, `INSERT INTO notes (title, body) VALUES (?, ?)`, title, body)

// одна строка
row := db.QueryRowContext(ctx, `SELECT id, title FROM notes WHERE id = ?`, id)
err = row.Scan(&note.ID, &note.Title)

// много строк
rows, err := db.QueryContext(ctx, `SELECT id, title FROM notes ORDER BY id`)
if err != nil {
	return nil, err
}
defer rows.Close()
for rows.Next() {
	var note Note
	if err := rows.Scan(&note.ID, &note.Title); err != nil {
		return nil, err
	}
	notes = append(notes, note)
}
return notes, rows.Err()
```

Плейсхолдеры обязательны: конкатенация строк открывает SQL-инъекции.

## Транзакции

`tx, err := db.BeginTx(ctx, nil)`, затем `tx.ExecContext`, `tx.Commit()` или
`tx.Rollback()` (через `defer`).

## Миграции

Схему хранят файлами `schema.sql` или упорядоченными миграциями с таблицей
`schema_migrations`. Накатывайте по одной в транзакции и записывайте номер
версии.

## Частые ошибки

- **`SELECT *` и `Scan` по позициям.** Порядок колонок меняется — перечисляйте
  явно.
- **Забыть `rows.Close()`.** Утечка соединений.
- **Не проверять `rows.Err()`.** Ошибка итерации теряется.
- **`Exec` с интерполяцией строк.** Инъекция и поломка на кавычках.

## Практика

**Задание.** Сформулируйте SQL-запрос с параметром и выведите его: напишите функцию `queryByID(id int) (string, []any)`, возвращающую текст запроса и аргументы; напечатайте оба значения.

**Стартовый код:**

```go
package main

import "fmt"

func queryByID(id int) (string, []any) {
	return "", nil // верните запрос и аргументы
}

func main() {
	query, args := queryByID(7)
	fmt.Println(query)
	fmt.Println(args)
}
```

**Ожидаемый вывод:**

```text
SELECT id, title FROM notes WHERE id = ?
[7]
```

**Подсказка.** Верните `SELECT id, title FROM notes WHERE id = ?` и `[]any{id}`.

**Решение:**

```go
package main

import "fmt"

func queryByID(id int) (string, []any) {
	return "SELECT id, title FROM notes WHERE id = ?", []any{id}
}

func main() {
	query, args := queryByID(7)
	fmt.Println(query)
	fmt.Println(args)
}
```

## Резюме

- `database/sql` + драйвер без cgo дают переносимый доступ к SQLite.
- Параметры передаются плейсхолдерами, строки обходятся с `rows.Err()`.
- Схема обновляется миграциями, соединения ограничиваются осознанно.
