## Конфигурация как структура

```go
type Config struct {
	Host string
	Port int
	DataDir string
}

func Load() (Config, error) {
	cfg := Config{
		Host:    envOr("GOACADEMY_HOST", "127.0.0.1"),
		Port:    8080,
		DataDir: envOr("GOACADEMY_DATA_DIR", "./data"),
	}
	flag.StringVar(&cfg.Host, "host", cfg.Host, "адрес прослушивания")
	flag.IntVar(&cfg.Port, "port", cfg.Port, "порт HTTP")
	flag.Parse()

	if cfg.Port < 1 || cfg.Port > 65535 {
		return Config{}, fmt.Errorf("порт вне диапазона: %d", cfg.Port)
	}
	return cfg, nil
}

func envOr(key, fallback string) string {
	if value := os.Getenv(key); value != "" {
		return value
	}
	return fallback
}
```

Приоритет: флаг → переменная окружения → значение по умолчанию. Так конфиг
удобно менять и локально, и в контейнере.

## Валидация на старте

Ошибка конфигурации должна ронять приложение сразу и понятным сообщением.
Проверяйте диапазоны, существование каталогов, доступность порта.

## Секреты

Пароли и токены — только из окружения или файла с правами `0600`, никогда не в
коде и не в git. Логируйте конфигурацию без секретов.

## Частые ошибки

- **Читать env в случайных местах.** Конфигурация собирается один раз.
- **Паника при отсутствии переменной.** Дайте значение по умолчанию или верните
  ошибку.
- **Печатать весь конфиг в лог.** Секреты утекают.
- **Игнорировать `flag.Parse` ошибки.** В `flag` они обрабатываются сами, но
  валидация значений — на вас.

## Практика

**Задание.** Реализуйте `ConfigFrom(env map[string]string) (string, error)`, возвращающую адрес `host:port` с умолчаниями `127.0.0.1:8080`; напечатайте адрес для пустой карты.

**Стартовый код:**

```go
package main

import "fmt"

func ConfigFrom(env map[string]string) (string, error) {
	host := env["HOST"]
	if host == "" {
		host = "127.0.0.1"
	}
	port := env["PORT"]
	if port == "" {
		port = "8080"
	}
	return "", nil // верните host:port
}

func main() {
	addr, err := ConfigFrom(map[string]string{})
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(addr)
}
```

**Ожидаемый вывод:**

```text
127.0.0.1:8080
```

**Подсказка.** Берите значения из карты с проверкой на пустоту и склеивайте через `fmt.Sprintf("%s:%s", host, port)`.

**Решение:**

```go
package main

import "fmt"

func ConfigFrom(env map[string]string) (string, error) {
	host := env["HOST"]
	if host == "" {
		host = "127.0.0.1"
	}
	port := env["PORT"]
	if port == "" {
		port = "8080"
	}
	return fmt.Sprintf("%s:%s", host, port), nil
}

func main() {
	addr, err := ConfigFrom(map[string]string{})
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(addr)
}
```

## Резюме

- Конфигурация собирается один раз из флагов, env и умолчаний.
- Валидируйте значения при старте и падайте с понятной ошибкой.
- Секреты храните вне кода и не логируйте.
