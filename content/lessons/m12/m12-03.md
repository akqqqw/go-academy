## Ресурсы, а не действия

URL описывают сущности, метод — операцию:

| Метод и путь | Действие | Ответ |
| --- | --- | --- |
| `GET /api/lessons` | список | 200 + массив |
| `GET /api/lessons/m01-01` | один урок | 200 или 404 |
| `POST /api/lessons` | создать | 201 + `Location` |
| `PATCH /api/lessons/m01-01` | изменить | 200 или 422 |
| `DELETE /api/lessons/m01-01` | удалить | 204 |

Избегайте `/api/getLessons` и `/api/lessons/delete` — это RPC в обёртке REST.

## Вложенность и фильтры

`GET /api/decks/{id}/cards?limit=20&offset=0` — вложенный ресурс. Фильтры и
пагинация — в query, а не в пути. Вложенность глубже двух уровней усложняет
клиентов.

## Формат ошибки

Единый конверт для всего API:

```json
{ "error": { "code": "lesson_not_found", "message": "урок не найден" } }
```

Код машинно-читаемый, сообщение — для человека. HTTP-статус при этом
соответствующий.

## Версионирование

- `/api/v1/...` — явная версия, просто и надёжно.
- Заголовок `Accept: application/vnd.api+json;version=2` — гибко, но сложнее.
- Ломающие изменения без версии — источник боли у клиентов.

## Частые ошибки

- **Всегда 200.** Клиент не может отличить успех от ошибки.
- **Списки без пагинации.** Однажды таблица вырастет.
- **Разные форматы ошибок в разных эндпоинтах.**
- **Идентификатор в теле POST.** Пусть сервер создаёт его и возвращает.

## Практика

**Задание.** Реализуйте маршруты `GET /api/tasks/{id}` (200 и JSON) и `DELETE /api/tasks/{id}` (204), вызовите оба через `httptest` и напечатайте коды.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /api/tasks/{id}", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		// верните JSON с id
	})
	mux.HandleFunc("DELETE /api/tasks/{id}", func(w http.ResponseWriter, r *http.Request) {
		// верните 204
	})

	for _, call := range []struct{ method, path string }{
		{http.MethodGet, "/api/tasks/7"},
		{http.MethodDelete, "/api/tasks/7"},
	} {
		recorder := httptest.NewRecorder()
		mux.ServeHTTP(recorder, httptest.NewRequest(call.method, call.path, nil))
		fmt.Println(recorder.Code)
	}
}
```

**Ожидаемый вывод:**

```text
200
204
```

**Подсказка.** Зарегистрируйте два маршрута в `ServeMux`, для удаления верните `http.StatusNoContent`.

**Решение:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /api/tasks/{id}", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprintf(w, `{"id":%q,"status":"open"}`, r.PathValue("id"))
	})
	mux.HandleFunc("DELETE /api/tasks/{id}", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusNoContent)
	})

	for _, call := range []struct{ method, path string }{
		{http.MethodGet, "/api/tasks/7"},
		{http.MethodDelete, "/api/tasks/7"},
	} {
		recorder := httptest.NewRecorder()
		mux.ServeHTTP(recorder, httptest.NewRequest(call.method, call.path, nil))
		fmt.Println(recorder.Code)
	}
}
```
