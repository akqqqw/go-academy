## Сервер и мультиплексор

```go
package main

import (
	"fmt"
	"log"
	"net/http"
)

func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		fmt.Fprint(w, "ok")
	})

	mux.HandleFunc("GET /lessons/{id}", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		fmt.Fprintf(w, "урок %s", id)
	})

	log.Fatal(http.ListenAndServe(":8080", mux))
}
```

С Go 1.22 шаблоны поддерживают метод и параметры `{id}`. `r.PathValue("id")`
возвращает значение.

## Handler и HandlerFunc

Обработчик — интерфейс с методом `ServeHTTP(w, r)`. `http.HandlerFunc` превращает
функцию в обработчик. Функции удобны для маленьких маршрутов, структуры — когда
нужны зависимости:

```go
type Server struct {
	store *Store
}

func (s *Server) handleLessons(w http.ResponseWriter, r *http.Request) {}
```

## Порядок и точность

`ServeMux` выбирает самый точный шаблон. `GET /items/{id}` и `GET /items/all`
могут сосуществовать: статический путь приоритетнее. Для старых версий Go нужен
внешний роутер.

## Тестирование без порта

```go
recorder := httptest.NewRecorder()
request := httptest.NewRequest(http.MethodGet, "/health", nil)
mux.ServeHTTP(recorder, request)
```

`httptest` не открывает сокет и работает быстро.

## Частые ошибки

- **Игнорировать ошибку `ListenAndServe`.** Возвращает `http.ErrServerClosed`
  при штатном завершении.
- **`http.DefaultServeMux` и глобальные хендлеры.** Мешают тестам и создают
  неявные зависимости.
- **Отдавать `http.Handler` без таймаутов.** `http.Server` без `ReadTimeout`
  уязвим к медленным клиентам.
- **Забыть `Content-Type`.** Клиент будет угадывать формат.

## Практика

**Задание.** Создайте `ServeMux` с маршрутом `GET /hello/{name}`, вызовите его через `httptest` для `/hello/Го` и напечатайте тело ответа.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /hello/{name}", func(w http.ResponseWriter, r *http.Request) {
		// поприветствуйте r.PathValue("name")
	})

	recorder := httptest.NewRecorder()
	mux.ServeHTTP(recorder, httptest.NewRequest(http.MethodGet, "/hello/Го", nil))
	fmt.Println(recorder.Body.String())
}
```

**Ожидаемый вывод:**

```text
Привет, Го!
```

**Подсказка.** `mux.HandleFunc("GET /hello/{name}", …)`, затем `mux.ServeHTTP(recorder, request)` и `recorder.Body.String()`.

**Решение:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /hello/{name}", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "Привет, %s!", r.PathValue("name"))
	})

	recorder := httptest.NewRecorder()
	mux.ServeHTTP(recorder, httptest.NewRequest(http.MethodGet, "/hello/Го", nil))
	fmt.Println(recorder.Body.String())
}
```

## Резюме

- `http.NewServeMux` регистрирует маршруты с методом и параметрами пути.
- `http.HandlerFunc` адаптирует функцию, `httptest` тестирует без сети.
- Серверу нужны таймауты, а обработчикам — корректные заголовки.
