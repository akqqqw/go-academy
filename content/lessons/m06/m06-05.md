## Ветвление по динамическому типу

```go
package main

import "fmt"

func describe(value any) string {
	switch v := value.(type) {
	case int:
		return fmt.Sprintf("целое %d", v)
	case string:
		return fmt.Sprintf("строка %q длиной %d", v, len(v))
	case []int:
		return fmt.Sprintf("срез из %d чисел", len(v))
	case nil:
		return "nil"
	default:
		return fmt.Sprintf("другой тип %T", v)
	}
}

func main() {
	fmt.Println(describe(7))
	fmt.Println(describe("go"))
	fmt.Println(describe([]int{1, 2}))
	fmt.Println(describe(nil))
	fmt.Println(describe(3.5))
}
```

В каждой ветке `v` уже имеет нужный статический тип: в `case int` это `int`.

## Несколько типов в одной ветке

```go
case int, int64:
	// здесь v снова any: конкретный тип неизвестен
```

Если нужен доступ к значению, типы лучше разделять.

## type switch или assertion

- Один ожидаемый тип — assertion.
- Набор типов с разной обработкой — type switch.
- Интерфейсы (не конкретные типы) тоже можно указывать в `case`:
  `case fmt.Stringer:`.

## Частые ошибки

- **`switch value.(type)` вне интерфейса.** Работает только для интерфейсных
  значений.
- **Ожидание конкретного типа при `case int, int64`.** В такой ветке `v` — `any`.
- **Забытый default.** Для отладки полезно печатать `%T`.
- **Путаница с `.()`.** `switch value.(T)` — синтаксическая ошибка.

## Практика

**Задание.** Напишите функцию `kind(value any) string`, возвращающую `int`, `string`, `bool` или `другое`, и напечатайте результат для трёх значений.

**Стартовый код:**

```go
package main

import "fmt"

func kind(value any) string {
	return "" // реализуйте type switch
}

func main() {
	fmt.Println(kind(1), kind("go"), kind(true), kind(1.5))
}
```

**Ожидаемый вывод:**

```text
int string bool другое
```

**Подсказка.** Используйте `switch value.(type)` с ветками `case int:`, `case string:`, `case bool:` и `default:`.

**Решение:**

```go
package main

import "fmt"

func kind(value any) string {
	switch value.(type) {
	case int:
		return "int"
	case string:
		return "string"
	case bool:
		return "bool"
	default:
		return "другое"
	}
}

func main() {
	fmt.Println(kind(1), kind("go"), kind(true), kind(1.5))
}
```

## Резюме

- `switch v := x.(type)` выбирает ветку по динамическому типу.
- В ветке одного типа переменная получает этот тип.
- Для одного типа проще assertion, для набора — type switch.

Интерфейсы можно собирать из других интерфейсов — композиция.
