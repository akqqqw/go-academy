## Интерфейс из интерфейсов

В интерфейс можно встроить другие интерфейсы — получится объединение методов:

```go
package main

import (
	"fmt"
	"io"
	"os"
)

type ReadWriter interface {
	io.Reader
	io.Writer
}

func main() {
	var rw ReadWriter = os.Stdout // *os.File реализует оба метода
	fmt.Fprintln(rw, "пишем в стандартный вывод")
}
```

Так устроены `io.ReadWriter`, `io.ReadCloser`, `io.WriteCloser`. Никакого
наследования здесь нет — только список требований.

## Маленькие интерфейсы

Идиома Go: «чем меньше методов, тем шире применимость». `io.Writer` с одним
методом `Write` реализуют файлы, буферы, сокеты, HTTP-ответы и тестовые заглушки.
Функция, принимающая `io.Writer`, работает со всеми ними:

```go
func report(w io.Writer, text string) error {
	_, err := fmt.Fprintln(w, text)
	return err
}
```

## Проектирование

- Объявляйте интерфейс там, где он используется, а не там, где реализуется.
- Не добавляйте метод «на будущее»: это ломает все существующие реализации.
- Комбинируйте поведение встраиванием, а не копированием сигнатур.
- Для моков в тестах достаточно реализовать маленький интерфейс.

## Частые ошибки

- **Дублирование сигнатур.** Повторять методы из встроенного интерфейса не
  нужно и вредно: расхождения при рефакторинге.
- **Слишком крупный контракт.** Интерфейс из 15 методов сложно реализовать и
  подменить.
- **Интерфейс ради интерфейса.** Возвращайте конкретный тип из конструктора,
  принимайте интерфейс в аргументах.

## Практика

**Задание.** Реализуйте методы `Read` и `Write` структуры `Buffer` так, чтобы интерфейс `ReadWriter` работал: `Write` дописывает текст, `Read` возвращает накопленное.

**Стартовый код:**

```go
package main

import "fmt"

type Reader interface {
	Read() string
}

type Writer interface {
	Write(text string) error
}

type ReadWriter interface {
	Reader
	Writer
}

type Buffer struct {
	data string
}

func (b *Buffer) Read() string {
	return "" // верните накопленные данные
}

func (b *Buffer) Write(text string) error {
	// сохраните текст в буфере
	return nil
}

func main() {
	var rw ReadWriter = &Buffer{}
	if err := rw.Write("go"); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(rw.Read())
}
```

**Ожидаемый вывод:**

```text
go
```

**Подсказка.** Встройте оба интерфейса в `Counter`, затем реализуйте методы на `*Buffer`.

**Решение:**

```go
package main

import "fmt"

type Reader interface {
	Read() string
}

type Writer interface {
	Write(text string) error
}

type ReadWriter interface {
	Reader
	Writer
}

type Buffer struct {
	data string
}

func (b *Buffer) Read() string { return b.data }

func (b *Buffer) Write(text string) error {
	b.data += text
	return nil
}

func main() {
	var rw ReadWriter = &Buffer{}
	if err := rw.Write("go"); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(rw.Read())
}
```

## Резюме

- Интерфейс может встраивать другие интерфейсы, объединяя методы.
- Маленькие интерфейсы вроде `io.Writer` применимы к большому числу типов.
- Объявляйте интерфейс у потребителя и не добавляйте лишних методов.
