## Синтаксис

`v.(T)` достаёт значение типа `T` из интерфейса:

```go
package main

import "fmt"

func main() {
	var value any = "go"
	text := value.(string)
	fmt.Println(text, len(text))
}
```

Если динамический тип не совпадает с `T`, возникает паника `interface
conversion: interface {} is int, not string`.

## Безопасная форма

Двухрезультатная форма возвращает значение и признак успеха:

```go
var value any = 42
if number, ok := value.(int); ok {
	fmt.Println("число:", number)
} else {
	fmt.Println("это не int")
}
```

Эту форму используют почти всегда, когда тип не гарантирован.

## Только для интерфейсов

Assertion применим к переменной интерфейсного типа. Для конкретного типа
компилятор скажет: `invalid type assertion: value.(string) (non-interface type
int on left)`.

Частный случай — утверждение, что тип реализует другой интерфейс:

```go
type Stringer interface{ String() string }

if s, ok := value.(Stringer); ok {
	fmt.Println(s.String())
}
```

## Частые ошибки

- **Забыть ok.** Паника на неподходящем типе в проде.
- **Ожидание преобразования.** `value.(float64)` не превратит `int` в
  `float64` — это разные динамические типы.
- **Assertion на nil-интерфейсе.** Даёт панику/`ok == false`.
- **Длинные цепочки assertion.** Если вариантов много, нужен type switch.

## Практика

**Задание.** Достаньте целое число из `any` безопасной формой assertion и напечатайте его удвоенное значение; для не-числа напечатайте `не число`.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	var value any = 21
	n, ok := value.(int)
	if !ok {
		fmt.Println("не число")
		return
	}
	fmt.Println(n * 2)
}
```

**Ожидаемый вывод:**

```text
42
не число
```

**Подсказка.** `if n, ok := value.(int); ok { ... } else { ... }`.

**Решение:**

```go
package main

import "fmt"

func main() {
	values := []any{21, "текст"}
	for _, value := range values {
		n, ok := value.(int)
		if !ok {
			fmt.Println("не число")
			continue
		}
		fmt.Println(n * 2)
	}
}
```

## Резюме

- `v.(T)` извлекает значение типа T из интерфейса.
- Форма `v, ok := x.(T)` безопасна, однозначная — паникует.
- Assertion работает с интерфейсами, а не с конкретными типами.

Если типов несколько, вместо цепочки assertion используют type switch.
