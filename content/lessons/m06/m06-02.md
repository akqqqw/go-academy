## Никаких объявлений

Достаточно объявить методы — компилятор сам проверит соответствие:

```go
package main

import "fmt"

type Greeter interface {
	Greet() string
}

type Robot struct{ Model string }

func (r Robot) Greet() string { return "бип: " + r.Model }

func hello(g Greeter) string { return g.Greet() }

func main() {
	fmt.Println(hello(Robot{Model: "R2"}))
}
```

`Robot` нигде не упоминает `Greeter`, но удовлетворяет ему. Это позволяет
объявлять интерфейс **в пакете-потребителе**, а не рядом с реализацией.

## Набор методов: T и *T

Метод с получателем `*T` не входит в набор методов `T`:

```go
type Counter struct{ n int }

func (c *Counter) Greet() string { return "раз" }

var _ Greeter = &Counter{} // ok
// var _ Greeter = Counter{} // ошибка
```

Поэтому реализации с методами на указателе передают как `&T{}`.

## Проверка на этапе компиляции

Идиома — пустая переменная с присваиванием:

```go
var _ Greeter = (*Robot)(nil)
```

Если сигнатура изменится, сборка упадёт сразу, а не в месте использования.

## Частые ошибки

- **Метод с другим получателем.** `func (r *Robot) Greet()` не удовлетворит
  `Greeter` для значения `Robot`.
- **Опечатка в сигнатуре.** Другой тип аргумента или результата — и интерфейс не
  реализован; ошибка появляется при присваивании.
- **Импорт ради интерфейса.** Не нужно импортировать пакет, где объявлен
  интерфейс, чтобы реализовать его.

## Практика

**Задание.** Допишите метод `Describe()` типа `Temperature`, чтобы он реализовал интерфейс `Describer`, и напечатайте описание в виде `21.5 градуса`.

**Стартовый код:**

```go
package main

import "fmt"

type Describer interface {
	Describe() string
}

type Temperature float64

func (t Temperature) Describe() string {
	return "" // верните описание
}

func main() {
	var d Describer = Temperature(21.5)
	fmt.Println(d.Describe())
}
```

**Ожидаемый вывод:**

```text
21.5 градуса
```

**Подсказка.** Объявите `type Temperature float64` и метод `func (t Temperature) Describe() string`.

**Решение:**

```go
package main

import "fmt"

type Describer interface {
	Describe() string
}

type Temperature float64

func (t Temperature) Describe() string {
	return fmt.Sprintf("%.1f градуса", float64(t))
}

func main() {
	var d Describer = Temperature(21.5)
	fmt.Println(d.Describe())
}
```

## Резюме

- Интерфейс реализуется автоматически при совпадении методов.
- Методы `*T` не входят в набор методов `T`, поэтому используйте `&T{}`.
- `var _ I = (*T)(nil)` проверяет соответствие на этапе компиляции.

`any` — интерфейс без методов; разберём его возможности и ограничения.
