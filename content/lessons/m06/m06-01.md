## Контракт из методов

Интерфейс описывает поведение: набор методов с сигнатурами. Любой тип с такими
методами подходит:

```go
package main

import "fmt"

type Shape interface {
	Area() float64
}

type Square struct{ Side float64 }

func (s Square) Area() float64 { return s.Side * s.Side }

func main() {
	var shape Shape = Square{Side: 3}
	fmt.Println(shape.Area())
}
```

Функция может принимать интерфейс и работать с любым его реализующим типом —
это и есть полиморфизм:

```go
func describe(s Shape) string {
	return fmt.Sprintf("площадь %.2f", s.Area())
}
```

## Интерфейс — это значение

В переменной интерфейса лежит пара: динамический тип и значение. `nil`-интерфейс
не содержит ничего, и вызов метода у него паникует:

```go
var s Shape
fmt.Println(s == nil) // true
// s.Area()            // panic
```

Уже упомянутые `error`, `fmt.Stringer`, `io.Writer` — тоже интерфейсы.

## Имена и размер

По соглашению интерфейсы называют по методу: `Reader`, `Writer`, `Stringer`.
Чем меньше методов, тем проще их реализовать и комбинировать. В стандартной
библиотеке полно интерфейсов из одного метода.

## Частые ошибки

- **Интерфейс на пустом месте.** Если тип используется в одном месте, интерфейс
  добавляет косвенность без пользы.
- **Разыменование nil-интерфейса.** Проверяйте `if s == nil`.
- **Ожидание полей.** Интерфейс описывает только методы, поля в него не входят.
- **Слишком широкий интерфейс.** 10 методов обязывают реализовать все десять.

## Практика

**Задание.** Допишите метод `Name()` структуры `User`, чтобы она реализовала интерфейс `Namer`, и напечатайте имя через переменную интерфейса.

**Стартовый код:**

```go
package main

import "fmt"

type Namer interface {
	Name() string
}

type User struct {
	First string
}

func (u User) Name() string {
	return "" // верните имя
}

func main() {
	var n Namer = User{First: "Анна"}
	fmt.Println(n.Name())
}
```

**Ожидаемый вывод:**

```text
Анна
```

**Подсказка.** Метод должен быть с получателем `User`: `func (u User) Name() string { return u.First }`.

**Решение:**

```go
package main

import "fmt"

type Namer interface {
	Name() string
}

type User struct {
	First string
}

func (u User) Name() string { return u.First }

func main() {
	var n Namer = User{First: "Анна"}
	fmt.Println(n.Name())
}
```

## Резюме

- Интерфейс — набор сигнатур методов, описывающий поведение.
- Переменная интерфейса хранит динамический тип и значение.
- Маленькие интерфейсы проще реализовать и комбинировать.

Главная особенность Go: реализация интерфейса не объявляется.
