## Схема

```sql
CREATE TABLE IF NOT EXISTS notes (
	id         INTEGER PRIMARY KEY AUTOINCREMENT,
	title      TEXT NOT NULL,
	body       TEXT NOT NULL DEFAULT '',
	created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_notes_created ON notes(created_at);
```

`AUTOINCREMENT` не обязателен, но гарантирует, что id не переиспользуются.
Время хранят в RFC3339 (`TEXT`) — сортировка лексикографически совпадает с
хронологической.

## Репозиторий

```go
type Note struct {
	ID        int64
	Title     string
	Body      string
	CreatedAt time.Time
}

type NoteRepo struct {
	db *sql.DB
}

func (r *NoteRepo) Create(ctx context.Context, note Note) (int64, error) {
	result, err := r.db.ExecContext(ctx,
		`INSERT INTO notes (title, body, created_at) VALUES (?, ?, ?)`,
		note.Title, note.Body, note.CreatedAt.UTC().Format(time.RFC3339))
	if err != nil {
		return 0, fmt.Errorf("вставить заметку: %w", err)
	}
	return result.LastInsertId()
}
```

Интерфейс объявляют у потребителя (HTTP-слой), а `NoteRepo` — реализация.

## Частые ошибки

- **`SELECT *` и `Scan` по позициям.** Перечисляйте колонки.
- **Время в локальной зоне без указания.** Храните UTC и RFC3339.
- **Отсутствие индексов на фильтрах.** Медленные списки.
- **Тесты на «настоящей» базе разработчика.** Только `t.TempDir()`.

## Практика

**Задание.** Реализуйте `rowToNote(id int64, title, created string) (Note, error)`, разбирающую время из RFC3339, и напечатайте заголовок и год.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"time"
)

type Note struct {
	ID        int64
	Title     string
	CreatedAt time.Time
}

func rowToNote(id int64, title, created string) (Note, error) {
	return Note{}, nil // разберите время
}

func main() {
	note, err := rowToNote(1, "Заметка", "2026-10-27T10:00:00Z")
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(note.Title, note.CreatedAt.Year())
}
```

**Ожидаемый вывод:**

```text
Заметка 2026
```

**Подсказка.** Используйте `time.Parse(time.RFC3339, created)` и верните структуру `Note`.

**Решение:**

```go
package main

import (
	"fmt"
	"time"
)

type Note struct {
	ID        int64
	Title     string
	CreatedAt time.Time
}

func rowToNote(id int64, title, created string) (Note, error) {
	createdAt, err := time.Parse(time.RFC3339, created)
	if err != nil {
		return Note{}, fmt.Errorf("разбор времени: %w", err)
	}
	return Note{ID: id, Title: title, CreatedAt: createdAt}, nil
}

func main() {
	note, err := rowToNote(1, "Заметка", "2026-10-27T10:00:00Z")
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(note.Title, note.CreatedAt.Year())
}
```
