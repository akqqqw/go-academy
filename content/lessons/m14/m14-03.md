## Деньги нельзя в float64

`0.1 + 0.2 != 0.3` — накопление ошибок округления в банке недопустимо. Суммы
хранят в минимальных единицах (копейках) как `int64`:

```go
type Account struct {
	ID      string
	Balance int64 // копейки
}

func (a *Account) Deposit(kopecks int64) error {
	if kopecks <= 0 {
		return errors.New("сумма должна быть положительной")
	}
	a.Balance += kopecks
	return nil
}

func (a *Account) Withdraw(kopecks int64) error {
	if kopecks <= 0 {
		return errors.New("сумма должна быть положительной")
	}
	if a.Balance < kopecks {
		return ErrInsufficientFunds
	}
	a.Balance -= kopecks
	return nil
}
```

## Перевод

```go
func Transfer(from, to *Account, kopecks int64) error {
	if err := from.Withdraw(kopecks); err != nil {
		return fmt.Errorf("списание: %w", err)
	}
	if err := to.Deposit(kopecks); err != nil {
		return fmt.Errorf("зачисление: %w", err)
	}
	return nil
}
```

Для настоящей БД перевод выполняют в транзакции. В памяти достаточно порядка
операций и проверок.

## Форматирование

```go
func Format(kopecks int64) string {
	sign := ""
	if kopecks < 0 {
		sign = "-"
		kopecks = -kopecks
	}
	return fmt.Sprintf("%s%d.%02d ₽", sign, kopecks/100, kopecks%100)
}
```

## Журнал операций

Каждую операцию записывают в срез `Entry{Time, From, To, Amount}`. Журнал —
источник истории и отладки. Время лучше передавать параметром (`time.Time`),
чтобы тесты были детерминированными.

## Частые ошибки

- **`float64` для баланса.** Копейки теряются.
- **Списание без проверки.** Отрицательный баланс и «потерянные» деньги.
- **Перевод без атомарности.** В памяти — порядок и проверки, в БД — транзакция.
- **Форматирование через деление float.** Округление съедает копейки.

## Практика

**Задание.** Реализуйте перевод 2500 копеек со счёта A на B и напечатайте баланс B в формате `B: 30.00`.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
)

type Account struct {
	ID      string
	Balance int64
}

var ErrInsufficientFunds = errors.New("недостаточно средств")

func (a *Account) Withdraw(kopecks int64) error {
	if a.Balance < kopecks {
		return ErrInsufficientFunds
	}
	a.Balance -= kopecks
	return nil
}

func (a *Account) Deposit(kopecks int64) error {
	a.Balance += kopecks
	return nil
}

func main() {
	a := &Account{ID: "A", Balance: 5000}
	b := &Account{ID: "B", Balance: 500}
	_ = a // переведите 2500 копеек с a на b
	fmt.Printf("%s: %d.%02d\n", b.ID, b.Balance/100, b.Balance%100)
}
```

**Ожидаемый вывод:**

```text
B: 30.00
```

**Подсказка.** Спишите через `Withdraw`, зачислите через `Deposit` и напечатайте `fmt.Printf("%s: %d.%02d\n", …)`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

type Account struct {
	ID      string
	Balance int64
}

var ErrInsufficientFunds = errors.New("недостаточно средств")

func (a *Account) Withdraw(kopecks int64) error {
	if a.Balance < kopecks {
		return ErrInsufficientFunds
	}
	a.Balance -= kopecks
	return nil
}

func (a *Account) Deposit(kopecks int64) error {
	a.Balance += kopecks
	return nil
}

func main() {
	a := &Account{ID: "A", Balance: 5000}
	b := &Account{ID: "B", Balance: 500}
	if err := a.Withdraw(2500); err != nil {
		fmt.Println(err)
		return
	}
	if err := b.Deposit(2500); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Printf("%s: %d.%02d\n", b.ID, b.Balance/100, b.Balance%100)
}
```

## Резюме

- Деньги хранят в минимальных единицах (`int64`), не в `float64`.
- Списание проверяет баланс и возвращает ошибку при нехватке средств.
- Журнал операций даёт историю, а время передаётся параметром для тестов.
