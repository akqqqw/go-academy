## Модель

```go
type Task struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
	Done  bool   `json:"done"`
}

type Store struct {
	path  string
	tasks []Task
	next  int
}
```

`next` хранит следующий id — так id не повторяются после удаления.

## Операции

```go
func (s *Store) Add(title string) (Task, error) {
	if strings.TrimSpace(title) == "" {
		return Task{}, errors.New("пустой заголовок")
	}
	task := Task{ID: s.next, Title: title}
	s.next++
	s.tasks = append(s.tasks, task)
	return task, s.save()
}

func (s *Store) Toggle(id int) error {
	for i := range s.tasks {
		if s.tasks[i].ID == id {
			s.tasks[i].Done = !s.tasks[i].Done
			return s.save()
		}
	}
	return fmt.Errorf("задача %d не найдена", id)
}

func (s *Store) Filter(done bool) []Task {
	out := make([]Task, 0, len(s.tasks))
	for _, task := range s.tasks {
		if task.Done == done {
			out = append(out, task)
		}
	}
	return out
}
```

## Сохранение

```go
func (s *Store) save() error {
	data, err := json.MarshalIndent(s.tasks, "", "  ")
	if err != nil {
		return err
	}
	return os.WriteFile(s.path, data, 0o600)
}
```

Атомарная запись (временный файл + `os.Rename`) защищает от потери данных при
сбое. Загружать нужно с проверкой ошибки и пустого файла.

## CLI

Меню из `bufio.Scanner`: `add`, `list`, `done <id>`, `filter`, `exit`. Каждая
команда — отдельная функция, `main` только читает ввод и вызывает их.

## Тесты

`Store` с путём в `t.TempDir()` тестируется без моков: добавьте задачи,
перезагрузите из файла, проверьте, что данные на месте.

## Частые ошибки

- **Игнорировать ошибку сохранения.** Пользователь думает, что данные записаны.
- **Дублировать id после перезапуска.** Вычисляйте `next` при загрузке.
- **Хранить `done` как строку.** Используйте `bool` и JSON-теги.
- **Менять срез во время `range`.** Удаление требует отдельного прохода или
  `slices.Delete`.

## Практика

**Задание.** Реализуйте `Store.Toggle(id int) bool`: переключает `Done` у задачи с id и возвращает `true`, если задача найдена; напечатайте состояние после переключения.

**Стартовый код:**

```go
package main

import "fmt"

type Task struct {
	ID   int
	Done bool
}

type Store struct {
	tasks []Task
}

func (s *Store) Toggle(id int) bool {
	return false // найдите задачу и переключите Done
}

func main() {
	store := &Store{tasks: []Task{{ID: 1}, {ID: 2}}}
	ok := store.Toggle(2)
	fmt.Println(ok, store.tasks[1].Done)
}
```

**Ожидаемый вывод:**

```text
true true
```

**Подсказка.** Пройдите по индексам среза и инвертируйте `Done` при совпадении id.

**Решение:**

```go
package main

import "fmt"

type Task struct {
	ID   int
	Done bool
}

type Store struct {
	tasks []Task
}

func (s *Store) Toggle(id int) bool {
	for i := range s.tasks {
		if s.tasks[i].ID == id {
			s.tasks[i].Done = !s.tasks[i].Done
			return true
		}
	}
	return false
}

func main() {
	store := &Store{tasks: []Task{{ID: 1}, {ID: 2}}}
	ok := store.Toggle(2)
	fmt.Println(ok, store.tasks[1].Done)
}
```
