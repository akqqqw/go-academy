## Входные данные

```json
{
  "users": [
    {"name": "Анна", "age": 30, "tags": ["go"]},
    {"name": "Борис", "age": 17}
  ]
}
```

## Структуры

```go
type User struct {
	Name string   `json:"name"`
	Age  int      `json:"age"`
	Tags []string `json:"tags"`
}

type Payload struct {
	Users []User `json:"users"`
}
```

Отсутствующий `tags` останется `nil`, а `age` — нулём. Если нужно отличить «не
передали» от «передали 0», используют `*int`.

## Разбор и валидация

```go
func parse(data []byte) (Payload, error) {
	var payload Payload
	if err := json.Unmarshal(data, &payload); err != nil {
		return Payload{}, fmt.Errorf("json: %w", err)
	}
	if len(payload.Users) == 0 {
		return Payload{}, errors.New("пустой список users")
	}
	for _, user := range payload.Users {
		if strings.TrimSpace(user.Name) == "" {
			return Payload{}, errors.New("имя не может быть пустым")
		}
		if user.Age < 0 || user.Age > 150 {
			return Payload{}, fmt.Errorf("возраст %q вне диапазона", user.Name)
		}
	}
	return payload, nil
}
```

## Сводка

Средний возраст, число взрослых, топ тегов — обычные циклы и map. Строгий режим:
`decoder.DisallowUnknownFields()`, чтобы опечатки в полях ловились сразу.

## Потоковая обработка

Для файла в гигабайт — `json.Decoder` с чтением по одному объекту из
последовательности (`Decode` в цикле), а не `Unmarshal` целиком.

## Частые ошибки

- **Игнорировать ошибку `Unmarshal`.** Получите частично заполненную структуру.
- **Не проверять бизнес-правила.** JSON-схема не гарантирует смысл.
- **Делать все поля обязательными.** Продумайте, что реально обязательно.
- **Хранить числа в `any`.** Приводите к типам явно.

## Практика

**Задание.** Разберите JSON с двумя пользователями, посчитайте их количество и напечатайте имена через запятую.

**Стартовый код:**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	Name string `json:"name"`
}

type Payload struct {
	Users []User `json:"users"`
}

func main() {
	data := []byte(`{"users":[{"name":"Анна"},{"name":"Борис"}]}`)
	var payload Payload
	if err := json.Unmarshal(data, &payload); err != nil {
		fmt.Println(err)
		return
	}
	// соберите имена через запятую
	fmt.Println(len(payload.Users))
}
```

**Ожидаемый вывод:**

```text
Анна, Борис
```

**Подсказка.** Опишите структуру `Payload` с `Users []User` и обойдите её после `json.Unmarshal`.

**Решение:**

```go
package main

import (
	"encoding/json"
	"fmt"
	"strings"
)

type User struct {
	Name string `json:"name"`
}

type Payload struct {
	Users []User `json:"users"`
}

func main() {
	data := []byte(`{"users":[{"name":"Анна"},{"name":"Борис"}]}`)
	var payload Payload
	if err := json.Unmarshal(data, &payload); err != nil {
		fmt.Println(err)
		return
	}
	names := make([]string, 0, len(payload.Users))
	for _, user := range payload.Users {
		names = append(names, user.Name)
	}
	fmt.Println(strings.Join(names, ", "))
}
```

## Резюме

- Структуры под JSON описывают тегами, отсутствующие поля дают нулевые значения.
- После разбора данные проверяют бизнес-правилами.
- Большие файлы читают `json.Decoder` потоково.
