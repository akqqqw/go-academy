## Каркас

```go
type Server struct {
	log   *log.Logger
	start time.Time
}

func NewServer(logger *log.Logger) *Server {
	return &Server{log: logger, start: time.Now()}
}

func (s *Server) Routes() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", s.handleHealth)
	mux.HandleFunc("GET /api/info", s.handleInfo)
	return logging(mux)
}

func (s *Server) handleHealth(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(map[string]string{"status": "ok"})
}
```

## Запуск с таймаутами

```go
server := &http.Server{
	Addr:              ":8080",
	Handler:           app.Routes(),
	ReadHeaderTimeout: 5 * time.Second,
	ReadTimeout:       15 * time.Second,
	WriteTimeout:      30 * time.Second,
	IdleTimeout:       60 * time.Second,
}

go func() {
	if err := server.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
		log.Fatal(err)
	}
}()
```

## Корректное завершение

По сигналу `SIGINT` перестаём принимать новые запросы и ждём текущие:

```go
stop := make(chan os.Signal, 1)
signal.Notify(stop, os.Interrupt, syscall.SIGTERM)
<-stop

ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()
if err := server.Shutdown(ctx); err != nil {
	log.Println("shutdown:", err)
}
```

## Что важно в проде

- Логи в структурированном виде (`log/slog`) с идентификатором запроса.
- Health-эндпоинт для оркестратора.
- Ограничение размера тела и таймауты.
- Никаких `log.Fatal` внутри обработчиков.

## Частые ошибки

- **Без `Shutdown`.** В обработке обрываются запросы.
- **`http.ListenAndServe` в горутине без обработки ошибки.** Падение остаётся
  незамеченным.
- **Глобальные переменные для настроек.** Передавайте зависимости в `NewServer`.
- **Отсутствие таймаутов.** Медленные клиенты занимают соединения.

## Практика

**Задание.** Соберите `ServeMux` с `/health` и `/api/info`, вызовите оба маршрута через `httptest` и напечатайте их коды.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func routes() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "ok")
	})
	// добавьте маршрут /api/info
	return mux
}

func main() {
	for _, path := range []string{"/health", "/api/info"} {
		recorder := httptest.NewRecorder()
		routes().ServeHTTP(recorder, httptest.NewRequest(http.MethodGet, path, nil))
		fmt.Println(recorder.Code)
	}
}
```

**Ожидаемый вывод:**

```text
200
200
```

**Подсказка.** Зарегистрируйте два обработчика и выполните `mux.ServeHTTP` с `httptest.NewRequest`.

**Решение:**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func routes() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "ok")
	})
	mux.HandleFunc("GET /api/info", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, `{"name":"go-academy"}`)
	})
	return mux
}

func main() {
	for _, path := range []string{"/health", "/api/info"} {
		recorder := httptest.NewRecorder()
		routes().ServeHTTP(recorder, httptest.NewRequest(http.MethodGet, path, nil))
		fmt.Println(recorder.Code)
	}
}
```

- Health-эндпоинт и структурированные логи упрощают эксплуатацию.
