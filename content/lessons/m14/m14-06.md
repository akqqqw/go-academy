## Хранилище в памяти

```go
type Book struct {
	ID     int    `json:"id"`
	Title  string `json:"title"`
	Author string `json:"author"`
}

type Library struct {
	mu    sync.Mutex
	books map[int]Book
	next  int
}

func NewLibrary() *Library {
	return &Library{books: make(map[int]Book), next: 1}
}

func (l *Library) Create(book Book) Book {
	l.mu.Lock()
	defer l.mu.Unlock()
	book.ID = l.next
	l.next++
	l.books[book.ID] = book
	return book
}
```

Мьютекс обязателен: HTTP-сервер обрабатывает запросы параллельно.

## Маршруты

```go
mux.HandleFunc("GET /api/books", api.list)
mux.HandleFunc("POST /api/books", api.create)
mux.HandleFunc("GET /api/books/{id}", api.get)
mux.HandleFunc("DELETE /api/books/{id}", api.delete)
```

`id` разбирается через `strconv.Atoi(r.PathValue("id"))`; ошибка разбора — `400`,
отсутствие записи — `404`.

## Ответы

- `GET` — `200` и массив (инициализированный, чтобы не было `null`).
- `POST` — `201`, `Location: /api/books/{id}` и созданный объект.
- `DELETE` — `204`.
- Ошибки — единый конверт с `code` и `message`.

## Тест

```go
func TestCreateAndGet(t *testing.T) {
	api := NewHandler(NewLibrary())
	body := strings.NewReader(`{"title":"Go","author":"Анна"}`)
	req := httptest.NewRequest(http.MethodPost, "/api/books", body)
	rec := httptest.NewRecorder()
	api.ServeHTTP(rec, req)
	if rec.Code != http.StatusCreated {
		t.Fatalf("код = %d", rec.Code)
	}

	var created Book
	if err := json.Unmarshal(rec.Body.Bytes(), &created); err != nil {
		t.Fatal(err)
	}

	rec = httptest.NewRecorder()
	api.ServeHTTP(rec, httptest.NewRequest(http.MethodGet, fmt.Sprintf("/api/books/%d", created.ID), nil))
	if rec.Code != http.StatusOK {
		t.Fatalf("код = %d", rec.Code)
	}
}
```

## Частые ошибки

- **Гонка данных.** Забытый мьютекс ломает map при параллельных запросах.
- **`null` вместо массива.** Инициализируйте срез.
- **Нет валидации.** Пустой заголовок доходит до хранилища.
- **Тесты через реальный порт.** `httptest` быстрее и надёжнее.

## Практика

**Задание.** Реализуйте `Library.Create` и `Library.Get`, создайте книгу и напечатайте её id и заголовок.

type Book struct {

	Title string
}

type Library struct {

**Ожидаемый вывод:**

```text
1 Язык Go true
```

**Подсказка.** Присвойте id из `next`, сохраните в map и верните значение.

**Решение:**

```go
package main

import "fmt"

type Book struct {
	ID    int
	Title string
}

type Library struct {
	books map[int]Book
	next  int
}

func (l *Library) Create(title string) Book {
	book := Book{ID: l.next, Title: title}
	l.next++
	l.books[book.ID] = book
	return book
}

func (l *Library) Get(id int) (Book, bool) {
	book, ok := l.books[id]
	return book, ok
}

func main() {
	library := &Library{books: make(map[int]Book), next: 1}
	book := library.Create("Язык Go")
	found, ok := library.Get(book.ID)
	fmt.Println(found.ID, found.Title, ok)
}
```

## Резюме

- CRUD-API строится из хранилища, маршрутов и единого формата ошибок.
- Общее хранилище защищают мьютексом: обработчики работают параллельно.
- `httptest` позволяет тестировать API без запуска порта.
