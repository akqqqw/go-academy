## Идея

`POST /api/links` с длинным URL возвращает короткий код, `GET /{code}`
перенаправляет по исходному адресу.

```go
type Shortener struct {
	mu    sync.RWMutex
	links map[string]string
	seq   int
}

func (s *Shortener) Shorten(url string) (string, error) {
	parsed, err := urlpkg.ParseRequestURI(url)
	if err != nil || parsed.Scheme == "" {
		return "", errors.New("некорректный URL")
	}

	s.mu.Lock()
	defer s.mu.Unlock()
	s.seq++
	code := encode(s.seq)
	s.links[code] = url
	return code, nil
}

func (s *Shortener) Resolve(code string) (string, bool) {
	s.mu.RLock()
	defer s.mu.RUnlock()
	url, ok := s.links[code]
	return url, ok
}
```

## Код из числа

Простой base36-код без коллизий:

```go
const alphabet = "0123456789abcdefghijklmnopqrstuvwxyz"

func encode(n int) string {
	if n == 0 {
		return "0"
	}
	out := ""
	for n > 0 {
		out = string(alphabet[n%len(alphabet)]) + out
		n /= len(alphabet)
	}
	return out
}
```

Счётчик гарантирует уникальность; случайные коды требуют проверки коллизий.

## Редирект

```go
func (s *Server) handleRedirect(w http.ResponseWriter, r *http.Request) {
	code := r.PathValue("code")
	target, ok := s.shortener.Resolve(code)
	if !ok {
		http.NotFound(w, r)
		return
	}
	http.Redirect(w, r, target, http.StatusFound)
}
```

`302 Found` — временный редирект; `301` кешируется браузером и мешает менять
назначение.

## Валидация

- Разрешайте только `http`/`https`.
- Ограничивайте длину URL.
- Не превращайте сервис в открытый редирект на любые схемы (`javascript:`).

## Частые ошибки

- **Гонка на map.** Записи из разных запросов без мьютекса ломают map.
- **Случайный код без проверки коллизий.** Две ссылки получают один код.
- **`301` для тестирования.** Браузер закеширует редирект.
- **Игнорирование схемы URL.** Открытый редирект и XSS.

## Практика

**Задание.** Сгенерируйте короткий код для `https://go.dev` (один символ для номера 10) и напечатайте его вместе с исходным адресом через двоеточие.

**Стартовый код:**

```go
package main

import "fmt"

const alphabet = "0123456789abcdefghijklmnopqrstuvwxyz"

func encode(n int) string {
	out := ""
	for n > 0 {
		out = string(alphabet[n%len(alphabet)]) + out
		n /= len(alphabet)
	}
	return out
}

func main() {
	links := make(map[string]string)
	code := encode(10)
	_ = links // сохраните адрес и напечатайте пару
	fmt.Println(code)
}
```

**Ожидаемый вывод:**

```text
a:https://go.dev
```

**Подсказка.** `encode(10)` по алфавиту base36 даёт `a`; сохраните пару в map и напечатайте.

**Решение:**

```go
package main

import "fmt"

const alphabet = "0123456789abcdefghijklmnopqrstuvwxyz"

func encode(n int) string {
	out := ""
	for n > 0 {
		out = string(alphabet[n%len(alphabet)]) + out
		n /= len(alphabet)
	}
	return out
}

func main() {
	links := make(map[string]string)
	code := encode(10)
	links[code] = "https://go.dev"
	fmt.Printf("%s:%s\n", code, links[code])
}
```

## Резюме

- Короткий код генерируют из счётчика или случайных байт с проверкой коллизий.
- Map под мьютексом защищает от гонок при параллельных запросах.
- Редирект — 302, схемы URL валидируются.
