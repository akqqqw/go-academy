## Задача

Калькулятор принимает операцию и два числа:

```bash
calc add 2 3      # 5
calc div 10 0     # ошибка
```

## Структура

```go
package main

import (
	"errors"
	"fmt"
	"os"
	"strconv"
)

func calculate(op string, a, b float64) (float64, error) {
	switch op {
	case "add":
		return a + b, nil
	case "sub":
		return a - b, nil
	case "mul":
		return a * b, nil
	case "div":
		if b == 0 {
			return 0, errors.New("деление на ноль")
		}
		return a / b, nil
	default:
		return 0, fmt.Errorf("неизвестная операция %q", op)
	}
}

func run(args []string) (float64, error) {
	if len(args) != 3 {
		return 0, errors.New("нужно: <операция> <a> <b>")
	}
	a, err := strconv.ParseFloat(args[1], 64)
	if err != nil {
		return 0, fmt.Errorf("a: %w", err)
	}
	b, err := strconv.ParseFloat(args[2], 64)
	if err != nil {
		return 0, fmt.Errorf("b: %w", err)
	}
	return calculate(args[0], a, b)
}

func main() {
	result, err := run(os.Args[1:])
	if err != nil {
		fmt.Fprintln(os.Stderr, "ошибка:", err)
		os.Exit(1)
	}
	fmt.Println(result)
}
```

## Почему так

- `calculate` — чистая функция, её легко покрыть тестами.
- `run` отвечает за разбор аргументов и не печатает.
- `main` — тонкая обёртка: вывод и код выхода.

Ошибки идут в `stderr`, результат — в `stdout`. Ненулевой код выхода позволяет
использовать утилиту в скриптах.

## Развитие

- Чтение выражения целиком (`2 + 2`) требует токенизатора — это уже парсер.
- Флаги (`-precision 2`) удобно добавлять через `flag`.
- Для интерактивного режима — `bufio.Scanner` по `os.Stdin`.

## Частые ошибки

- **Паника при неверном числе аргументов.** Проверяйте `len(args)`.
- **Печать ошибки в stdout.** Сломает конвейеры.
- **`os.Exit` внутри функции.** Код выхода только в `main`.
- **Игнорирование ошибки `ParseFloat`.** Получите молчаливый ноль.

## Практика

**Задание.** Реализуйте `run(args []string) (float64, error)` для `mul 6 7` и напечатайте результат; неизвестную операцию обработайте ошибкой.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"strconv"
)

func run(args []string) (float64, error) {
	a, err := strconv.ParseFloat(args[1], 64)
	if err != nil {
		return 0, err
	}
	b, err := strconv.ParseFloat(args[2], 64)
	if err != nil {
		return 0, err
	}
	_ = a
	_ = b
	return 0, nil // реализуйте операцию mul
}

func main() {
	result, err := run([]string{"mul", "6", "7"})
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(result)
}
```

**Ожидаемый вывод:**

```text
42
```

**Подсказка.** Проверьте длину `args`, преобразуйте числа и верните `a * b` для `mul`.

**Решение:**

```go
package main

import (
	"fmt"
	"strconv"
)

func run(args []string) (float64, error) {
	a, err := strconv.ParseFloat(args[1], 64)
	if err != nil {
		return 0, err
	}
	b, err := strconv.ParseFloat(args[2], 64)
	if err != nil {
		return 0, err
	}
	return a * b, nil
}

func main() {
	result, err := run([]string{"mul", "6", "7"})
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(result)
}
```

## Резюме

- CLI разделяют на разбор аргументов, вычисление и вывод.
- Ошибки печатаются в stderr, код выхода — в main.
- Чистые функции без ввода-вывода легко тестировать.
