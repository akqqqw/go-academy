## Массив хранит длину в типе

Массив — набор элементов одного типа фиксированной длины. Длина задаётся при
объявлении и входит в тип: `[3]int` и `[4]int` — разные типы.

```go
package main

import "fmt"

func main() {
	var zeros [3]int
	squares := [4]int{1, 4, 9, 16}
	smart := [...]string{"a", "b", "c"}

	fmt.Println(zeros, squares, smart, len(smart))
}
```

`[...]T{...}` просит компилятор посчитать длину самому. Неуказанные элементы
получают нулевое значение своего типа: `0`, `""`, `false`, `nil`.

## Массив копируется

Присваивание и передача в функцию копируют массив целиком — это значение, а не
ссылка:

```go
a := [3]int{1, 2, 3}
b := a
b[0] = 100
fmt.Println(a[0], b[0]) // 1 100
```

Для больших массивов такая копия дорогая, поэтому на практике почти всегда
используют срезы.

## Сравнение

Массивы сравнимы, если сравнимы их элементы: `a == b` сравнивает все элементы и
длину. Для срезов такой оператор не работает — это одна из причин, почему массивы
встречаются реже.

```go
fmt.Println([2]int{1, 2} == [2]int{1, 2}) // true
```

## Частые ошибки

- **Выход за границы.** `a[3]` для `[3]int` — ошибка компиляции при константном
  индексе и `panic` при переменном.
- **Ожидание изменения после передачи.** Функция получает копию массива; чтобы
  изменить исходный, передайте `*[3]int` или используйте срез `a[:]`.
- **Путаница с инициализацией.** `[3]int{1, 2}` даёт `[1 2 0]`, а не ошибку.
- **`make` для массива.** `make` работает только со срезами, map и каналами.

## Практика

**Задание.** Создайте массив из пяти чисел, замените третий элемент на `42` и напечатайте сумму элементов.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	numbers := [5]int{1, 2, 3, 4, 5}
	numbers[2] = 42
	total := 0
	// сложите элементы
	fmt.Println(total)
}
```

**Ожидаемый вывод:**

```text
54
```

**Подсказка.** Обойдите массив через `range` и складывайте элементы в переменную.

**Решение:**

```go
package main

import "fmt"

func main() {
	numbers := [5]int{1, 2, 3, 4, 5}
	numbers[2] = 42
	total := 0
	for _, n := range numbers {
		total += n
	}
	fmt.Println(total)
}
```

## Резюме

- Длина массива — часть типа, менять её нельзя.
- Массивы копируются при присваивании и передаче, их можно сравнивать через `==`.
- Для «растущих» коллекций используют срезы, а не массивы.

Срезы — рабочий инструмент Go: разберём, чем они отличаются от массивов.
