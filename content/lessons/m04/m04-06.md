## Индекс и значение

`range` возвращает индекс и значение. Если нужен только индекс, второй результат
опускают; если только значение — ставят `_`:

```go
package main

import "fmt"

func main() {
	words := []string{"go", "is", "fun"}
	for i, w := range words {
		fmt.Println(i, w)
	}
	for _, w := range words {
		fmt.Println(w)
	}
}
```

## Значение — копия

`range` копирует элемент в переменную цикла. Изменение `v` не меняет срез;
менять нужно `words[i]`. Для больших структур это важно: обходите через индекс
или используйте указатели.

```go
numbers := []int{1, 2, 3}
for _, n := range numbers {
	n *= 10 // меняется только копия
}
fmt.Println(numbers) // [1 2 3]
```

## Map и строки

Для map `range` даёт ключ и значение, порядок обхода **не определён** — при
каждом запуске он может быть другим. Для строки `range` идёт по рунам:

```go
for key, value := range map[string]int{"a": 1, "b": 2} {
	fmt.Println(key, value)
}

for i, r := range "привет" {
	fmt.Println(i, string(r))
}
```

Индекс в строке — байтовый, а `r` — `rune` (модуль 4, последний урок).

## Частые ошибки

- **Ожидание порядка map.** Для стабильного вывода соберите ключи и
  отсортируйте.
- **Изменение map во время range.** Добавление и удаление допустимо, но новые
  элементы могут не попасть в текущий обход.
- **Изменение значения через `v`.** Правьте по индексу или сделайте срез
  указателей.
- **`for i := range 3`** — это Go 1.22+: диапазон по целому числу, не срез.

## Практика

**Задание.** Обойдите map с оценками, посчитайте сумму и среднее, затем напечатайте среднее с одним знаком после запятой.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	grades := map[string]int{"Анна": 5, "Борис": 4, "Вера": 5}
	sum := 0
	// посчитайте сумму
	fmt.Printf("среднее: %.1f\n", float64(sum)/float64(len(grades)))
}
```

**Ожидаемый вывод:**

```text
среднее: 4.7
```

**Подсказка.** Складывайте значения в `sum`, делите на `float64(len(grades))` и печатайте через `%.1f`.

**Решение:**

```go
package main

import "fmt"

func main() {
	grades := map[string]int{"Анна": 5, "Борис": 4, "Вера": 5}
	sum := 0
	for _, grade := range grades {
		sum += grade
	}
	fmt.Printf("среднее: %.1f\n", float64(sum)/float64(len(grades)))
}
```

## Резюме

- `range` даёт индекс и копию значения; `_` отбрасывает ненужное.
- Порядок обхода map не определён, для строки `range` идёт по рунам.
- Чтобы изменить элементы, используйте индекс или указатели.

Map — хеш-таблица Go: создание, проверка ключа и удаление.
