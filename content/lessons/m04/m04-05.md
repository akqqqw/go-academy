## Копирование элементов

`copy(dst, src)` копирует `min(len(dst), len(src))` элементов и возвращает их
число. Ёмкости не важны — длина `dst` задаёт максимум:

```go
package main

import "fmt"

func main() {
	src := []int{1, 2, 3, 4}
	dst := make([]int, 2)
	n := copy(dst, src)
	fmt.Println(n, dst)
}
```

Здесь `n == 2`, а `dst` равен `[1 2]`. Если нужен полный клон, создайте
`dst := make([]int, len(src))`.

## Копия вместо окна

Срезы из `append`/подсреза делят массив. Настоящую копию даёт именно `copy`:

```go
origin := []string{"a", "b", "c"}
clone := make([]string, len(origin))
copy(clone, origin)
clone[0] = "z"
fmt.Println(origin[0], clone[0]) // a z
```

## Отрезать от большого массива

Классическая ловушка: маленький подсрез удерживает весь большой массив в памяти.
Копия решает проблему:

```go
func tail(s []byte, n int) []byte {
	out := make([]byte, len(s)-n)
	copy(out, s[n:])
	return out
}
```

Начиная с Go 1.21 для этого есть `slices.Clone`.

## Частые ошибки

- **Ожидание автоматического роста `dst`.** `copy` не увеличивает срез; лишние
  элементы игнорируются.
- **Копирование перекрывающихся срезов без понимания.** `copy(s[1:], s)` работает
  корректно (копирует как `memmove`), но логику стоит проверять.
- **`copy(dst, src...)`.** Здесь многоточие лишнее: `copy` принимает срезы.

## Практика

**Задание.** Скопируйте срез `[]int{5, 10, 15}` в новый срез длиной 3, измените первый элемент копии на `1` и напечатайте оба среза.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	src := []int{5, 10, 15}
	dst := make([]int, len(src))
	// скопируйте данные и измените первый элемент dst
	fmt.Println(src, dst)
}
```

**Ожидаемый вывод:**

```text
[5 10 15] [1 10 15]
```

**Подсказка.** Создайте `dst := make([]int, len(src))` и вызовите `copy(dst, src)`.

**Решение:**

```go
package main

import "fmt"

func main() {
	src := []int{5, 10, 15}
	dst := make([]int, len(src))
	copy(dst, src)
	dst[0] = 1
	fmt.Println(src, dst)
}
```

## Резюме

- `copy(dst, src)` копирует минимум из длин и возвращает число элементов.
- Копия отделяет данные от общего массива, в отличие от подсреза.
- Копия помогает не удерживать в памяти большой массив через маленький подсрез.

`range` — единый способ обойти срез, map и канал; посмотрим на его тонкости.
