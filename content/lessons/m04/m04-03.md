## Длина и ёмкость

`len(s)` — сколько элементов доступно, `cap(s)` — сколько поместится без
перевыделения массива. Для литерала они обычно равны:

```go
package main

import "fmt"

func main() {
	s := make([]int, 2, 5)
	fmt.Println(len(s), cap(s)) // 2 5

	part := s[:4]
	fmt.Println(len(part), cap(part)) // 4 5
}
```

Расти можно только до ёмкости: `s[:6]` при `cap == 5` — паника.

## Что происходит при append

`append` пишет в свободную ёмкость, а если её нет — выделяет новый массив
(обычно удвоенной ёмкости), копирует данные и возвращает новый срез. Старый
массив остаётся нетронутым:

```go
s := make([]int, 0, 2)
fmt.Println(len(s), cap(s)) // 0 2
s = append(s, 1, 2)
fmt.Println(len(s), cap(s)) // 2 2
s = append(s, 3)
fmt.Println(len(s), cap(s)) // 3 4
```

Поэтому результат `append` всегда нужно присваивать: `s = append(s, x)`.

## Зачем задавать ёмкость

Если заранее известно число элементов, `make([]T, 0, n)` избавляет от нескольких
перевыделений и копирований. Это заметно на сотнях тысяч элементов:

```go
out := make([]int, 0, len(values))
for _, v := range values {
	out = append(out, v*2)
}
```

## Частые ошибки

- **Забыть присвоить результат append.** `append(s, 1)` без `s =` ничего не
  изменит.
- **Индексация за длиной.** `s[2]` при `len(s) == 2` — паника, даже если
  `cap(s) > 2`; сначала нужно `append` или `s = s[:3]`.
- **Ожидание отдельной копии.** Два среза с общим массивом видят изменения друг
  друга.

## Практика

**Задание.** Создайте срез с `len 0` и `cap 4`, добавьте три элемента и напечатайте `len`, `cap` и сам срез.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	s := make([]int, 0, 4)
	// добавьте 10, 20, 30
	fmt.Println(len(s), cap(s), s)
}
```

**Ожидаемый вывод:**

```text
3 4 [10 20 30]
```

**Подсказка.** Начните с `make([]int, 0, 4)` и добавляйте элементы через `append`.

**Решение:**

```go
package main

import "fmt"

func main() {
	s := make([]int, 0, 4)
	s = append(s, 10, 20, 30)
	fmt.Println(len(s), cap(s), s)
}
```

## Резюме

- `len` — число доступных элементов, `cap` — размер выделенного массива.
- `append` при нехватке ёмкости выделяет новый массив и копирует данные.
- Заранее известная ёмкость экономит перевыделения.

`append` заслуживает отдельного урока: он умеет добавлять срез целиком.
