## Строка — это неизменяемые байты

Строка в Go — последовательность байт в UTF-8. `len(s)` возвращает число **байт**,
а не символов:

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "привет"
	fmt.Println(len(text), utf8.RuneCountInString(text))

	for _, r := range text {
		fmt.Print(string(r), " ")
	}
	fmt.Println()
}
```

`len("привет") == 12` (по 2 байта на кириллическую букву), а рун — 6. `range`
декодирует UTF-8 и даёт `rune` (`int32`), индекс при этом байтовый.

## Индексация и подсрез

`s[0]` — это `byte`, а `s[0:2]` может разрезать символ посередине. Для работы с
символами строку превращают в срез рун:

```go
runes := []rune("привет")
runes[0] = 'П'
fmt.Println(string(runes)) // Привет
```

## Пакет strings

Основные функции: `Contains`, `HasPrefix`, `TrimSpace`, `Split`, `Join`,
`ToUpper`, `ReplaceAll`, `Cut`. Сборка строк из многих частей — через
`strings.Builder`, а не `+=` в цикле (каждый `+=` создаёт новую строку).

```go
var b strings.Builder
for i := 0; i < 3; i++ {
	b.WriteString("го")
}
fmt.Println(b.String())
```

## Частые ошибки

- **`len` вместо числа символов.** Для кириллицы и эмодзи результат завышен.
- **Индекс как символ.** `s[i]` — байт; для рун используйте `[]rune`.
- **Конкатенация в цикле.** Квадратичная сложность на больших данных.
- **Сравнение руны и строки.** `r == "a"` не компилируется: сравните
  `r == 'a'` или `string(r) == "a"`.

## Практика

**Задание.** Посчитайте количество букв и байт в строке «Привет, Go!» и напечатайте их в формате `букв: N, байт: M`.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "Привет, Go!"
	fmt.Println(utf8.RuneCountInString(text), len(text))
}
```

**Ожидаемый вывод:**

```text
букв: 11, байт: 17
```

**Подсказка.** `utf8.RuneCountInString(text)` даёт число рун, `len(text)` — число байт.

**Решение:**

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "Привет, Go!"
	fmt.Printf("букв: %d, байт: %d\n", utf8.RuneCountInString(text), len(text))
}
```

## Резюме

- Строка — неизменяемая последовательность байт UTF-8, `len` считает байты.
- `range` по строке даёт руны, `[]rune` позволяет менять символы.
- Для сборки текста используйте `strings.Builder`, для поиска и замены — `strings`.
