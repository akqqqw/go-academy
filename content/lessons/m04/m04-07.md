## Хеш-таблица

`map[K]V` хранит значения по ключу. Ключ должен быть сравним (`==`), поэтому
срезы и функции ключами быть не могут, а структуры без несравнимых полей — могут:

```go
package main

import "fmt"

func main() {
	counts := map[string]int{"go": 1}
	counts["rust"] = 2
	counts["go"]++

	fmt.Println(counts, len(counts), counts["rust"])
	delete(counts, "rust")
	fmt.Println(len(counts))
}
```

Чтение отсутствующего ключа возвращает нулевое значение типа, а не ошибку.

## Проверка наличия

Идиома `value, ok := m[key]`:

```go
age, ok := map[string]int{"Анна": 30}["Борис"]
fmt.Println(age, ok) // 0 false
```

Отличить «нет ключа» от «лежит ноль» иначе нельзя. Для счётчиков удобно
`counts[key]++` — нулевое значение для `int` равно нулю.

## nil-map и make

```go
var m map[string]int   // nil
fmt.Println(m["x"])    // 0 — читать можно
// m["x"] = 1           // panic: assignment to entry in nil map
```

Запись в nil-map — паника, поэтому карту нужно создать: `make(map[string]int)` или
литералом. `len(nil)` равно 0, `range` по nil ничего не делает.

## Частые ошибки

- **Запись в nil-map.** Самая частая паника у новичков.
- **Срез как ключ.** `map[[]int]bool` не компилируется; используйте строковый
  ключ или `fmt.Sprint`.
- **Порядок.** Итерация неупорядочена; для вывода — сортируйте ключи.
- **Гонка данных.** Map не безопасна для конкурентной записи; нужен мьютекс или
  `sync.Map` (модуль 11).

## Практика

**Задание.** Посчитайте частоту слов в срезе `[]string{"go", "go", "sql", "go", "sql"}` и напечатайте количество для `"go"` и `"sql"`.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	words := []string{"go", "go", "sql", "go", "sql"}
	counts := make(map[string]int)
	for range words {
		// увеличьте счётчик нужного слова
	}
	fmt.Println(counts["go"], counts["sql"])
}
```

**Ожидаемый вывод:**

```text
3 2
```

**Подсказка.** Заведите `map[string]int` и увеличивайте `counts[word]` в цикле.

**Решение:**

```go
package main

import "fmt"

func main() {
	words := []string{"go", "go", "sql", "go", "sql"}
	counts := make(map[string]int)
	for _, word := range words {
		counts[word]++
	}
	fmt.Println(counts["go"], counts["sql"])
}
```

## Резюме

- Map хранит пары «ключ — значение» и требует сравнимого ключа.
- Наличие ключа проверяют через `value, ok := m[key]`.
- Запись в nil-map паникует: создавайте карту через `make` или литерал.

Строки в Go — UTF-8, а `len` считает байты; разберём руны.
