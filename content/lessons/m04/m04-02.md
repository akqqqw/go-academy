## Срез — окно в массив

Срез (slice) описывается тремя полями: указатель на массив, длина и ёмкость.
Создать его можно литералом, через `make` или срезав массив:

```go
package main

import "fmt"

func main() {
	words := []string{"go", "is", "fun"}
	made := make([]int, 3)        // len 3, все нули
	empty := []int{}              // пустой, но не nil
	var nilSlice []int            // nil-срез
	fmt.Println(words, made, empty, nilSlice, len(empty), len(nilSlice))
}
```

`make([]T, len)` создаёт срез нужной длины, `make([]T, len, cap)` — ещё и с
запасом ёмкости.

## Подсрез

`a[low:high]` берёт элементы с `low` по `high-1`. Границы можно опускать:

```go
numbers := []int{10, 20, 30, 40, 50}
fmt.Println(numbers[1:3])  // [20 30]
fmt.Println(numbers[:2])   // [10 20]
fmt.Println(numbers[3:])   // [40 50]
```

Подсрез не копирует данные: он смотрит в тот же массив. Изменение элемента
подсреза меняет исходный срез.

## nil-срез и пустой срез

Оба имеют `len == 0` и оба безопасны для `range` и `append`. Разница только в
сравнении с `nil` и в JSON: nil-срез кодируется как `null`, пустой — как `[]`.
Если API должен отдавать массив, инициализируйте срез: `[]T{}`.

## Частые ошибки

- **Ожидание копии.** `b := a[1:3]` создаёт окно, а не независимую копию; для
  копии нужен `copy` или `slices.Clone`.
- **Забытый индекс.** `a[len(a)]` — паника; допустимы индексы до `len(a)-1`.
- **Путаница len и cap при подсрезе.** У `a[2:4]` длина 2, а ёмкость
  `cap(a)-2`.
- **Сравнение срезов через `==`.** Разрешено только с `nil`; для сравнения
  содержимого — `slices.Equal`.

## Практика

**Задание.** Создайте срез `[]string{"a", "b", "c", "d", "e"}`, возьмите подсрез со второго по четвёртый элемент и напечатайте его и его длину.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	items := []string{"a", "b", "c", "d", "e"}
	part := items[:0] // возьмите элементы с индекса 1 по 3 включительно
	fmt.Println(part, len(part))
}
```

**Ожидаемый вывод:**

```text
[b c d] 3
```

**Подсказка.** Используйте `items[1:4]`; длина подсреза — `len(part)`.

**Решение:**

```go
package main

import "fmt"

func main() {
	items := []string{"a", "b", "c", "d", "e"}
	part := items[1:4]
	fmt.Println(part, len(part))
}
```

## Резюме

- Срез — окно в массив: указатель, длина и ёмкость.
- Создание: литерал, `make([]T, len, cap)`, подсрез `a[low:high]`.
- Подсрез делит память с исходным срезом, копирует только `copy`.

Разберём `len` и `cap` подробнее: от них зависит поведение `append`.
