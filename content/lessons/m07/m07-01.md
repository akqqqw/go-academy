## error — обычный интерфейс

```go
type error interface {
	Error() string
}
```

Любой тип с методом `Error() string` является ошибкой. Ошибки в Go — значения:
их возвращают, сравнивают, складывают в поля структур и передают по стеку.

```go
package main

import (
	"errors"
	"fmt"
)

func parseAge(age int) (int, error) {
	if age < 0 {
		return 0, errors.New("возраст не может быть отрицательным")
	}
	return age, nil
}

func main() {
	value, err := parseAge(-1)
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(value)
}
```

## nil означает успех

Нулевое значение интерфейса `error` — `nil`. Соглашение: `err != nil` — что-то
пошло не так, `err == nil` — успех. Других сигналов нет.

## Ошибка или паника

- **Ошибка** — ожидаемая ситуация: файл не найден, ввод неверный, сеть упала.
  Возвращайте её.
- **Паника** — программная ошибка: выход за границы, nil-разыменование, деление
  на ноль. Обычно её не перехватывают.

Библиотечный код почти никогда не должен паниковать вместо возврата ошибки.

## Частые ошибки

- **Сравнение строк ошибок.** `err.Error() == "not found"` ломается при смене
  текста; используйте `errors.Is`.
- **Потеря ошибки.** `if err != nil { return }` без возврата скрывает причину.
- **Ошибка как строка в API.** Пользователю нужен код, разработчику — контекст.
- **Паника в библиотеке.** Вызывающий код не сможет обработать ситуацию штатно.

## Практика

**Задание.** Напишите функцию `validate(name string) error`, возвращающую ошибку для пустого имени, и обработайте её в `main`.

**Стартовый код:**

```go
package main

import "fmt"

func validate(name string) error {
	return nil // проверьте пустое имя
}

func main() {
	if err := validate(""); err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println("ок")
}
```

**Ожидаемый вывод:**

```text
ошибка: имя не может быть пустым
```

**Подсказка.** Верните `errors.New("имя не может быть пустым")`, если `name == ""`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

func validate(name string) error {
	if name == "" {
		return errors.New("имя не может быть пустым")
	}
	return nil
}

func main() {
	if err := validate(""); err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println("ок")
}
```

## Резюме

- `error` — интерфейс с единственным методом `Error() string`.
- `nil` означает успех, `err != nil` — ошибку.
- Ожидаемые сбои возвращают ошибку, паника остаётся для программных ошибок.
