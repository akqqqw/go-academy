## Простейшая ошибка

```go
var ErrNotFound = errors.New("не найдено")

func find(name string) error {
	if name == "" {
		return ErrNotFound
	}
	return nil
}
```

`errors.New` возвращает значение, реализующее `error`. Каждый вызов создаёт новый
указатель, поэтому сравнивать надо не текст, а само значение.

## Сентинел-ошибки

Ошибка уровня пакета, которую вызывающий код узнаёт по имени, называется
сентинелом (`io.EOF`, `sql.ErrNoRows`, `os.ErrNotExist`). Её экспортируют, если
потребителю нужно различать ситуации:

```go
package main

import (
	"errors"
	"fmt"
)

var ErrNotFound = errors.New("не найдено")

func main() {
	err := fmt.Errorf("пользователь: %w", ErrNotFound)
	if errors.Is(err, ErrNotFound) {
		fmt.Println("не найдено")
	}
}
```

`errors.Is` проходит по цепочке обёрток, поэтому работает и с обёрнутой ошибкой,
в отличие от `==`.

## Именование

- Экспортируемые: `ErrNotFound`, `ErrClosed`.
- Текст — строчными буквами, без точки в конце: ошибку часто встраивают в
  `fmt.Errorf`.
- Не добавляйте имя пакета в текст: `errors.New("storage: нет записи")` в
  пакете `storage` даст двойной префикс.

## Частые ошибки

- **Создание сентинела в функции.** Новая переменная на каждый вызов не даст
  сравнивать её снаружи.
- **Сравнение через `==` обёрнутой ошибки.** Не сработает; нужен `errors.Is`.
- **Зависимость от текста.** Тесты на `err.Error() == "..."` хрупкие.

## Практика

**Задание.** Объявите сентинел `ErrEmpty` и функцию `requireName`, возвращающую его для пустой строки; проверьте результат через `errors.Is`.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrEmpty = errors.New("пустое имя")

func requireName(name string) error {
	return nil // проверьте пустое имя и верните ErrEmpty
}

func main() {
	err := requireName("")
	if errors.Is(err, ErrEmpty) {
		fmt.Println("поймали:", err)
	}
}
```

**Ожидаемый вывод:**

```text
поймали: пустое имя
```

**Подсказка.** `var ErrEmpty = errors.New("пустое имя")`, затем `errors.Is(err, ErrEmpty)`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrEmpty = errors.New("пустое имя")

func requireName(name string) error {
	if name == "" {
		return ErrEmpty
	}
	return nil
}

func main() {
	err := requireName("")
	if errors.Is(err, ErrEmpty) {
		fmt.Println("поймали:", err)
	}
}
```

## Резюме

- `errors.New` создаёт простую ошибку-значение.
- Сентинел объявляют один раз на уровне пакета и экспортируют.
- Проверка — `errors.Is`, а не сравнение текста.

`fmt.Errorf` добавляет контекст и умеет оборачивать ошибки.
