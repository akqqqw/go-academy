## Что внутри обёртки

`fmt.Errorf` с `%w` создаёт ошибку с методом `Unwrap() error`, который возвращает
причину. `errors.Is`/`As` разворачивают цепочку именно через него.

```go
package main

import (
	"errors"
	"fmt"
)

var ErrNotFound = errors.New("не найдено")

type QueryError struct {
	Table string
	Err   error
}

func (e *QueryError) Error() string {
	return fmt.Sprintf("таблица %s: %v", e.Table, e.Err)
}

func (e *QueryError) Unwrap() error { return e.Err }

func main() {
	err := fmt.Errorf("загрузка: %w", &QueryError{Table: "users", Err: ErrNotFound})

	fmt.Println(err)
	fmt.Println(errors.Is(err, ErrNotFound))

	var queryErr *QueryError
	fmt.Println(errors.As(err, &queryErr), queryErr.Table)
}
```

## Несколько причин

`errors.Join` собирает список ошибок. Его текст — строки через перевод строки,
`Is`/`As` проверяют каждый элемент:

```go
err := errors.Join(errors.New("первая"), errors.New("вторая"))
fmt.Println(err.Error())
```

## Один Unwrap или несколько

- `Unwrap() error` — одна причина.
- `Unwrap() []error` — несколько (так делает `Join`).

Реализовывать оба сразу нельзя: методы с одним именем и разными результатами не
перегружаются.

## Частые ошибки

- **Забыть `Unwrap`.** Ошибка выглядит обёрнутой, но `errors.Is` её не видит.
- **Вернуть `nil` из Unwrap.** Допустимо, но цепочка закончится.
- **Хранить текст вместо ошибки.** `Err string` нельзя развернуть.
- **Оборачивать без контекста.** `%w` без текста не добавляет информации.

## Практика

**Задание.** Реализуйте `Unwrap` для `ConfigError`, чтобы `errors.Is(err, ErrInvalid)` возвращал true, и напечатайте результат.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrInvalid = errors.New("неверная конфигурация")

type ConfigError struct {
	Key string
	Err error
}

func (e *ConfigError) Error() string { return e.Key + ": " + e.Err.Error() }

// добавьте Unwrap

func main() {
	err := fmt.Errorf("старт: %w", &ConfigError{Key: "port", Err: ErrInvalid})
	fmt.Println(errors.Is(err, ErrInvalid))
}
```

**Ожидаемый вывод:**

```text
true
```

**Подсказка.** Добавьте `func (e *ConfigError) Unwrap() error { return e.Err }`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrInvalid = errors.New("неверная конфигурация")

type ConfigError struct {
	Key string
	Err error
}

func (e *ConfigError) Error() string { return e.Key + ": " + e.Err.Error() }

func (e *ConfigError) Unwrap() error { return e.Err }

func main() {
	err := fmt.Errorf("старт: %w", &ConfigError{Key: "port", Err: ErrInvalid})
	fmt.Println(errors.Is(err, ErrInvalid))
}
```

## Резюме

- Обёртка хранит причину и отдаёт её через `Unwrap`.
- `errors.Join` объединяет несколько ошибок в одну.
- Свой тип ошибки должен реализовать `Unwrap`, иначе цепочка оборвётся.

Паники тоже бывают полезны — но только для действительно исключительных ситуаций.
