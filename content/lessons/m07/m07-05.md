## Сравнение причин

`errors.Is(err, target)` возвращает true, если `err` совпадает с `target` или
оборачивает его:

```go
package main

import (
	"errors"
	"fmt"
	"io"
)

func main() {
	wrapped := fmt.Errorf("чтение: %w", io.EOF)
	fmt.Println(wrapped == io.EOF)          // false
	fmt.Println(errors.Is(wrapped, io.EOF)) // true
}
```

`==` сравнивает только верхний уровень, `errors.Is` разворачивает цепочку через
`Unwrap()`.

## Цепочка и несколько ошибок

Ошибка может содержать несколько причин (`errors.Join`). `errors.Is` проверяет
все ветки:

```go
err := errors.Join(io.EOF, errors.New("сеть"))
fmt.Println(errors.Is(err, io.EOF)) // true
```

## Своя ошибка и Is

Если тип ошибки особенный (например, сравнение по коду), можно реализовать метод
`Is(target error) bool`. Обычно это не требуется: достаточно сентинела или типа.

## Частые ошибки

- **`err == target` для обёрнутой ошибки.** Даёт false, хотя причина та же.
- **`errors.Is(err.Error(), ...)`.** Метод принимает `error`, а не строку.
- **Сравнение ошибок разных пакетов.** `sql.ErrNoRows` и своя `ErrNotFound` —
  разные значения, даже если текст похож.
- **Забытая проверка `err != nil`.** `errors.Is(nil, nil)` вернёт true — не
  путайте отсутствие ошибки с совпадением.

## Практика

**Задание.** Оберните `io.EOF` дважды и убедитесь, что `errors.Is` находит причину, напечатав результат.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
	"io"
)

func load() error {
	return fmt.Errorf("внешний: %w", io.EOF) // добавьте второй уровень обёртки
}

func main() {
	err := load()
	fmt.Println(errors.Is(err, io.EOF))
}
```

**Ожидаемый вывод:**

```text
true
```

**Подсказка.** Соберите `err := fmt.Errorf("внешний: %w", fmt.Errorf("внутренний: %w", io.EOF))`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
	"io"
)

func load() error {
	return fmt.Errorf("внешний: %w", fmt.Errorf("внутренний: %w", io.EOF))
}

func main() {
	err := load()
	fmt.Println(errors.Is(err, io.EOF))
}
```

## Резюме

- `errors.Is` ищет ошибку по всей цепочке обёрток.
- `==` сравнивает только верхний уровень и обычно не подходит.
- `errors.Join` объединяет несколько причин, `Is` проверяет все.

`errors.As` нужен, когда из ошибки надо достать данные определённого типа.
