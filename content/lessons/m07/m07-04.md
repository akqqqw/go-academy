## Контекст вместо новой ошибки

`fmt.Errorf` форматирует текст с данными. Так добавляют контекст, не теряя
причину:

```go
package main

import (
	"errors"
	"fmt"
)

var ErrPermission = errors.New("нет доступа")

func openFile(name string) error {
	if name == "" {
		return fmt.Errorf("открыть файл: %w", ErrPermission)
	}
	return nil
}

func main() {
	err := openFile("")
	fmt.Println(err)
	fmt.Println(errors.Is(err, ErrPermission))
}
```

Результат: `открыть файл: нет доступа` и `true`.

## %w и %v

- `%w` оборачивает ошибку: она остаётся доступной для `errors.Is` и `errors.As`.
- `%v` просто вставляет текст: цепочка рвётся.

Оборачивать можно несколько ошибок (Go 1.20+): `fmt.Errorf("%w: %w", first,
second)` — `errors.Is` найдёт любую из них.

## Читаемая цепочка

```go
func load(path string) error {
	data, err := read(path)
	if err != nil {
		return fmt.Errorf("загрузка конфигурации %q: %w", path, err)
	}
	_ = data
	return nil
}
```

Правило: каждое звено добавляет **что** делали, но не дублирует «error:».
Итоговый текст читается как маршрут: `загрузка конфигурации "app.json":
открыть файл: нет доступа`.

## Частые ошибки

- **`%w` без ошибки.** Аргумент должен быть типа `error`, иначе получите
  `%!w(...)`.
- **Двойное оборачивание одного и того же.** Текст раздувается, пользы нет.
- **Потеря причины через `%v`.** Вызывающий код не сможет проверить `errors.Is`.
- **Оборачивание на каждом уровне без надобности.** Достаточно там, где есть
  новые детали.

## Практика

**Задание.** Оберните ошибку `ErrPermission` контекстом `"чтение файла"` через `fmt.Errorf` и проверьте результат через `errors.Is`.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrPermission = errors.New("нет доступа")

func readFile() error {
	return ErrPermission // оберните ошибку контекстом
}

func main() {
	err := readFile()
	fmt.Println(err)
	fmt.Println(errors.Is(err, ErrPermission))
}
```

**Ожидаемый вывод:**

```text
чтение файла: нет доступа
true
```

**Подсказка.** Верните `fmt.Errorf("чтение файла: %w", ErrPermission)`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrPermission = errors.New("нет доступа")

func readFile() error {
	return fmt.Errorf("чтение файла: %w", ErrPermission)
}

func main() {
	err := readFile()
	fmt.Println(err)
	fmt.Println(errors.Is(err, ErrPermission))
}
```

## Резюме

- `fmt.Errorf` добавляет данные и контекст к ошибке.
- `%w` сохраняет цепочку для `errors.Is`/`errors.As`, `%v` — нет.
- Каждое звено описывает операцию, текст должен читаться как маршрут.

`errors.Is` — надёжная проверка «это та самая ошибка?».
