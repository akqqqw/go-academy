## Достать тип и его поля

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func parse(text string) (int, error) {
	n, err := strconv.Atoi(text)
	if err != nil {
		return 0, fmt.Errorf("разбор %q: %w", text, err)
	}
	return n, nil
}

func main() {
	_, err := parse("семь")

	var numErr *strconv.NumError
	if errors.As(err, &numErr) {
		fmt.Println("не число:", numErr.Num)
	}
}
```

`errors.As` заполняет переменную и возвращает true, если в цепочке есть ошибка
нужного типа. Второй аргумент — **указатель** на переменную нужного типа.

## Is против As

| Вопрос | Функция |
| --- | --- |
| «Это именно эта ошибка?» | `errors.Is` |
| «Есть ли в цепочке ошибка такого типа и какие у неё поля?» | `errors.As` |

`errors.As` работает и с сентинелами, но для них достаточно `Is`.

## Свои типы

```go
type APIError struct {
	Status int
}

func (e *APIError) Error() string { return fmt.Sprintf("статус %d", e.Status) }

func call() error { return fmt.Errorf("запрос: %w", &APIError{Status: 503}) }
```

Затем `var apiErr *APIError; if errors.As(err, &apiErr) { ... }`.

## Частые ошибки

- **Передать значение вместо указателя.** `errors.As(err, target)` не
  скомпилируется: нужен `&target`.
- **Не тот уровень указателя.** Для `*APIError` объявляйте `var target
  *APIError` и передавайте `&target`.
- **Использовать As для сравнения сентинела.** Проще и понятнее `Is`.
- **Паника при nil.** `errors.As(nil, &target)` вернёт false, это безопасно.

## Практика

**Задание.** Извлеките `*strconv.NumError` из обёрнутой ошибки разбора и напечатайте проблемную строку.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func parse(text string) (int, error) {
	n, err := strconv.Atoi(text)
	if err != nil {
		return 0, fmt.Errorf("разбор: %w", err)
	}
	return n, nil
}

func main() {
	_, err := parse("семь")
	var numErr *strconv.NumError
	if errors.As(err, &numErr) {
		fmt.Println(numErr.Num)
	}
}
```

**Ожидаемый вывод:**

```text
не число: семь
```

**Подсказка.** `var numErr *strconv.NumError; if errors.As(err, &numErr) { fmt.Println(numErr.Num) }`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func parse(text string) (int, error) {
	n, err := strconv.Atoi(text)
	if err != nil {
		return 0, fmt.Errorf("разбор %q: %w", text, err)
	}
	return n, nil
}

func main() {
	_, err := parse("семь")
	var numErr *strconv.NumError
	if errors.As(err, &numErr) {
		fmt.Println("не число:", numErr.Num)
	}
}
```

## Резюме

- `errors.As` находит в цепочке ошибку нужного типа и заполняет переменную.
- Второй аргумент — указатель на переменную: `var e *MyError; errors.As(err, &e)`.
- `Is` — про совпадение, `As` — про тип и поля.

Оборачивание ошибок: `Unwrap`, `errors.Join` и собственные цепочки.
