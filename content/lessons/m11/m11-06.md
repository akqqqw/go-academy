## Взаимное исключение

`sync.Mutex` гарантирует, что критическую секцию выполняет одна горутина:

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu    sync.Mutex
	value int
}

func (c *Counter) Inc() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.value++
}

func (c *Counter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.value
}

func main() {
	counter := &Counter{}
	var wg sync.WaitGroup
	for i := 0; i < 100; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			counter.Inc()
		}()
	}
	wg.Wait()
	fmt.Println(counter.Value())
}
```

Без мьютекса инкремент `value++` (чтение, сложение, запись) теряет обновления —
это гонка данных.

## Правила

- Мьютекс — поле структуры, а не глобальная переменная без нужды.
- `defer mu.Unlock()` сразу после `Lock()`: меньше шансов забыть.
- Не держите блокировку во время ввода-вывода или вызова чужого кода.
- Структуру с мьютексом не копируют (`go vet` предупредит).

## RWMutex

`sync.RWMutex` разрешает много читателей одновременно, но писатель получает
исключительный доступ: `RLock`/`RUnlock`. Полезно, когда чтений заметно больше,
чем записей.

## Частые ошибки

- **Забыть Unlock.** Взаимная блокировка (deadlock).
- **Блокировать одну и ту же секцию дважды.** `sync.Mutex` не рекурсивный.
- **Возвращать значение без блокировки.** Читатель увидит частичное состояние.
- **Копировать структуру с мьютексом.** Копия защищает уже другие данные.

## Практика

**Задание.** Защитите общий счётчик мьютексом в 50 горутинах и напечатайте итог.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu    sync.Mutex
	value int
}

func (c *Counter) Inc() {
	// защитите инкремент
}

func main() {
	counter := &Counter{}
	var wg sync.WaitGroup
	for i := 0; i < 50; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			counter.Inc()
		}()
	}
	wg.Wait()
	fmt.Println(counter.value)
}
```

**Ожидаемый вывод:**

```text
50
```

**Подсказка.** Заведите структуру с `sync.Mutex` и методом `Inc`, увеличивайте под блокировкой.

**Решение:**

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu    sync.Mutex
	value int
}

func (c *Counter) Inc() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.value++
}

func main() {
	counter := &Counter{}
	var wg sync.WaitGroup
	for i := 0; i < 50; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			counter.Inc()
		}()
	}
	wg.Wait()
	fmt.Println(counter.value)
}
```

## Резюме

- `Mutex` делает критическую секцию доступной одной горутине.
- `defer mu.Unlock()` защищает от забытого разблокирования.
- `RWMutex` разделяет читателей и писателей.
