## Выбор готового канала

`select` похож на `switch`, но ждёт готовности операций с каналами:

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	fast := make(chan string)
	slow := make(chan string)

	go func() { time.Sleep(10 * time.Millisecond); slow <- "медленно" }()
	go func() { fast <- "быстро" }()

	fmt.Println(<-fast)

	select {
	case msg := <-fast:
		fmt.Println("fast:", msg)
	case msg := <-slow:
		fmt.Println("slow:", msg)
	case <-time.After(50 * time.Millisecond):
		fmt.Println("таймаут")
	}
}
```

Если готовы несколько case, выбирается случайный — это защита от голодания.

## default

`default` делает операцию неблокирующей:

```go
select {
case msg := <-ch:
	fmt.Println("получили", msg)
default:
	fmt.Println("данных нет")
}
```

Так проверяют, закрыт ли канал и есть ли данные, но нельзя использовать это как
цикл ожидания — получится busy loop.

## Таймауты и отмена

`time.After(d)` возвращает канал, который сработает через `d`. Для отмены по
`context` используют `ctx.Done()`.

## Частые ошибки

- **select без default в цикле ожидания.** Блокируется навсегда, если никто не
  пишет.
- **Забытый `time.After` в долгом цикле.** Создаёт таймеры; лучше `time.NewTimer`.
- **Ожидание приоритета.** `select` не гарантирует порядок case.
- **Чтение из закрытого канала как сигнал ошибки.** Помните: закрытый канал
  всегда готов, вернёт нулевое значение.

## Практика

**Задание.** Сделайте неблокирующее чтение из пустого канала через `select` с `default` и напечатайте `пусто`.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int, 1)
	select {
	case v := <-ch:
		fmt.Println("значение:", v)
	default:
		fmt.Println("занято")
	}
}
```

**Ожидаемый вывод:**

```text
пусто
```

**Подсказка.** `select { case v := <-ch: ...; default: fmt.Println("пусто") }`.

**Решение:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int, 1)
	select {
	case v := <-ch:
		fmt.Println("значение:", v)
	default:
		fmt.Println("пусто")
	}
}
```

## Резюме

- `select` ждёт первый готовый канал и выбирает случайный при равенстве.
- `default` делает операцию неблокирующей.
- `time.After` и `ctx.Done()` добавляют таймауты и отмену.

`sync.WaitGroup` — ожидание группы горутин.
