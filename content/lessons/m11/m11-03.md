## Ёмкость

`make(chan T, n)` создаёт канал с буфером на `n` значений. Пока буфер не полон,
отправка не блокируется:

```go
package main

import "fmt"

func main() {
	jobs := make(chan int, 3)
	jobs <- 1
	jobs <- 2
	jobs <- 3
	close(jobs)

	for job := range jobs {
		fmt.Println("задача:", job)
	}
	fmt.Println("len/cap:", len(jobs), cap(jobs))
}
```

После закрытия можно прочитать все накопленные значения. `len` — сколько лежит
сейчас, `cap` — ёмкость.

## Когда буфер полезен

- **Сглаживание пиков.** Отправитель не ждёт мгновенно получателя.
- **Пул задач.** Очередь ограниченного размера.
- **Сбор результатов.** Каналы на число воркеров.

Важно: буфер не решает проблему медленного потребителя, он только откладывает
блокировку. Неограниченной очереди в канале нет — при переполнении отправитель
встанет.

## Семантика закрытия

- Получатель из пустого закрытого канала сразу получает нулевое значение.
- `range` завершается, когда буфер опустел и канал закрыт.
- `select` с `default` позволяет проверить, есть ли данные без ожидания.

## Частые ошибки

- **Ждать, что отправка никогда не блокируется.** При полном буфере она ждёт.
- **Брать буфер «на всякий случай» размером 100000.** Маскирует проблему
  потребителя и ест память.
- **Читать `len(ch)` для логики синхронизации.** Значение мгновенно устаревает.

## Практика

**Задание.** Создайте канал с буфером 2, отправьте два значения без горутины, закройте и напечатайте их произведение.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int, 2)
	ch <- 2
	ch <- 3
	close(ch)

	// прочитайте два значения и посчитайте произведение
	fmt.Println(0)
}
```

**Ожидаемый вывод:**

```text
6
```

**Подсказка.** После `ch <- 2; ch <- 3; close(ch)` прочитайте два значения через `<-ch`.

**Решение:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int, 2)
	ch <- 2
	ch <- 3
	close(ch)

	a := <-ch
	b := <-ch
	fmt.Println(a * b)
}
```

## Резюме

- `make(chan T, n)` даёт буфер на n элементов.
- Отправка блокируется только при полном буфере.
- Буфер сглаживает пики, но не заменяет быстрого потребителя.

`select` — переключение между несколькими каналами.
