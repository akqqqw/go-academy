## Запуск

`go f()` запускает функцию параллельно и сразу возвращает управление:

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	wg.Add(1)
	go func() {
		defer wg.Done()
		fmt.Println("из горутины")
	}()
	wg.Wait()
	fmt.Println("конец")
}
```

Горутина — не поток ОС: планировщик Go раскладывает миллионы горутин по
небольшому числу потоков. Стартовый стек маленький и растёт по необходимости.

## main завершает всё

Когда `main` возвращается, программа заканчивается, не дожидаясь горутин:

```go
go fmt.Println("не факт, что увидим")
```

Порядок вывода между горутинами не определён.

## Как ждать завершения

- `sync.WaitGroup` — когда известно число задач.
- Канал — когда нужен результат.
- `context` — когда нужно уметь отменять.

`time.Sleep` для синхронизации — плохая практика: время выполнения не
гарантировано.

## Частые ошибки

- **Забыть дождаться.** Программа завершится раньше горутин.
- **Горутина с паникой.** Необработанная паника в любой горутине роняет всю
  программу.
- **Переменная цикла.** В Go 1.22+ `go func() { use(i) }()` безопасно, но лучше
  передавать значение параметром — код понятнее.
- **Утечка горутин.** Горутина, ждущая канал, который никто не закроет, живёт
  вечно.

## Практика

**Задание.** Запустите три горутины, каждая добавляет единицу в общий счётчик под защитой `sync.WaitGroup`, и напечатайте итог после ожидания.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	results := make([]int, 3)
	for i := range results {
		wg.Add(1)
		go func(index int) {
			defer wg.Done()
			results[index] = 1 // запишите единицу
		}(i)
	}
	wg.Wait()
	total := 0
	for _, v := range results {
		total += v
	}
	fmt.Println(total)
}
```

**Ожидаемый вывод:**

```text
3
```

**Подсказка.** Создайте срез результатов, по горутине на элемент, соберите сумму после `wg.Wait()`.

**Решение:**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	results := make([]int, 3)
	for i := range results {
		wg.Add(1)
		go func(index int) {
			defer wg.Done()
			results[index] = 1
		}(i)
	}
	wg.Wait()
	total := 0
	for _, v := range results {
		total += v
	}
	fmt.Println(total)
}
```

## Резюме

- `go f()` запускает функцию конкурентно, main не ждёт её завершения.
- Горутины дешёвые, но требуют явной синхронизации.
- Ожидание — `WaitGroup`, канал или `context`.

Каналы — способ передавать данные между горутинами.
