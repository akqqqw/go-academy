## Счётчик активных задач

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	for i := 1; i <= 3; i++ {
		wg.Add(1)
		go func(n int) {
			defer wg.Done()
			fmt.Println("шаг", n)
		}(i)
	}
	wg.Wait()
	fmt.Println("все горутины завершены")
}
```

`Add(1)` увеличивает счётчик, `Done()` уменьшает, `Wait()` блокируется, пока
счётчик не станет нулём.

## Правила

- `Add` вызывают **до** запуска горутины, в родительской.
- `Done` удобно ставить в `defer`, чтобы он выполнился при панике и раннем
  возврате.
- `WaitGroup` нельзя копировать: передавайте `*sync.WaitGroup`.
- Отрицательный счётчик — паника: `sync: negative WaitGroup counter`.

## Результаты

`WaitGroup` не возвращает значения. Для результатов используют каналы или срез
с индексами (по одному индексу на горутину) и читают его после `Wait`.

## Частые ошибки

- **`wg.Add(1)` внутри горутины.** `Wait` может завершиться раньше добавления.
- **Забыть `Done`.** `Wait` зависнет.
- **Копировать WaitGroup.** `go vet` предупредит о `copylocks`.
- **`Add` после `Wait`.** Неопределённое поведение и паника.

## Практика

**Задание.** Запустите две горутины, каждая записывает квадрат своего индекса в срез, дождитесь завершения и напечатайте сумму.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	squares := make([]int, 2)
	for i := range squares {
		wg.Add(1)
		go func(index int) {
			defer wg.Done()
			squares[index] = 0 // запишите квадрат
		}(i)
	}
	wg.Wait()
	fmt.Println(squares[0] + squares[1])
}
```

**Ожидаемый вывод:**

```text
5
```

**Подсказка.** `wg.Add(1)` перед каждой горутиной, `defer wg.Done()`, запись в `squares[i]`.

**Решение:**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	squares := make([]int, 2)
	for i := range squares {
		wg.Add(1)
		go func(index int) {
			defer wg.Done()
			squares[index] = (index + 1) * (index + 1)
		}(i)
	}
	wg.Wait()
	fmt.Println(squares[0] + squares[1])
}
```

## Резюме

- `WaitGroup` ждёт группу горутин: `Add`, `Done`, `Wait`.
- `Add` вызывают до старта горутины, `Done` — через `defer`.
- WaitGroup передают по указателю и не копируют.

Общие данные требуют защиты — знакомимся с `sync.Mutex`.
