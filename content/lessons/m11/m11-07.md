## Что такое гонка данных

Две горутины обращаются к одной переменной, хотя бы одна пишет, и нет
синхронизации. Результат непредсказуем:

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	counter := 0
	for i := 0; i < 1000; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			counter++ // гонка: без мьютекса или atomic
		}()
	}
	wg.Wait()
	fmt.Println(counter) // почти всегда меньше 1000
}
```

## Детектор гонок

```bash
go test -race ./...
go run -race main.go
```

Детектор инструментирует обращения к памяти и печатает стек обеих горутин.
Запускайте `-race` в CI: он замедляет в 5–10 раз, но находит реальные баги.

## Три способа исправить

1. **Мьютекс** — когда несколько полей меняются вместе.
2. **`atomic`** — для счётчиков, флагов и указателей: `atomic.AddInt64`,
   `atomic.LoadInt32`, `atomic.Bool`.
3. **Избежать общего состояния** — передавать данные каналами, не делить память.

Идиома Go: «не общайтесь через общую память, общайтесь через каналы».

## Частые ошибки

- **Проверять гонку глазами.** Без `-race` баг может не проявиться месяцами.
- **Защищать только запись.** Чтение без блокировки тоже гонка.
- **Использовать обычный `map` из нескольких горутин.** Она не безопасна даже
  для параллельного чтения при записи.
- **Ленивая инициализация без `sync.Once`.** Дважды созданный ресурс.

## Практика

**Задание.** Сделайте счётчик безопасным через `sync/atomic`: 100 горутин увеличивают его на единицу, напечатайте итог.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
)

func main() {
	var counter atomic.Int64
	var wg sync.WaitGroup
	for i := 0; i < 100; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			// атомарно увеличьте счётчик
		}()
	}
	wg.Wait()
	fmt.Println(counter.Load())
}
```

**Ожидаемый вывод:**

```text
100
```

**Подсказка.** Используйте `atomic.Int64` с методами `Add(1)` и `Load()`.

**Решение:**

```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
)

func main() {
	var counter atomic.Int64
	var wg sync.WaitGroup
	for i := 0; i < 100; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			counter.Add(1)
		}()
	}
	wg.Wait()
	fmt.Println(counter.Load())
}
```

## Резюме

- Гонка данных — одновременный доступ без синхронизации, хотя бы одна запись.
- `-race` находит гонки, его стоит включать в CI.
- Лечение: мьютекс, atomic или отказ от общего состояния.

`context` — отмена, дедлайны и передача значений через стек вызовов.
