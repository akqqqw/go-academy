## Канал — типизированная труба

```go
package main

import "fmt"

func main() {
	messages := make(chan string)
	go func() {
		messages <- "привет"
	}()
	text := <-messages
	fmt.Println(text)
}
```

Небуферизованный канал синхронизирует: отправитель ждёт получателя, получатель
ждёт отправителя. `close(ch)` закрывает канал, после чего приём возвращает
нулевое значение и `ok == false`.

## Приём в цикле

```go
func produce(ch chan<- int) {
	for i := 1; i <= 3; i++ {
		ch <- i
	}
	close(ch)
}

func main() {
	ch := make(chan int)
	go produce(ch)
	for value := range ch {
		fmt.Println(value)
	}
}
```

`range` по каналу читает до закрытия. Направление можно ограничить в сигнатуре:
`chan<- int` — только отправка, `<-chan int` — только приём.

## Закрытие: правила

- Закрывает **отправитель**, не получатель.
- Отправка в закрытый канал — паника.
- Повторное закрытие — паника.
- Приём из закрытого канала безопасен.

## Частые ошибки

- **Забыть закрыть канал.** `range` будет ждать вечно, горутина утечёт.
- **Закрыть из получателя.** Нарушение контракта владения.
- **Писать в закрытый канал.** Паника `send on closed channel`.
- **Ожидать порядка.** Несколько отправителей дают неопределённый порядок.

## Практика

**Задание.** Передайте три числа через небуферизованный канал в отдельной горутине и напечатайте их сумму в основной.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int)
	go func() {
		for i := 1; i <= 3; i++ {
			ch <- i
		}
		close(ch)
	}()

	total := 0
	for value := range ch {
		_ = value // сложите значения
	}
	fmt.Println(total)
}
```

**Ожидаемый вывод:**

```text
6
```

**Подсказка.** Заведите `ch := make(chan int)`, отправьте числа в горутине, закройте канал и сложите значения из `range`.

**Решение:**

```go
package main

import "fmt"

func main() {
	ch := make(chan int)
	go func() {
		for i := 1; i <= 3; i++ {
			ch <- i
		}
		close(ch)
	}()

	total := 0
	for value := range ch {
		total += value
	}
	fmt.Println(total)
}
```

## Резюме

- Канал передаёт значения между горутинами и синхронизирует их.
- `range` читает до закрытия, закрывает отправитель.
- Направление канала можно ограничить в типе параметра.

Буферизованные каналы разрывают жёсткую синхронизацию.
