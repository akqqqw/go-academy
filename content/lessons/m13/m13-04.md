## Как работает

Сборщик мусора в Go — конкурентный, трёхцветный, с барьерами записи. Он работает
параллельно с программой и стремится к коротким паузам (обычно доли миллисекунды).
Память не освобождается вручную: объект жив, пока на него есть ссылки.

## GOGC и GOMEMLIMIT

- `GOGC=100` (по умолчанию): следующая сборка при росте кучи на 100% относительно
  живой памяти.
- `GOGC=off` — отключить (только для коротких утилит).
- `GOMEMLIMIT` (Go 1.19+) — мягкий предел памяти: сборщик становится активнее
  при приближении к лимиту. Удобно в контейнерах.

```bash
GOGC=50 GOMEMLIMIT=512MiB ./server
```

## Что важно на практике

- Больше живых данных — чаще сборки и выше нагрузка на CPU.
- Кеши без ограничения размера превращаются в утечку памяти.
- Горутина, ждущая канал, удерживает всё, на что ссылается.
- `runtime.ReadMemStats` и профиль `heap` показывают реальную картину.

## Сборка мусора и производительность

Не стоит отключать GC ради «скорости» в долгоживущем сервисе. Вместо этого
уменьшайте аллокации в горячих путях и ограничивайте кеши.

## Частые ошибки

- **Утечка через глобальную map.** Записи не удаляются, память растёт.
- **Горутины без завершения.** Каждая держит стек и ссылки.
- **Ожидание мгновенного освобождения.** `runtime.GC()` — только для отладки.
- **`GOGC=off` в проде.** OOM при первой же нагрузке.

## Практика

**Задание.** Выделите срез сразу с нужной ёмкостью: добавьте 1000 элементов и
напечатайте `ready`, если ёмкость ни разу не изменилась, иначе `grow`.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	items := make([]int, 0) // выделите ёмкость 1000
	prev := cap(items)
	grown := false
	for i := 0; i < 1000; i++ {
		items = append(items, i)
		if cap(items) != prev {
			grown = true
			prev = cap(items)
		}
	}
	if grown {
		fmt.Println("grow")
		return
	}
	fmt.Println("ready")
}
```

**Ожидаемый вывод:**

```text
ready
```

**Подсказка.** Замените `make([]int, 0)` на `make([]int, 0, 1000)`: тогда
перевыделений не будет и `cap` не изменится.

**Решение:**

```go
package main

import "fmt"

func main() {
	items := make([]int, 0, 1000)
	prev := cap(items)
	grown := false
	for i := 0; i < 1000; i++ {
		items = append(items, i)
		if cap(items) != prev {
			grown = true
			prev = cap(items)
		}
	}
	if grown {
		fmt.Println("grow")
		return
	}
	fmt.Println("ready")
}
```

## Резюме

- GC конкурентный и трёхцветный, паузы короткие.
- `GOGC` и `GOMEMLIMIT` управляют агрессивностью сборки.
- Утечки памяти чаще из-за глобальных кешей и незавершённых горутин.

Профилирование: pprof и поиск узких мест.
