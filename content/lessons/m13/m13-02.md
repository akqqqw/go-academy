## Тип и значение

```go
package main

import (
	"fmt"
	"reflect"
)

type User struct {
	ID   int    `json:"id"`
	Name string `json:"name"`
}

func main() {
	user := User{ID: 1, Name: "Анна"}
	t := reflect.TypeOf(user)
	v := reflect.ValueOf(user)

	fmt.Println(t.Name(), t.Kind(), v.NumField())

	for i := 0; i < t.NumField(); i++ {
		field := t.Field(i)
		fmt.Println(field.Name, field.Tag.Get("json"), v.Field(i).Interface())
	}
}
```

Рефлексия — основа `encoding/json`, ORM и валидаторов. В прикладном коде её
используют редко.

## Изменение значения

Чтобы менять данные, нужен указатель и `Elem()`:

```go
v := reflect.ValueOf(&user).Elem()
if field := v.FieldByName("Name"); field.CanSet() {
	field.SetString("Борис")
}
```

`CanSet` проверяет экспортированность и адресуемость.

## Ограничения и цена

- Рефлексия медленнее прямого доступа: тип проверяется в рантайме.
- Опечатки в именах полей — паника или silent-пропуск.
- Компилятор не подскажет ошибку; тесты обязательны.
- Паникующие `Interface()` и `Set` можно обойти проверками `IsValid`.

## Частые ошибки

- **`reflect.ValueOf(x).SetString`.** Значение не адресуемо; нужен указатель.
- **`Interface()` на неэкспортированном поле.** Паника.
- **Рефлексия в горячем цикле.** Кешируйте тип и индексы полей.
- **Ожидание, что теги обязательны.** Тег — просто строка, её читает ваш код.

## Практика

**Задание.** Выведите имена полей структуры `Book` (Title, Pages) через рефлексию и напечатайте их количество.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"reflect"
)

type Book struct {
	Title string
	Pages int
}

func main() {
	t := reflect.TypeOf(Book{})
	names := make([]string, 0, t.NumField())
	for i := 0; i < t.NumField(); i++ {
		names = append(names, "") // добавьте имя поля
	}
	fmt.Println(names)
}
```

**Ожидаемый вывод:**

```text
[Title Pages]
```

**Подсказка.** `reflect.TypeOf(Book{}).NumField()` и `Field(i).Name`.

**Решение:**

```go
package main

import (
	"fmt"
	"reflect"
)

type Book struct {
	Title string
	Pages int
}

func main() {
	t := reflect.TypeOf(Book{})
	names := make([]string, 0, t.NumField())
	for i := 0; i < t.NumField(); i++ {
		names = append(names, t.Field(i).Name)
	}
	fmt.Println(names)
}
```

## Резюме

- `reflect.TypeOf` даёт описание типа, `reflect.ValueOf` — значение.
- Изменение требует указателя и `Elem`, теги читаются через `StructTag`.
- Рефлексия медленнее и не проверяется компилятором.

Управление памятью: стек, куча и аллокации.
