## Слои

```text
cmd/            сборка приложения
internal/api/   HTTP: разбор запроса, коды, JSON
internal/app/   сценарии: «создать заметку»
internal/domain/ правила и типы
internal/storage/ SQL, файлы, внешние API
```

Зависимости направлены внутрь: транспорт и хранилище знают домен, домен не знает
их.

## Инверсия зависимостей

Сценарий объявляет интерфейс, который ему нужен:

```go
package app

import "context"

type Note struct {
	ID    string
	Title string
}

type NoteRepository interface {
	Save(ctx context.Context, note Note) error
	ByID(ctx context.Context, id string) (Note, error)
}

type Service struct {
	repo NoteRepository
}
```

`storage` реализует этот интерфейс. В тестах — реализация в памяти. Домен не
импортирует SQL-драйвер.

## Границы пакетов

- Пакет — единица смысла, а не «папка по типу файла».
- Маленькие пакеты с явным API легче тестировать.
- `internal` защищает от внешних импортов.
- Циклы импортов — сигнал неверных границ.

## Прагматизм

Не каждый проект требует чистых слоёв. Для CLI на 300 строк достаточно одного
пакета. Усложняйте архитектуру, когда появляются реальные требования:
несколько транспортов, смена хранилища, командная разработка.

## Частые ошибки

- **Слои ради слоёв.** Пять пакетов на одну функцию.
- **Домен зависит от БД.** Типы `sql.NullString` в бизнес-логике.
- **Интерфейс на каждый тип.** Интерфейс нужен там, где есть подмена или
  граница.
- **Глобальный логгер и конфиг.** Передавайте зависимости явно.

## Практика

**Задание.** Разделите сценарий и транспорт: функция `serviceTotal` считает сумму, `handlerTotal` форматирует ответ; напечатайте ответ обработчика.

**Стартовый код:**

```go
package main

import "fmt"

func serviceTotal(values []int) int {
	return 0 // сложите значения
}

func handlerTotal(values []int) string {
	return fmt.Sprintf("total=%d", serviceTotal(values))
}

func main() {
	fmt.Println(handlerTotal([]int{2, 3, 5}))
}
```

**Ожидаемый вывод:**

```text
total=10
```

**Подсказка.** `handlerTotal` вызывает `serviceTotal` и возвращает `fmt.Sprintf("total=%d", …)`.

**Решение:**

```go
package main

import "fmt"

func serviceTotal(values []int) int {
	total := 0
	for _, value := range values {
		total += value
	}
	return total
}

func handlerTotal(values []int) string {
	return fmt.Sprintf("total=%d", serviceTotal(values))
}

func main() {
	fmt.Println(handlerTotal([]int{2, 3, 5}))
}
```

## Резюме

- Домен не зависит от транспорта и хранилища, зависимости идут внутрь.
- Интерфейсы объявляет потребитель, реализации живут в инфраструктуре.
- Архитектура должна оправдываться требованиями, а не модой.

Обработка конкурентных задач: ограничение, отмена и устойчивость.
