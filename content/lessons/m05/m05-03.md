## Изменение исходной переменной

Чтобы функция изменила аргумент, передают адрес и работают через `*`:

```go
package main

import "fmt"

func increase(n *int) {
	*n++
}

func main() {
	count := 1
	increase(&count)
	fmt.Println(count) // 2
}
```

Вызов становится явным: `&count` показывает, что переменная может измениться.

## Указатель на структуру

Для структур разыменование часто не требуется: `p.Name` работает как
`(*p).Name` — компилятор сам подставляет звёздочку:

```go
type User struct {
	Name string
}

func rename(u *User, name string) {
	u.Name = name
}
```

Это удобно и читается лучше, чем `(*u).Name`.

## Обработка nil

Функция, принимающая указатель, должна решить: nil допустим или это ошибка.

```go
func setDefault(limit *int) int {
	if limit == nil {
		return 10
	}
	return *limit
}
```

Так делают библиотеки: `nil` означает «не задано».

## Частые ошибки

- **Забыть `&` при вызове.** `increase(count)` не скомпилируется.
- **Изменить копию указателя.** `p = &other` внутри функции не меняет указатель
  вызывающего кода; менять нужно `*p`.
- **Возвращать указатель на локальную переменную «нельзя».** В Go можно: значение
  уйдёт в кучу, и это безопасно.
- **Разыменовывать без проверки.** Если nil допустим, проверяйте его в начале.

## Практика

**Задание.** Реализуйте `doubleAll(nums []int)`, умножающую каждый элемент на 2 без возврата нового среза, и напечатайте результат.

**Стартовый код:**

```go
package main

import "fmt"

func doubleAll(nums []int) {
	// измените элементы на месте
}

func main() {
	nums := []int{1, 2, 3}
	doubleAll(nums)
	fmt.Println(nums)
}
```

**Ожидаемый вывод:**

```text
[2 4 6]
```

**Подсказка.** Срез уже ссылается на данные, поэтому достаточно `nums[i] *= 2` в цикле.

**Решение:**

```go
package main

import "fmt"

func doubleAll(nums []int) {
	for i := range nums {
		nums[i] *= 2
	}
}

func main() {
	nums := []int{1, 2, 3}
	doubleAll(nums)
	fmt.Println(nums)
}
```

## Резюме

- Указатель позволяет функции изменить переменную вызывающего кода.
- Для структур `u.Name` работает без явного разыменования.
- Функция с указателем должна явно определить поведение при `nil`.

Структуры — способ собрать связанные поля в один тип.
