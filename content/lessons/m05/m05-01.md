## Адрес и значение

Указатель хранит адрес переменной. `&x` берёт адрес, `*p` читает или пишет
значение по адресу:

```go
package main

import "fmt"

func main() {
	x := 40
	p := &x
	fmt.Println(p, *p)

	*p = 42
	fmt.Println(x) // 42
}
```

Тип `*int` читается как «указатель на int». Указатель — самостоятельное значение:
его можно передать в функцию и изменить исходную переменную.

## Нулевое значение — nil

```go
var p *int
fmt.Println(p == nil) // true
// fmt.Println(*p)     // panic: nil pointer dereference
```

Перед разыменованием проверяйте `p != nil`. В отличие от C, арифметики указателей
в Go нет: `p++` не скомпилируется (кроме обхода через `unsafe`, чего избегают).

## Зачем указатели

1. **Изменить данные на месте.** Функция без указателя получает копию.
2. **Не копировать большие структуры.** Указатель фиксированного размера.
3. **«Нет значения».** `nil` в указателе — явный сигнал отсутствия данных.

Указатели на локальные переменные безопасны: сборщик мусора не даст им исчезнуть,
Go сам решает, хранить значение в стеке или куче.

## Частые ошибки

- **Разыменование nil.** Самая частая паника; проверяйте указатель до `*`.
- **Путаница & и *.** `&` — взять адрес, `*` в типе — «указатель на», `*` в
  выражении — «значение по адресу».
- **Ожидание арифметики.** `p + 1` запрещено; индексация срезов — отдельная
  операция.
- **Указатель на переменную цикла.** В Go 1.22+ переменная своя у каждого шага,
  но в старом коде `&v` может дать один адрес на все итерации.

## Практика

**Задание.** Заведите переменную `score := 10`, указатель на неё, увеличьте значение через указатель и напечатайте результат.

**Стартовый код:**

```go
package main

import "fmt"

func main() {
	score := 10
	p := &score
	// увеличьте значение через указатель
	fmt.Println(score, *p)
}
```

**Ожидаемый вывод:**

```text
15 15
```

**Подсказка.** Возьмите `p := &score`, затем `*p = *p + 5`.

**Решение:**

```go
package main

import "fmt"

func main() {
	score := 10
	p := &score
	*p = *p + 5
	fmt.Println(score, *p)
}
```

## Резюме

- `&x` даёт адрес, `*p` читает и записывает значение по адресу.
- Нулевой указатель равен `nil`, разыменование nil паникует.
- Указатели нужны для изменения данных и передачи больших структур без копии.

Посмотрим, что именно происходит с аргументами функции при передаче по значению.
