## Аргументы копируются

Go всегда передаёт аргументы по значению. Функция получает копию, поэтому
присваивание параметру не влияет на переменную вызывающего кода:

```go
package main

import "fmt"

func increase(n int) {
	n++
}

func main() {
	count := 1
	increase(count)
	fmt.Println(count) // 1
}
```

## Копия не всегда «глубокая»

Копируется само значение. Если это срез, копия — заголовок (указатель, длина,
ёмкость) и он смотрит в тот же массив. Map и каналы — ссылочные типы, их копия
указывает на те же данные:

```go
func addItem(items []string) {
	items[0] = "изменено" // видно снаружи: общий массив
	items = append(items, "новый") // не видно: длина копии
}

func put(m map[string]int) {
	m["a"] = 1 // видно снаружи
}
```

Поэтому «передача по значению» не означает «полная изоляция».

## Стоимость копии

Для маленьких типов копия дешева и безопасна. Для большой структуры копия на
каждый вызов — это заметные расходы, поэтому передают `*Struct`. Компилятор
умеет избегать части копий, но полагаться на это в проектировании API не стоит.

## Частые ошибки

- **Ожидание изменения int/bool/string.** Строки неизменяемы, числа копируются.
- **`append` внутри функции.** Новый срез остаётся локальным; чтобы вернуть
  данные, нужно вернуть сам срез.
- **Копия структуры с мьютексом.** Копировать `sync.Mutex` нельзя — вместе с ним
  копируется состояние блокировки; такие структуры передают указателем.

## Практика

**Задание.** Напишите функцию `tryChange(text string)`, которая внутри присваивает параметру новое значение, и убедитесь, что исходная строка не изменилась.

**Стартовый код:**

```go
package main

import "fmt"

func tryChange(text string) {
	// попробуйте изменить параметр
}

func main() {
	text := "исходная"
	tryChange(text)
	fmt.Println(text)
}
```

**Ожидаемый вывод:**

```text
внутри: другая
исходная
```

**Подсказка.** Присвойте `text = "другое"` внутри функции и напечатайте строку после вызова.

**Решение:**

```go
package main

import "fmt"

func tryChange(text string) {
	text = "другая"
	fmt.Println("внутри:", text)
}

func main() {
	text := "исходная"
	tryChange(text)
	fmt.Println(text)
}
```

## Резюме

- Все аргументы передаются по значению: функция работает с копией.
- Срезы, map и каналы копируются как заголовки и делят данные с вызывающим кодом.
- Большие структуры передают указателем, чтобы не копировать их на каждом вызове.

Передача указателя — способ действительно изменить аргумент.
