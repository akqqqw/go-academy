## Метод — функция с получателем

Метод объявляется с дополнительным параметром — получателем (receiver):

```go
package main

import "fmt"

type Rectangle struct {
	Width  float64
	Height float64
}

func (r Rectangle) Area() float64 {
	return r.Width * r.Height
}

func main() {
	box := Rectangle{Width: 3, Height: 4}
	fmt.Println(box.Area())
}
```

Внутри метода работают с `r` как с обычной переменной. При вызове `box.Area()`
компилятор передаёт `box` первым аргументом.

## Получатель по значению

`func (r Rectangle)` получает копию. Изменения полей внутри метода не видны
снаружи:

```go
func (r Rectangle) scaleWrong(f float64) {
	r.Width *= f // меняется копия
}
```

Такие методы подходят для чтения и вычислений, но не для изменения состояния.

## Правила и ограничения

- Метод можно объявить только для типа, определённого в том же пакете. Для
  `int`, `string` и типов из чужих пакетов — нельзя; заведите свой тип:
  `type Celsius float64`.
- Имя метода не должно конфликтовать с полем структуры.
- Метод — обычная функция: его можно вызвать как `Rectangle.Area(box)`.

## Частые ошибки

- **Ожидание изменения при value receiver.** Нужен указательный получатель.
- **Метод на указателе без инициализации.** Вызов метода через nil-указатель на
  структуру сработает, но обращение к полям внутри — паника.
- **Попытка объявить метод на псевдониме чужого пакета.** `type MyTime =
  time.Time` — псевдоним, метод не добавить; только новое определение типа.

## Практика

**Задание.** Добавьте к структуре `Counter` метод `Inc()`, увеличивающий поле `Value` на 1, вызовите его дважды и напечатайте `Value`.

**Стартовый код:**

```go
package main

import "fmt"

type Counter struct {
	Value int
}

func (c Counter) Inc() {
	// увеличьте Value
}

func main() {
	c := Counter{}
	c.Inc()
	c.Inc()
	fmt.Println(c.Value)
}
```

**Ожидаемый вывод:**

```text
2
```

**Подсказка.** Используйте получатель-указатель: `func (c *Counter) Inc() { c.Value++ }`.

**Решение:**

```go
package main

import "fmt"

type Counter struct {
	Value int
}

func (c *Counter) Inc() {
	c.Value++
}

func main() {
	c := Counter{}
	c.Inc()
	c.Inc()
	fmt.Println(c.Value)
}
```

## Резюме

- Метод — функция с получателем, объявленная в том же пакете, что и тип.
- Получатель по значению работает с копией, изменения теряются.
- Методы добавляют только к типам, определённым в своём пакете.

Указательный получатель — основной способ менять состояние структуры.
