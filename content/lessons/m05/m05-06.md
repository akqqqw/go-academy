## Получатель-указатель меняет состояние

```go
package main

import "fmt"

type Account struct {
	Balance int
}

func (a *Account) Deposit(sum int) {
	a.Balance += sum
}

func main() {
	acc := Account{Balance: 100}
	acc.Deposit(50)
	fmt.Println(acc.Balance) // 150
}
```

Компилятор сам берёт адрес: `acc.Deposit(50)` означает `(&acc).Deposit(50)` —
если `acc` адресуема. Для значения из map или результата функции это не всегда
сработает, тогда нужна переменная.

## Когда что выбирать

- **Изменяет состояние** — указатель.
- **Большая структура** — указатель, чтобы не копировать.
- **Маленькое неизменяемое значение** — можно по значению (`time.Time`,
  `Point`).
- **Структура содержит мьютекс** — только указатель.

Если у типа есть хотя бы один указательный метод, разумно делать указательными
и остальные: смешанный набор методов путает.

## Интерфейсы и набор методов

Важно для модуля 6: у типа `T` набор методов — только методы с получателем `T`,
а у `*T` — и `T`, и `*T`. Поэтому если метод объявлен на `*T`, интерфейс
удовлетворяет только `*T`.

```go
type Counter struct{ n int }

func (c *Counter) Inc() { c.n++ }

var c Counter
// var i interface{ Inc() } = c  // ошибка: у Counter нет метода Inc
var i interface{ Inc() } = &c // так можно
_ = i
```

## Частые ошибки

- **Вызов метода значения, не имеющего адреса.** `Map["k"].Inc()` не
  скомпилируется: элемент map не адресуем.
- **Смешение получателей.** Часть методов на `T`, часть на `*T` — легко получить
  несовпадение интерфейса.
- **Копирование структуры с мьютексом.** `go vet` предупредит о `copylocks`.

## Практика

**Задание.** Сделайте так, чтобы метод `Add` структуры `Cart` добавлял позиции в срез, и напечатайте итоговое количество.

**Стартовый код:**

```go
package main

import "fmt"

type Cart struct {
	Items []string
}

func (c *Cart) Add(item string) {
	// добавьте item в срез
}

func main() {
	cart := &Cart{}
	cart.Add("книга")
	cart.Add("ручка")
	fmt.Println(len(cart.Items))
}
```

**Ожидаемый вывод:**

```text
2
```

**Подсказка.** Получатель-указатель `func (c *Cart) Add(item string)` и `c.Items = append(c.Items, item)`.

**Решение:**

```go
package main

import "fmt"

type Cart struct {
	Items []string
}

func (c *Cart) Add(item string) {
	c.Items = append(c.Items, item)
}

func main() {
	cart := &Cart{}
	cart.Add("книга")
	cart.Add("ручка")
	fmt.Println(len(cart.Items))
}
```

## Резюме

- Указательный получатель меняет исходное значение и не копирует структуру.
- Вызов `v.Method()` автоматически берёт адрес, если `v` адресуемо.
- Методы `*T` входят в набор методов `*T`, но не `T` — это важно для интерфейсов.

Встраивание структур позволяет переиспользовать поведение без наследования.
