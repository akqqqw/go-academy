## Своя составная типа

Структура объединяет поля разных типов:

```go
package main

import "fmt"

type Book struct {
	Title  string
	Author string
	Pages  int
}

func main() {
	b := Book{Title: "Язык Go", Pages: 350}
	fmt.Println(b.Title, b.Pages)
	fmt.Printf("%+v\n", b)
}
```

Нулевое значение структуры — структура с нулевыми значениями полей:
`Book{}` даёт пустые строки и `0`.

## Литералы и позиционная запись

`Book{"Язык Go", "Керниган", 350}` работает, но именованные поля читаются лучше и
не ломаются при добавлении поля. Смешивать позиционные и именованные нельзя.

Вложенные структуры:

```go
type Address struct {
	City string
}

type Person struct {
	Name    string
	Address Address // вложенное значение
	Work    *Address // может быть nil
}
```

## Сравнение и копирование

Структура — значение: присваивание копирует все поля. Сравнение `==` допустимо,
только если сравнимы все поля; если внутри срез или map — компилятор откажет, и
нужен `reflect.DeepEqual` или своё сравнение.

## Частые ошибки

- **Забытая запятая в многострочном литерале.** Последнее поле тоже требует `,`.
- **Ожидание ссылки.** `b2 := b1; b2.Pages = 1` не меняет `b1`.
- **Путаница типа и значения.** `var b Book` создаёт готовое значение, `var b
  *Book` — nil-указатель.
- **Неэкспортированные поля и JSON.** Поля со строчной буквы `encoding/json` не
  видит; нужны теги `json:"name"`.

## Практика

**Задание.** Объявите структуру `Point` с полями `X, Y int`, создайте точку `(3, 4)` и напечатайте её и сумму координат.

**Стартовый код:**

```go
package main

import "fmt"

type Point struct {
	X int
	Y int
}

func main() {
	p := Point{} // задайте 3 и 4
	fmt.Printf("%+v %d\n", p, p.X+p.Y)
}
```

**Ожидаемый вывод:**

```text
{X:3 Y:4} 7
```

**Подсказка.** Используйте литерал `Point{X: 3, Y: 4}` и `fmt.Printf("%+v\n", p)`.

**Решение:**

```go
package main

import "fmt"

type Point struct {
	X int
	Y int
}

func main() {
	p := Point{X: 3, Y: 4}
	fmt.Printf("%+v %d\n", p, p.X+p.Y)
}
```

## Резюме

- Структура собирает поля в один тип; нулевое значение — все поля нулевые.
- Именованные поля в литерале надёжнее позиционных.
- Структуры копируются и сравниваются, если все поля сравнимы.

Методы превращают структуру в полноценный объект с поведением.
