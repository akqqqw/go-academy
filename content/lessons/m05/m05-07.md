## Композиция через встраивание

Если указать тип без имени поля, он встраивается. Поля и методы встроенного типа
становятся доступны через внешний:

```go
package main

import "fmt"

type Person struct {
	Name string
}

func (p Person) Greet() string {
	return "Привет, " + p.Name
}

type Employee struct {
	Person // встроенное поле
	Company string
}

func main() {
	e := Employee{Person: Person{Name: "Анна"}, Company: "Go Inc"}
	fmt.Println(e.Greet(), e.Name, e.Company)
}
```

`e.Name` — это сокращение для `e.Person.Name`. У встроенного поля есть имя —
`Person`, поэтому его можно задать явно в литерале.

## Продвижение и переопределение

Метод внешнего типа «перекрывает» одноимённый метод внутреннего. Чтобы вызвать
внутренний, обращаются явно: `e.Person.Greet()`.

Встраивание — не наследование: `Employee` не является `Person`, но если `Person`
реализует интерфейс, то `Employee` тоже его реализует (методы продвигаются).

## Встраивание указателя

```go
type Manager struct {
	*Person
	Reports []string
}
```

Такой вариант позволяет разделять данные между значениями, но добавляет
nil-опасность: если указатель не задан, обращение к полям паникует.

## Частые ошибки

- **Конфликт имён.** Если встроить две структуры с полем `ID`, обращение `x.ID`
  станет ошибкой — нужно указывать через `x.A.ID`.
- **Ожидание полиморфизма.** Переопределённый метод не вызывается «виртуально»
  из методов встроенного типа.
- **Глубокие цепочки встраивания.** Три уровня и больше делают поведение
  неочевидным; предпочитайте явные поля и маленькие интерфейсы.

## Практика

**Задание.** Встройте `Logger` в `Service` и вызовите продвинутый метод `Log` через `Service`, напечатав сообщение.

**Стартовый код:**

```go
package main

import "fmt"

type Logger struct{}

func (Logger) Log(message string) {
	fmt.Println("log:", message)
}

type Service struct {
	Logger
	Name string
}

func main() {
	s := Service{Name: "api"}
	_ = s // вызовите s.Log(s.Name)
}
```

**Ожидаемый вывод:**

```text
log: api
```

**Подсказка.** Встроенное поле объявляется как `Logger` без имени; метод вызывается `s.Log("…")`.

**Решение:**

```go
package main

import "fmt"

type Logger struct{}

func (Logger) Log(message string) {
	fmt.Println("log:", message)
}

type Service struct {
	Logger
	Name string
}

func main() {
	s := Service{Name: "api"}
	s.Log(s.Name)
}
```

## Резюме

- Встраивание добавляет поля и методы внутреннего типа к внешнему.
- Конфликтующие имена требуют явного обращения через встроенное поле.
- Композиция заменяет наследование: собирайте поведение из маленьких типов.
