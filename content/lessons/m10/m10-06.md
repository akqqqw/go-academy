## Проверка причины

Ошибку проверяют по значению или типу, а не по тексту:

```go
package store

import (
	"errors"
	"testing"
)

var ErrNotFound = errors.New("не найдено")

func Find(id int) error {
	if id <= 0 {
		return ErrNotFound
	}
	return nil
}

func TestFind(t *testing.T) {
	err := Find(0)
	if !errors.Is(err, ErrNotFound) {
		t.Fatalf("ожидалась ErrNotFound, получено %v", err)
	}
	if err := Find(1); err != nil {
		t.Fatalf("неожиданная ошибка: %v", err)
	}
}
```

## Проверка типа и полей

Если ошибка несёт данные, используют `errors.As`:

```go
var validation *ValidationError
if !errors.As(err, &validation) {
	t.Fatalf("ожидалась ValidationError, получено %T", err)
}
if validation.Field != "email" {
	t.Errorf("поле = %q, ожидалось email", validation.Field)
}
```

## Табличный вариант

```go
cases := []struct {
	name    string
	id      int
	wantErr error
}{
	{"нет записи", 0, ErrNotFound},
	{"успех", 1, nil},
}
```

Сравнение: `if !errors.Is(gotErr, tc.wantErr)`. Для `nil` проверяйте
`gotErr != nil`.

## Почему не текст

Текст ошибки — часть пользовательского интерфейса и может меняться. Тест на
`err.Error() == "не найдено"` ломается при косметической правке и не проверяет
причину.

## Частые ошибки

- **Сравнение `err == ErrNotFound` для обёрнутой ошибки.** Нужен `errors.Is`.
- **Проверка `err != nil` без причины.** Тест пройдёт при любой ошибке.
- **`errors.As` с неверным указателем.** Требуется `&target`.
- **Забыть проверить успешный путь.** Ошибка может возвращаться всегда.

## Практика

**Задание.** Реализуйте `ParsePositive(text string) (int, error)`, возвращающую `ErrNegative` для отрицательных чисел, и напечатайте `negative` при её получении.

**Стартовый код:**

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

var ErrNegative = errors.New("отрицательное число")

func ParsePositive(text string) (int, error) {
	n, err := strconv.Atoi(text)
	if err != nil {
		return 0, err
	}
	if n < 0 {
		return 0, nil // верните ErrNegative
	}
	return n, nil
}

func main() {
	if _, err := ParsePositive("-5"); errors.Is(err, ErrNegative) {
		fmt.Println("negative")
		return
	}
	fmt.Println("ok")
}
```

**Ожидаемый вывод:**

```text
negative
```

**Подсказка.** Преобразуйте `strconv.Atoi`, проверьте знак и верните сентинел.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
	"strconv"
)

func ParsePositive(text string) (int, error) {

	if err != nil {
		return 0, err
	}
	if n < 0 {
		return 0, ErrNegative
	}
	return n, nil
}

func main() {
	if _, err := ParsePositive("-5"); errors.Is(err, ErrNegative) {

```

## Резюме

- Ошибки в тестах проверяют через `errors.Is` и `errors.As`.
- В таблицах добавляют поле `wantErr` и сравнивают причину.
- Текст ошибки не должен быть контрактом для тестов.
