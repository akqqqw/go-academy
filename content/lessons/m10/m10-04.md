## Функция бенчмарка

```go
package calc

import "testing"

func Concat(parts []string) string {
	out := ""
	for _, part := range parts {
		out += part
	}
	return out
}

func BenchmarkConcat(b *testing.B) {
	parts := []string{"go", "is", "fast"}
	for i := 0; i < b.N; i++ {
		Concat(parts)
	}
}
```

`testing.B` сам подбирает `b.N`, повторяя тело столько раз, сколько нужно для
стабильного замера. Запуск:

```bash
go test -bench=. -benchmem ./calc
```

## Чтение результата

```text
BenchmarkConcat-8    12000000    95.3 ns/op    24 B/op    2 allocs/op
```

- `ns/op` — время на операцию.
- `B/op` — байт на операцию.
- `allocs/op` — число аллокаций.

Сравнивайте одинаковые условия: один и тот же вход, прогретый кеш.

## Правила измерения

- Результат бенчмарка нужно использовать: присвойте в переменную уровня пакета
  или `b.Log`, иначе компилятор может выбросить вызов.
- Тяжёлую подготовку выносите до цикла и вызывайте `b.ResetTimer()`.
- Не используйте `b.N` в подготовке данных.
- Прогоните несколько раз: шум на ноутбуке — норма.

## Частые ошибки

- **Разные данные в сравниваемых бенчмарках.** Нечестное сравнение.
- **Оптимизация без профиля.** Сначала `pprof`, потом правки.
- **Замер с `fmt.Println` внутри.** Основное время уйдёт в вывод.

## Практика

**Задание.** Сравните в практике два способа повторения строки, замерив время через `time.Now()` на 50 000 итераций, и напечатайте, какой способ быстрее (`builder` или `concat`).

**Стартовый код:**

```go
package main

import (
	"fmt"
	"strings"
	"time"
)

func main() {
	const n = 50000
	start := time.Now()
	var b strings.Builder
	for i := 0; i < n; i++ {
		b.WriteString("x")
	}
	builderTime := time.Since(start)

	start = time.Now()
	out := ""
	for i := 0; i < n; i++ {
		out += "x"
	}
	concatTime := time.Since(start)
	_ = out

	// сравните время и напечатайте победителя
	fmt.Println(builderTime, concatTime)
}
```

**Ожидаемый вывод:**

```text
builder
```

**Подсказка.** Замерьте `strings.Builder` и конкатенацию `+=`, сравните `time.Since` и напечатайте `builder`, если он быстрее.

**Решение:**

```go
package main

import (
	"fmt"
	"strings"
	"time"
)

func main() {
	const n = 50000
	start := time.Now()
	var b strings.Builder
	for i := 0; i < n; i++ {
		b.WriteString("x")
	}
	builderTime := time.Since(start)

	start = time.Now()
	out := ""
	for i := 0; i < n; i++ {
		out += "x"
	}
	concatTime := time.Since(start)
	_ = out

	if builderTime < concatTime {
		fmt.Println("builder")
		return
	}
	fmt.Println("concat")
}
```
