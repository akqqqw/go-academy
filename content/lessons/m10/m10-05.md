## Запуск

```bash
go test -cover ./...
go test -coverprofile=cover.out ./...
go tool cover -html=cover.out -o cover.html
```

`go test -cover` печатает процент выполненных строк. Профиль позволяет увидеть,
какие именно ветки не проверялись.

## Как читать

- Покрытие считает **выполненные операторы**, а не проверенные сценарии.
- 100% не значит «нет багов»: тесты могут вызывать код и не проверять результат.
- Низкое покрытие в критичных пакетах — сигнал, в декоративных — не приговор.

Практический ориентир: новые функции бизнес-логики — с тестами; 60–80% на пакет
обычно разумно, но цель не цифра, а защита от регрессий.

## Полезные приёмы

```bash
go test -coverpkg=./... -coverprofile=cover.out ./...
go test -cover ./... | grep -v "no test files"
```

`-coverpkg` учитывает пакеты, вызванные из тестов. Для CI удобно публиковать
профиль артефактом.

## Что покрывать в первую очередь

1. Крайние случаи: пусто, ноль, nil, максимум.
2. Ветки ошибок и обработку `err != nil`.
3. Публичный API, а не геттеры.

## Частые ошибки

- **Гнаться за 100%.** Тесты ради цифры ломают рефакторинг.
- **Проверять только успешный путь.** Ошибки чаще ломаются именно в ветках.
- **Коммитить `cover.out`.** Это артефакт, его место в CI.

## Практика

**Задание.** Посчитайте «покрытие» вручную: функция `Kind(n int) string` возвращает `negative`, `zero` или `positive`; проверьте все три случая и напечатайте число пройденных.

**Стартовый код:**

```go
package main

import "fmt"

func Kind(n int) string {
	switch {
	case n < 0:
		return "negative"
	case n == 0:
		return "zero"
	default:
		return "positive"
	}
}

func main() {
	cases := map[int]string{-5: "negative", 0: "zero", 5: "positive"}
	passed := 0
	for range cases {
		// проверьте случай и увеличьте passed
	}
	fmt.Println(passed)
}
```

**Ожидаемый вывод:**

```text
3
```

**Подсказка.** Вызовите функцию с `-5`, `0`, `5` и сравните со ожидаемыми строками.

**Решение:**

```go
package main

import "fmt"

func Kind(n int) string {
	switch {
	case n < 0:
		return "negative"
	case n == 0:
		return "zero"
	default:
		return "positive"
	}
}

func main() {
	cases := map[int]string{-5: "negative", 0: "zero", 5: "positive"}
	passed := 0
	for n, want := range cases {
		if Kind(n) == want {
			passed++
		}
	}
	fmt.Println(passed)
}
```

## Резюме

- `go test -cover` и `-coverprofile` показывают покрытие строк.
- 100% покрытия не гарантирует корректность проверок.
- В первую очередь покрывайте крайние случаи и ветки ошибок.

Тестирование ошибок: `errors.Is`, `errors.As` и проверка текста.
