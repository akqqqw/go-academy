## Тестовый файл

Тесты живут рядом с кодом в файлах `*_test.go` и в том же пакете. Функция теста
начинается с `Test`, принимает `*testing.T`:

```go
package calc

import "testing"

func Add(a, b int) int { return a + b }

func TestAdd(t *testing.T) {
	if got := Add(1, 2); got != 3 {
		t.Fatalf("Add(1, 2) = %d, ожидалось 3", got)
	}
}
```

Запуск: `go test ./...`. Файлы `_test.go` не попадают в обычную сборку, поэтому
тестовый код не тянет зависимости в бинарник.

## Сообщения об ошибках

- `t.Errorf` — тест продолжается, помечается провал.
- `t.Fatalf` — тест немедленно останавливается (удобно, чтобы не паниковать
  дальше).
- `t.Log`, `t.Logf` — вывод только при провале или с `-v`.

Хорошее сообщение содержит входные данные и фактический результат:
`Add(1, 2) = 5, ожидалось 3`.

## Полезные флаги

```bash
go test ./...              # все пакеты
go test -run TestAdd ./calc
go test -v ./...
go test -count=1 ./...     # без кеша
```

`-run` принимает регулярное выражение. `-short` позволяет пропустить долгие
тесты через `testing.Short()`.

## Частые ошибки

- **Файл без `_test.go`.** Тест попадёт в сборку и не запустится.
- **`func TestAdd()` без `*testing.T`.** Go не считает это тестом.
- **Проверка через `t.Log` вместо провала.** Тест «зелёный», хотя значение
  неверное.
- **Зависимость тестов от порядка запуска.** Каждый тест должен быть независим.

## Практика

**Задание.** Напишите функцию `Mul(a, b int) int` и в `main` проверьте её так, как это сделал бы тест: при неверном значении напечатайте `FAIL`, иначе `OK`.

**Стартовый код:**

```go
package main

import "fmt"

func Mul(a, b int) int {
	return 0 // умножьте
}

func main() {
	if got := Mul(3, 4); got != 12 {
		fmt.Println("FAIL:", got)
		return
	}
	fmt.Println("OK")
}
```

**Ожидаемый вывод:**

```text
OK
```

**Подсказка.** Сравните `Mul(3, 4)` с 12 и выберите сообщение.

**Решение:**

```go
package main

import "fmt"

func Mul(a, b int) int {
	return a * b
}

func main() {
	if got := Mul(3, 4); got != 12 {
		fmt.Println("FAIL:", got)
		return
	}
	fmt.Println("OK")
}
```

## Резюме

- Тесты лежат в `*_test.go` и принимают `*testing.T`.
- `Errorf` продолжает тест, `Fatalf` останавливает.
- `go test ./...`, `-run` и `-v` — повседневные команды.

Unit-тесты: изоляция, хелперы и `t.Run`.
