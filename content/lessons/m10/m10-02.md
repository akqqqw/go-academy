## Изоляция

Хороший unit-тест проверяет маленькую функцию и не зависит от сети, времени и
файлов вне `t.TempDir()`. Внешние зависимости подменяют интерфейсами.

```go
package calc

import (
	"errors"
	"testing"
)

func Divide(a, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("деление на ноль")
	}
	return a / b, nil
}

func TestDivide(t *testing.T) {
	if _, err := Divide(1, 0); err == nil {
		t.Fatal("ожидалась ошибка при делении на ноль")
	}
}
```

## Подтесты

`t.Run` даёт отдельное имя и изоляцию: провал одного не мешает остальным.

```go
func TestDivideOK(t *testing.T) {
	t.Run("положительные", func(t *testing.T) {
		if got, err := Divide(10, 2); err != nil || got != 5 {
			t.Fatalf("got = %d, err = %v", got, err)
		}
	})
	t.Run("отрицательные", func(t *testing.T) {
		if got, _ := Divide(-10, 2); got != -5 {
			t.Fatalf("got = %d", got)
		}
	})
}
```

## Хелперы и временные каталоги

- `t.Helper()` отмечает функцию как хелпер: в отчёте будет строка вызова теста, а
  не внутренности.
- `t.TempDir()` создаёт каталог, который удалится автоматически.
- `t.Cleanup(fn)` регистрирует уборку.

```go
func writeTemp(t *testing.T, name, data string) string {
	t.Helper()
	path := t.TempDir() + "/" + name
	if err := os.WriteFile(path, []byte(data), 0o600); err != nil {
		t.Fatal(err)
	}
	return path
}
```

## Частые ошибки

- **Общий изменяемый стейт между тестами.** Порядок запуска не гарантирован.
- **`time.Sleep` вместо синхронизации.** Тест становится медленным и хрупким.
- **Игнорирование `t.Helper()`.** Провал указывает не туда.
- **Хардкод `/tmp`.** Используйте `t.TempDir()`.

## Практика

**Задание.** Реализуйте `Max(a, b int) int` и проверьте в `main` два случая: `Max(3, 7)` и `Max(9, 2)`, напечатав оба результата.

**Стартовый код:**

```go
package main

import "fmt"

func Max(a, b int) int {
	return 0 // верните большее
}

func main() {
	fmt.Println(Max(3, 7), Max(9, 2))
}
```

**Ожидаемый вывод:**

```text
7 9
```

**Подсказка.** Сравните числа и верните большее.

**Решение:**

```go
package main

import "fmt"

func Max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(Max(3, 7), Max(9, 2))
}
```

## Резюме

- Unit-тест проверяет одну функцию и не зависит от окружения.
- `t.Run` группирует подтесты, `t.Helper` улучшает отчёты.
- `t.TempDir` и `t.Cleanup` убирают за тестом автоматически.

Table-driven tests — стандарт для проверки многих случаев.
