## Функция как значение

Функцию можно объявить без имени прямо в выражении. Такие литералы — обычные
значения: их присваивают переменным, передают в аргументы и возвращают:

```go
package main

import "fmt"

func main() {
	double := func(n int) int { return n * 2 }
	fmt.Println(double(21))

	fmt.Println(func(a, b int) int { return a * b }(6, 7))
}
```

Второй вызов — немедленный: литерал вызван сразу после закрывающей скобки.

## Замыкания

Анонимная функция захватывает переменные из окружающей области. Захватывается
сама переменная, а не её копия:

```go
func counter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}

func main() {
	c := counter()
	fmt.Println(c(), c(), c()) // 1 2 3
}
```

`count` живёт до тех пор, пока на неё ссылается возвращённое замыкание. Это
удобный способ спрятать состояние без структуры.

## Функции как параметры

Тип функции записывается как её сигнатура: `func(int) int`. На этом строится
`sort.Slice`, `http.HandlerFunc` и middleware:

```go
func apply(values []int, f func(int) int) []int {
	out := make([]int, len(values))
	for i, v := range values {
		out[i] = f(v)
	}
	return out
}
```

## Частые ошибки

- **Замыкание в цикле.** В Go 1.22+ переменная цикла у каждого шага своя, но код
  с ручным `i := i` всё ещё встречается; проверяйте версию и смысл.
- **Гонка данных.** Если замыкание меняет общую переменную из нескольких
  горутин, нужен `sync.Mutex` или канал (модуль 11).
- **Утечка памяти.** Долгоживущее замыкание удерживает всё, на что ссылается.
- **Ожидание рекурсии.** Литерал нельзя вызвать до объявления: `var f func()`
  нужен, если функция ссылается на себя.

## Практика

**Задание.** Реализуйте функцию `counter() func() int`, которая возвращает замыкание: каждый вызов увеличивает счётчик на 1, и напечатайте три вызова.

**Стартовый код:**

```go
package main

import "fmt"

func counter() func() int {
	count := 0
	return func() int {
		return count // увеличивайте count на каждом вызове
	}
}

func main() {
	next := counter()
	fmt.Println(next(), next(), next())
}
```

**Ожидаемый вывод:**

```text
1 2 3
```

**Подсказка.** Заведите `count := 0` перед `return func() int { ... }` и увеличивайте её внутри.

**Решение:**

```go
package main

import "fmt"

func counter() func() int {
	count := 0
	return func() int {
		count++
		return count
	}
}

func main() {
	next := counter()
	fmt.Println(next(), next(), next())
}
```

## Резюме

- Функциональные литералы — значения: их можно присваивать, передавать и вызывать сразу.
- Замыкание захватывает переменные окружения и хранит состояние между вызовами.
- Тип функции описывается сигнатурой, что делает возможными колбэки и middleware.
