## Позиционные параметры

Параметры передаются по позиции, по имени их указывать нельзя. Если у нескольких
параметров один тип, его пишут один раз:

```go
package main

import "fmt"

func area(width, height float64) float64 {
	return width * height
}

func main() {
	fmt.Println(area(3, 4.5))
}
```

`width, height float64` — сокращение для `width float64, height float64`. Типы
можно смешивать: `func label(name string, count int)`.

## Значений по умолчанию нет

В Go нет ни значений по умолчанию, ни именованных аргументов. Если нужен
необязательный параметр, идиома такая: передать ноль и обработать его, либо
передать функцию-опцию, либо завести несколько функций с понятными именами:

```go
func repeat(text string, times int) string {
	if times <= 0 {
		times = 1 // «значение по умолчанию» выставляем руками
	}
	out := ""
	for i := 0; i < times; i++ {
		out += text
	}
	return out
}
```

Такой приём называется «договорённость о нулевом значении»: `0`, `""`, `nil` и
`false` — валидные значения по умолчанию для своих типов.

## Параметры копируются

Аргументы передаются по значению: функция получает копию. Изменение параметра
внутри функции не затрагивает переменную вызывающего кода. Для структур это
особенно заметно — чтобы менять поле, нужен указатель (модуль 5).

```go
func double(n int) {
	n *= 2 // меняется только локальная копия
}
```

## Частые ошибки

- **Ожидание именованных аргументов.** Вызов `area(height: 2, width: 3)` не
  скомпилируется: порядок аргументов задаёт смысл.
- **Забытый тип в середине списка.** `func f(a int, b)` — ошибка; тип нужен
  каждому параметру или группе.
- **Путаница среза и массива.** Срез передаётся по значению, но указывает на тот
  же массив, поэтому изменения элементов видны снаружи.

## Практика

**Задание.** Напишите функцию `repeat(text string, times int) string`, которая повторяет строку `times` раз, а при `times <= 0` возвращает строку один раз.

**Стартовый код:**

```go
package main

import "fmt"

func repeat(text string, times int) string {
	return "" // реализуйте повторение
}

func main() {
	fmt.Println(repeat("go", 3))
	fmt.Println(repeat("go", 0))
}
```

**Ожидаемый вывод:**

```text
gogogo
go
```

**Подсказка.** Соберите результат циклом `for i := 0; i < times; i++` или используйте `strings.Repeat`.

**Решение:**

```go
package main

import (
	"fmt"
	"strings"
)

func repeat(text string, times int) string {
	if times <= 0 {
		times = 1
	}
	return strings.Repeat(text, times)
}

func main() {
	fmt.Println(repeat("go", 3))
	fmt.Println(repeat("go", 0))
}
```

## Резюме

- Параметры позиционные, типы можно группировать: `a, b int`.
- Значений по умолчанию и именованных аргументов нет — используйте нулевое значение или опции.
- Аргументы копируются, поэтому для изменения данных нужен указатель или срез.
