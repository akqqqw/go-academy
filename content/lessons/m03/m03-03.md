## Одно значение

Тип результата пишется после списка параметров. Функция без результата просто не
указывает тип:

```go
package main

import "fmt"

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}

func main() {
	fmt.Println(abs(5))
}
```

Ключевое слово `return` завершает функцию немедленно, поэтому всё, что написано
после него, недостижимо и не компилируется.

## Ранний возврат вместо вложенности

Вместо глубокой вложенности `if` в Go принято выходить из функции как можно
раньше:

```go
func clamp(value, low, high int) int {
	if value < low {
		return low
	}
	if value > high {
		return high
	}
	return value
}
```

После каждого `if` сценарий закрыт, и основная логика остаётся на одном уровне
отступа. Это правило часто называют «guard clauses».

## Один результат — один смысл

Если функция возвращает `bool`, её имя обычно читается как вопрос:
`isValid`, `hasPrefix`. Если функция возвращает значение и ошибку — это уже два
результата, им посвящён следующий урок. Функция, которая «иногда возвращает
результат, иногда ничего», в Go не выражается: нужно либо два результата, либо
ошибка.

## Частые ошибки

- **Код после return.** Компилятор скажет `missing return` или
  `unreachable code`, если ветки расходятся.
- **Забытая ветка.** Если тип результата указан, все пути выполнения должны
  что-то вернуть.
- **Игнорирование результата.** Строка `abs(5)` без использования — ошибка
  компиляции; результат нужно напечатать, присвоить или вернуть.

## Практика

**Задание.** Реализуйте функцию `clamp(value, low, high int) int`, которая ограничивает число диапазоном, и напечатайте `clamp(15, 0, 10)`.

**Стартовый код:**

```go
package main

import "fmt"

func clamp(value, low, high int) int {
	return 0 // реализуйте ограничение диапазоном
}

func main() {
	fmt.Println(clamp(15, 0, 10))
	fmt.Println(clamp(-3, 0, 10))
}
```

**Ожидаемый вывод:**

```text
10
0
```

**Подсказка.** Сначала проверьте нижнюю границу, потом верхнюю, в конце верните исходное значение.

**Решение:**

```go
package main

import "fmt"

func clamp(value, low, high int) int {
	if value < low {
		return low
	}
	if value > high {
		return high
	}
	return value
}

func main() {
	fmt.Println(clamp(15, 0, 10))
	fmt.Println(clamp(-3, 0, 10))
}
```

## Резюме

- Тип результата указывается после параметров, `return` завершает функцию.
- Ранние возвраты убирают вложенность и делают основную логику плоской.
- Все ветки функции с результатом должны возвращать значение нужного типа.

Следующий шаг — несколько результатов: идиома `value, err`, знакомая по стандартной библиотеке.
