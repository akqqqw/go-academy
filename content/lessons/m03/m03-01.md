## Функция — именованный блок кода

Функция объявляется ключевым словом `func`, затем идут имя, список параметров
(имя и тип каждого), необязательный список результатов и тело в фигурных скобках:

```go
package main

import "fmt"

func greet(name string) string {
	return "Привет, " + name
}

func main() {
	fmt.Println(greet("Мир"))
}
```

Сигнатура здесь — `func greet(name string) string`: на входе строка, на выходе
строка. `main` ничего не принимает и ничего не возвращает, поэтому у неё пустые
скобки и нет типа результата.

## Порядок объявления не важен

Go компилирует пакет целиком, а не построчно, поэтому функцию можно вызвать
раньше того места, где она описана:

```go
package main

import "fmt"

func main() {
	printSum(2, 3)
}

func printSum(a, b int) {
	fmt.Println(a + b)
}
```

Такой код компилируется и печатает `5`. Ограничение появляется только между
пакетами: импортировать можно лишь то, что объявлено в другом пакете.

## Имена и видимость

- Имя с заглавной буквы (`Greet`) экспортируется: функция доступна из других
  пакетов.
- Имя со строчной (`greet`) видна только внутри своего пакета.
- В Go нет перегрузки функций: `Sum(a, b int)` и `Sum(a, b, c int)` в одном
  пакете невозможны.
- Параметры и локальные переменные видны только внутри тела функции и вложенных
  блоков.

## Частые ошибки

- **Перегрузка.** `func f(a int)` и `func f(a, b int)` — ошибка
  `f redeclared in this block`. Нужны разные имена.
- **Забытый тип.** `func f(a, b)` не скомпилируется: у каждого параметра должен
  быть тип (кроме сгруппированных `a, b int`).
- **Лишний результат.** Если функция возвращает значение, его нужно использовать
  или вернуть дальше; «висящий» результат компилятор не пропустит.
- **Путаница имени и вызова.** `greet` — значение функции, `greet("Мир")` — её
  вызов.

## Практика

**Задание.** Напишите функцию `square(n int) int`, возвращающую квадрат числа, и напечатайте `square(7)`.

**Стартовый код:**

```go
package main

import "fmt"

func square(n int) int {
	return 0 // верните n * n
}

func main() {
	fmt.Println(square(7))
}
```

**Ожидаемый вывод:**

```text
49
```

**Подсказка.** Верните `n * n` из функции и вызовите её внутри `main`.

**Решение:**

```go
package main

import "fmt"

func square(n int) int {
	return n * n
}

func main() {
	fmt.Println(square(7))
}
```

## Резюме

- Функция объявляется через `func`, параметры и результаты указываются с типами.
- Порядок объявления внутри пакета не важен, между пакетами нужен импорт.
- Заглавная буква в имени делает функцию экспортируемой, перегрузки нет.

Дальше разберём параметры: группировку типов, передачу по значению и отсутствие значений по умолчанию.
