## Два результата в сигнатуре

Go не бросает исключения, поэтому ошибку возвращают явно — обычно последним
результатом:

```go
package main

import (
	"errors"
	"fmt"
)

func divide(a, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("деление на ноль")
	}
	return a / b, nil
}

func main() {
	result, err := divide(10, 2)
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(result)
}
```

Порядок важен: **значение, потом ошибка**. Тип ошибки — интерфейс `error`,
которому посвящён модуль 7.

## Проверяйте ошибку сразу

Идиома Go: вызов и проверка стоят рядом, ошибка не «путешествует» в переменной:

```go
value, err := divide(10, 0)
if err != nil {
	fmt.Println("не удалось:", err)
	return
}
```

Если ошибку проигнорировать через `_`, статический анализатор `go vet` иногда
предупредит, но компилятор — нет. Игнорируйте осознанно и с комментарием.

## Несколько однотипных результатов

Функция может вернуть и пару значений без ошибки, например поменять местами:

```go
func swap(a, b string) (string, string) {
	return b, a
}
```

Принимают их так: `x, y := swap("a", "b")`. Если одно значение не нужно,
используйте `_`: `first, _ := swap("a", "b")`.

## Частые ошибки

- **Вернуть `nil` вместо значения.** `return nil, nil` не скомпилируется для
  `int`: нужен `0`.
- **Сравнивать ошибку с нулём.** `if err` — ошибка; проверяют `if err != nil`.
- **Терять ошибку.** `result, _ := divide(1, 0)` даст `0` и скроет проблему.
- **Путать порядок.** Если вернуть `(error, int)`, код станет нечитаемым: держите
  ошибку последней.

## Практика

**Задание.** Реализуйте `divide(a, b int) (int, error)`, которая возвращает ошибку `errors.New("деление на ноль")` при `b == 0`, и обработайте её в `main` для `divide(10, 0)`.

**Стартовый код:**

```go
package main

import "fmt"

func divide(a, b int) (int, error) {
	return 0, nil // добавьте проверку деления на ноль через errors.New
}

func main() {
	result, err := divide(10, 0)
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(result)
}
```

**Ожидаемый вывод:**

```text
ошибка: деление на ноль
```

**Подсказка.** Проверьте делитель в начале функции и верните `0, errors.New(...)`.

**Решение:**

```go
package main

import (
	"errors"
	"fmt"
)

func divide(a, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("деление на ноль")
	}
	return a / b, nil
}

func main() {
	result, err := divide(10, 0)
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Println(result)
}
```

## Резюме

- Ошибка возвращается последним результатом: `(значение, error)`.
- Проверка `if err != nil` стоит сразу после вызова.
- Ненужные результаты отбрасываются через `_`, но ошибку лучше не терять.

Именованные результаты позволяют возвращать значения без явных аргументов `return` — и иногда это полезно.
