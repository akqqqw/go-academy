## Произвольное число аргументов

Многоточие перед типом делает параметр вариадическим. Внутри функции он — срез:

```go
package main

import "fmt"

func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum(1, 2, 3))
	fmt.Println(sum())
}
```

`sum()` корректно вернёт `0`: `nums` в этом случае — пустой срез, а не `nil`
проблема.

## Срез как набор аргументов

Если данные уже лежат в срезе, их передают с `...`:

```go
values := []int{4, 8, 15}
fmt.Println(sum(values...))
```

Без многоточия компилятор скажет: `cannot use values (variable of type []int) as
int value in argument`.

## Правила размещения

Вариадический параметр может быть только один и только последним:

```go
func join(sep string, parts ...string) string {
	out := ""
	for i, p := range parts {
		if i > 0 {
			out += sep
		}
		out += p
	}
	return out
}
```

Именно так устроены `fmt.Println`, `strings.Join` (там параметр обычный срез) и
`append` (там вариадический `...T`).

## Частые ошибки

- **Вариадический параметр не последний.** `func f(nums ...int, name string)` не
  компилируется.
- **Ожидание `nil`.** Пустой вызов даёт пустой срез: `len(nums) == 0`.
- **Изменение среза на месте.** `nums` — обычный срез, его элементы можно менять,
  и это увидят вызвавшие, если передавали свой срез.
- **Забытое многоточие при передаче среза.** Самая частая ошибка при работе с
  `fmt.Errorf` и собственными функциями.

## Практика

**Задание.** Реализуйте `join(sep string, parts ...string) string`, соединяющую части через разделитель, и напечатайте результат для `join("-", "go", "is", "fun")`.

**Стартовый код:**

```go
package main

import "fmt"

func join(sep string, parts ...string) string {
	return "" // соедините части через sep
}

func main() {
	fmt.Println(join("-", "go", "is", "fun"))
}
```

**Ожидаемый вывод:**

```text
go-is-fun
```

**Подсказка.** Собирайте строку в цикле, добавляя разделитель перед всеми частями, кроме первой.

**Решение:**

```go
package main

import "fmt"

func join(sep string, parts ...string) string {
	out := ""
	for i, p := range parts {
		if i > 0 {
			out += sep
		}
		out += p
	}
	return out
}

func main() {
	fmt.Println(join("-", "go", "is", "fun"))
}
```

## Резюме

- `...T` принимает произвольное число аргументов и внутри является срезом.
- Срез передаётся как аргументы с многоточием: `f(values...)`.
- Вариадический параметр один и стоит последним.

Функция может вызывать саму себя — переходим к рекурсии и базовому случаю.
