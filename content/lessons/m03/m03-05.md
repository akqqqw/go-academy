## Результаты можно назвать

В списке результатов допустимы имена. Они ведут себя как переменные, объявленные
в начале функции и инициализированные нулевыми значениями:

```go
package main

import "fmt"

func split(sum int) (x, y int) {
	x = sum / 2
	y = sum - x
	return
}

func main() {
	fmt.Println(split(10))
}
```

`return` без аргументов («naked return») возвращает текущие значения `x` и `y`.
Результат — `5 5`.

## Когда это действительно полезно

1. **Документация сигнатуры.** `func parse(s string) (value int, err error)`
   сразу говорит, что именно вернётся.
2. **`defer` изменяет результат.** Отложенная функция может поменять именованный
   результат перед самым выходом:

```go
func withDefault(text string) (result string) {
	defer func() {
		if result == "" {
			result = "по умолчанию"
		}
	}()
	return text
}
```

3. **Несколько однотипных результатов.** `(min, max int)` читается лучше, чем
   `(int, int)`.

## Когда лучше явно

В коротких функциях именованные результаты только добавляют шум: `return a + b`
понятнее, чем присваивание и пустой `return`. Главный риск — затенение:

```go
func total(values []int) (sum int) {
	for _, v := range values {
		sum := sum + v // новая переменная, результат останется нулём
		_ = sum
	}
	return
}
```

`:=` создаёт новую переменную внутри цикла, внешняя `sum` не меняется. Внутри
функции с именованным результатом используйте `=` для присваивания.

## Частые ошибки

- **Naked return в длинной функции.** Читатель не помнит, что там возвращается;
  пишите `return x, y` явно.
- **Затенение через `:=`.** Приводит к нулевому результату без ошибки компиляции.
- **Имена результатов в интерфейсе.** В объявлении метода интерфейса имена можно
  не повторять — они не влияют на совместимость.

## Практика

**Задание.** Реализуйте функцию `minMax(values []int) (min, max int)` с именованными результатами и напечатайте её результат для `[]int{3, 9, 2}`.

**Стартовый код:**

```go
package main

import "fmt"

func minMax(values []int) (min, max int) {
	return 0, 0 // найдите минимум и максимум
}

func main() {
	min, max := minMax([]int{3, 9, 2})
	fmt.Println(min, max)
}
```

**Ожидаемый вывод:**

```text
2 9
```

**Подсказка.** Начните с `min, max = values[0], values[0]` и обновите значения в цикле.

**Решение:**

```go
package main

import "fmt"

func minMax(values []int) (min, max int) {
	min, max = values[0], values[0]
	for _, v := range values[1:] {
		if v < min {
			min = v
		}
		if v > max {
			max = v
		}
	}
	return
}

func main() {
	min, max := minMax([]int{3, 9, 2})
	fmt.Println(min, max)
}
```

## Резюме

- Именованные результаты — переменные функции с нулевыми значениями.
- `return` без аргументов возвращает их текущие значения.
- Именование полезно для читаемости и `defer`, но требует аккуратности с `:=`.

Часть функций принимает произвольное число аргументов — разберём `...T`.
