## Функция, вызывающая себя

Рекурсия — приём, когда функция решает задачу через себя же на меньших данных.
Обязательны две части: **базовый случай** (когда ответ известен) и **шаг**
(сведение к меньшей задаче):

```go
package main

import "fmt"

func factorial(n int) int {
	if n <= 1 {
		return 1
	}
	return n * factorial(n-1)
}

func main() {
	fmt.Println(factorial(5))
}
```

Вызов `factorial(5)` разворачивается в `5 * 4 * 3 * 2 * 1`. Базовый случай
`n <= 1` не даёт рекурсии уйти в бесконечность.

## Стек вызовов

Каждый вызов занимает кадр стека: сохраняются аргументы и точка возврата. Go
умеет растить стек (growable stack), но глубина всё равно ограничена. Рекурсия по
срезу длиной миллион — плохая идея; цикл надёжнее.

```go
func countDown(n int) {
	if n == 0 {
		return
	}
	fmt.Println(n)
	countDown(n - 1)
}
```

## Рекурсия или цикл

- Деревья, вложенные структуры, обход файловой системы — рекурсия естественна.
- Линейные проходы по срезу, счётчики, суммы — цикл короче и дешевле.
- Если рекурсивная функция считает одно и то же много раз (наивный Фибоначчи),
  нужна мемоизация: кеш `map[int]int` или итеративный вариант.

## Частые ошибки

- **Нет базового случая.** `fatal error: stack overflow`, программа падает.
- **Базовый случай недостижим.** Например, `n-1` при отрицательном `n`.
- **Лишняя работа.** `fib(n-1) + fib(n-2)` без кеша даёт экспоненциальное время.
- **Огромная глубина.** Рекурсия по 10⁶ элементам расходует память; используйте
  цикл или явный стек.

## Практика

**Задание.** Напишите рекурсивную функцию `power(base, exp int) int`, возводящую число в неотрицательную степень, и напечатайте `power(2, 10)`.

**Стартовый код:**

```go
package main

import "fmt"

func power(base, exp int) int {
	return 0 // реализуйте рекурсию
}

func main() {
	fmt.Println(power(2, 10))
}
```

**Ожидаемый вывод:**

```text
1024
```

**Подсказка.** Базовый случай — `exp == 0` (результат 1), шаг — `base * power(base, exp-1)`.

**Решение:**

```go
package main

import "fmt"

func power(base, exp int) int {
	if exp == 0 {
		return 1
	}
	return base * power(base, exp-1)
}

func main() {
	fmt.Println(power(2, 10))
}
```

## Резюме

- Рекурсия требует базового случая и шага к нему.
- Глубина рекурсии ограничена памятью под стек вызовов.
- Для линейных проходов цикл проще, для деревьев рекурсия естественнее.
