## Арифметические операторы

```go
a, b := 7, 3

fmt.Println(a + b) // 10
fmt.Println(a - b) // 4
fmt.Println(a * b) // 21
fmt.Println(a / b) // 2 — целочисленное деление
fmt.Println(a % b) // 1 — остаток
```

Оператор `%` работает только с целыми. Для дробных остаток получают через
`math.Mod`.

Инкремент и декремент — только как операторы, не выражения:

```go
count := 0
count++      // можно
count--      // можно
// x := count++ // ошибка: count++ не значение
```

## Присваивание с операцией

```go
total := 10
total += 5   // 15
total -= 3   // 12
total *= 2   // 24
total /= 4   // 6
total %= 4   // 2
total <<= 1  // 4
```

Полезно для накопителей: `sum += value`, `count++`.

## Сравнение

```go
fmt.Println(3 == 3)   // true
fmt.Println(3 != 4)   // true
fmt.Println(3 > 2)    // true
fmt.Println("a" < "b") // true — лексикографически
```

Результат сравнения — `bool`. Сравнивать можно только совместимые типы. Срезы и
map сравнивать нельзя.

Разница между `=` и `==` принципиальна:

```go
x := 5   // присваивание
x == 5   // сравнение, результат bool
```

## Логические операторы

```go
ready := true
loaded := false

fmt.Println(ready && loaded) // false — «и»
fmt.Println(ready || loaded) // true  — «или»
fmt.Println(!ready)          // false — «не»
```

`&&` и `||` **ленивые**: правая часть не вычисляется, если результат уже известен.

```go
if user != nil && user.Active {
	// user.Active не будет вызван, если user == nil
}
```

Это распространённая защита от паники.

## Побитовые операторы

Работают с целыми на уровне битов:

| Оператор | Смысл | Пример |
| --- | --- | --- |
| `&` | и | `0b1100 & 0b1010 = 0b1000` |
| `\|` | или | `0b1100 \| 0b0011 = 0b1111` |
| `^` | исключающее или | `0b1100 ^ 0b1010 = 0b0110` |
| `&^` | сброс битов | `a &^ b` |
| `<<` | сдвиг влево | `1 << 3 = 8` |
| `>>` | сдвиг вправо | `8 >> 2 = 2` |

Флаги:

```go
const (
	Read   = 1 << 0 // 1
	Write  = 1 << 1 // 2
	Delete = 1 << 2 // 4
)

perms := Read | Write        // 3
fmt.Println(perms&Write != 0) // true: право есть
perms &^= Write               // снимаем право записи
fmt.Println(perms)            // 1
```

Двоичные литералы (`0b1010`) и шестнадцатеричные (`0xFF`) поддерживаются, как и
подчёркивания для читаемости (`0b1010_1010`).

## Приоритет

От высокого к низкому:

1. `*  /  %  <<  >>  &  &^`
2. `+  -  |  ^`
3. `==  !=  <  <=  >  >=`
4. `&&`
5. `||`

Скобки всегда допустимы и часто полезны: `(a + b) * c`. Не полагайтесь на память —
если сомневаетесь, поставьте скобки.

Обратите внимание: в Go **нет** оператора `?:` (тернарного). Вместо него пишут
`if` или функцию-хелпер.

## Частые ошибки

- **`count++` как значение.** Нельзя присвоить или передать в функцию.
- **Целочисленное деление.** `1 / 2` равно `0`.
- **Деление на ноль.** Для целых это паника `integer divide by zero`, для
  `float64` — `+Inf`.
- **`=` вместо `==`.** Компилятор поймает в условии, но в сложных выражениях
  легко ошибиться.
- **`&&` и `||` с числами.** В Go нет неявного приведения к `bool`.
- **Ожидание переполнения без последствий.** Целочисленное переполнение в Go
  молча «заворачивается».
- **`^` как степень.** Это побитовое исключающее или. Степень — `math.Pow`.

## Практика

**Задание.** Даны права пользователя: `Read | Write`. Напечатайте число прав,
проверьте наличие права `Delete` и добавьте его, затем выведите итоговое число.
Используйте константы-флаги.

**Стартовый код:**

```go
package main

const (
	Read  = 1 << iota // 1
	Write             // 2
	Delete            // 4
)

func main() {
	perms := Read | Write
	// выведите текущие права, проверку Delete и итог
	// fmt.Println("Права:", perms)
	// добавьте импорт "fmt"
	_ = perms
}
```

**Ожидаемый вывод:**

```text
Права: 3
Delete есть: false
После добавления: 7
```

**Подсказка.** Проверка — `perms&Delete != 0`, добавление — `perms |= Delete`.

**Решение:**

```go
package main

import "fmt"

const (
	Read = 1 << iota
	Write
	Delete
)

func main() {
	perms := Read | Write
	fmt.Println("Права:", perms)
	fmt.Println("Delete есть:", perms&Delete != 0)

	perms |= Delete
	fmt.Println("После добавления:", perms)
}
```

## Резюме

- Арифметика целых работает без дробей; `%` только для целых.
- `&&` и `||` ленивы — это используют для защиты от `nil`.
- Побитовые операции и сдвиги удобны для флагов и прав.
- Приоритеты запоминать необязательно: скобки делают код однозначным.
