## Один цикл вместо трёх

В Go нет отдельных `while` и `do while` — всё выражается через `for` в трёх
формах.

### 1. Классическая форма

```go
for i := 0; i < 5; i++ {
	fmt.Print(i, " ") // 0 1 2 3 4
}
```

Три части: инициализация, условие, шаг. Любую можно опустить.

### 2. Форма «while»

```go
n := 1
for n < 100 {
	n *= 2
}
fmt.Println(n) // 128
```

### 3. Бесконечный цикл

```go
for {
	// выполняется, пока не сработает break или return
	if done() {
		break
	}
}
```

Так пишут серверные циклы и чтение из канала. Не забывайте про условие выхода.

## `range`

```go
names := []string{"Анна", "Борис", "Вера"}

for index, name := range names {
	fmt.Println(index, name)
}

for _, name := range names { // индекс не нужен
	fmt.Println(name)
}

for index := range names { // только индексы
	fmt.Println(index)
}
```

Для map `range` даёт ключ и значение:

```go
scores := map[string]int{"Анна": 5, "Борис": 4}
for name, score := range scores {
	fmt.Println(name, score)
}
```

**Порядок обхода map не определён** и меняется от запуска к запуску. Если нужен
стабильный порядок — соберите ключи в срез и отсортируйте.

Для строки `range` обходит **руны**, а не байты:

```go
for index, char := range "GoЯ" {
	fmt.Println(index, string(char))
}
// 0 G
// 1 o
// 2 Я
```

Индекс — байтовый, поэтому у кириллицы он не совпадает с номером символа.

## `break` и `continue`

```go
for _, n := range []int{1, 2, 3, 4, 5, 6} {
	if n == 4 {
		break // прервать весь цикл
	}
	if n%2 == 0 {
		continue // перейти к следующей итерации
	}
	fmt.Println(n) // 1, 3
}
```

## Метки для вложенных циклов

`break` выходит только из ближайшего цикла. Чтобы выйти из внешнего, нужна метка:

```go
found := false
for i := 0; i < 3; i++ {
	for j := 0; j < 3; j++ {
		if matrix[i][j] == target {
			found = true
			break outer
		}
	}
}
```

Метка объявляется как `outer:` перед циклом. `continue outer` перейдёт к
следующей итерации внешнего цикла. Метку принято писать осмысленно (`search`,
`rows`), а не `L1`.

## Изменение среза в цикле

```go
numbers := []int{1, 2, 3}
for _, n := range numbers {
	n *= 2 // меняет только копию значения
}
fmt.Println(numbers) // [1 2 3]

for i := range numbers {
	numbers[i] *= 2 // меняет элемент среза
}
fmt.Println(numbers) // [2 4 6]
```

`range` копирует значение элемента. Если элементы — структуры и нужно менять
поля, берите индекс или используйте срез указателей.

## Цикл и замыкания

До Go 1.22 переменная цикла была одна на все итерации — замыкания «залипали» на
последнем значении. В Go 1.22+ переменная создаётся заново на каждой итерации,
поэтому классическая ловушка исчезла. Если проект собирается компилятором 1.21 и
ниже, передавайте значение в функцию явно:

```go
for _, v := range values {
	v := v // копия для замыкания (нужно в Go < 1.22)
	go func() { fmt.Println(v) }()
}
```

## Частые ошибки

- **Изменение длины среза внутри `range`.** Новые элементы могут не попасть в
  обход; поведение зависит от `append`. Итерируйте по копии, если меняете.
- **`break` из `switch` внутри цикла.** Он выйдет только из `switch`; нужна метка.
- **Порядок map.** Не полагайтесь на него даже «на глаз».
- **Забыть изменить условие.** Бесконечный цикл с `for n < 100` без изменения `n`.
- **`i++` в условии.** Шаг пишется в третьей части, а не в условии.
- **`for i := 0; i <= len(s); i++`.** Последняя итерация выйдет за границы:
  нужно `< len(s)`.
- **Ожидание `while`.** В Go его нет; используйте `for condition {}`.

## Практика

**Задание.** Напишите программу с тремя циклами:

1. вывести числа от 1 до 5 через пробел;
2. найти сумму чисел от 1 до 100;
3. вывести только чётные числа от 1 до 10, используя `continue`.

**Стартовый код:**

```go
package main

func main() {
	// 1) числа 1..5 через пробел
	// 2) сумма 1..100
	// 3) чётные от 1 до 10 через continue
	// для вывода добавьте импорт "fmt"
}
```

**Ожидаемый вывод:**

```text
1 2 3 4 5
Сумма: 5050
2 4 6 8 10
```

**Подсказка.** Для второго цикла заведите `sum := 0` и прибавляйте `i`. Для
третьего проверьте `if i%2 != 0 { continue }`.

**Решение:**

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 5; i++ {
		if i > 1 {
			fmt.Print(" ")
		}
		fmt.Print(i)
	}
	fmt.Println()

	sum := 0
	for i := 1; i <= 100; i++ {
		sum += i
	}
	fmt.Println("Сумма:", sum)

	first := true
	for i := 1; i <= 10; i++ {
		if i%2 != 0 {
			continue
		}
		if !first {
			fmt.Print(" ")
		}
		fmt.Print(i)
		first = false
	}
	fmt.Println()
}
```

## Резюме

- Все циклы в Go — это `for` в трёх формах: с тремя частями, с условием и
  бесконечный.
- `range` даёт индекс и копию значения; для изменения элемента берите индекс.
- `break` и `continue` работают с ближайшим циклом, метки — с внешним.
- Порядок обхода map не гарантирован.
