## `const`

```go
const MaxRetries = 3
const AppName string = "Go Academy"
const (
	Timeout   = 30
	BatchSize = 100
)
```

Константа вычисляется **на этапе компиляции** и не может быть изменена:

```go
MaxRetries = 5 // error: cannot assign to MaxRetries
```

Что можно присвоить константе: литералы, другие константы и выражения из
констант (`const KB = 1024; const MB = KB * 1024`). Вызов функции — нельзя:

```go
const now = time.Now() // error: not a constant
```

## Нетипизированные константы

Пока константе не указан тип, она **нетипизированная** и подстраивается под
контекст:

```go
const timeout = 30

var seconds int = timeout        // int
var millis int64 = timeout       // int64
var ratio float64 = timeout      // float64
```

Типизированная константа так не умеет:

```go
const typedTimeout int = 30
var ratio float64 = typedTimeout // error: cannot use typedTimeout (int) as float64
```

Поэтому в Go предпочитают **не указывать тип у констант** без необходимости — так
они удобнее в использовании.

## `iota`

`iota` — счётчик строк в блоке `const`. Начинается с нуля и увеличивается на 1 в
каждой следующей спецификации.

```go
const (
	Sunday = iota // 0
	Monday        // 1
	Tuesday       // 2
	Wednesday     // 3
)
```

Удобно для перечислений. Часто добавляют тип и строковое представление:

```go
type Weekday int

const (
	Sunday Weekday = iota
	Monday
	Tuesday
)

func (d Weekday) String() string {
	return [...]string{"Вс", "Пн", "Вт"}[d]
}

fmt.Println(Monday) // Пн
```

`[...]string{...}` — массив, длина которого выводится из литерала.

### Пропуск значений и смещения

```go
const (
	_  = iota             // пропускаем 0
	KB = 1 << (10 * iota) // 1 << 10 = 1024
	MB                    // 1 << 20
	GB                    // 1 << 30
)
```

Пустая строка `_` нужна, чтобы KB не оказался равным 1. Выражение повторяется для
каждой следующей строки блока — это ключевая особенность `iota`.

### Флаги

```go
const (
	FlagRead = 1 << iota // 1
	FlagWrite            // 2
	FlagExec             // 4
)
```

Получаются степени двойки, которые удобно комбинировать через `|` и проверять
через `&`.

## Зачем константы, если есть переменные

1. **Безопасность.** Компилятор не даст изменить значение.
2. **Читаемость.** `StatusOK` понятнее, чем `200`.
3. **Оптимизация.** Константы подставляются в код и не занимают память.
4. **Компиляция.** Выражения из констант проверяются до запуска.

## Частые ошибки

- **Попытка вычислить что-то в рантайме.** `const x = len(os.Args)` не
  скомпилируется. Используйте `var`.
- **Указание типа там, где оно мешает.** Типизированная константа не
  преобразуется неявно — часто лучше оставить её нетипизированной.
- **`iota` вне `const`.** Идентификатор доступен только в блоке констант.
- **Забыть, что выражение повторяется.** В блоке с `iota` строка без `=` копирует
  предыдущее выражение — это и даёт `MB` и `GB` без ручных степеней.
- **Ожидание `nil`-константы.** `const x = nil` невозможно: `nil` не константа.

## Практика

**Задание.** Объявите тип `Priority` и константы `Low`, `Medium`, `High` через
`iota`. Напечатайте числовые значения всех трёх констант и значение по умолчанию
для переменной этого типа.

**Стартовый код:**

```go
package main

import "fmt"

type Priority int

const (
	// объявите Low, Medium, High через iota
)

func main() {
	var p Priority
	fmt.Println("по умолчанию:", p)
	// после объявления констант напечатайте их номера:
	// fmt.Println(Low, Medium, High)
}
```

Стартовый код компилируется: пока константы не объявлены, программа печатает
только значение по умолчанию.

**Ожидаемый вывод:**

```text
0 1 2
по умолчанию: 0
```

**Подсказка.** `Low Priority = iota`, затем `Medium` и `High` без выражений.

**Решение:**

```go
package main

import "fmt"

type Priority int

const (
	Low Priority = iota
	Medium
	High
)

func main() {
	var p Priority
	fmt.Println(Low, Medium, High)
	fmt.Println("по умолчанию:", p)
}
```

## Резюме

- `const` вычисляется при компиляции и не меняется.
- Нетипизированные константы подстраиваются под контекст — используйте это.
- `iota` автоматически нумерует строки блока `const`, включая степени двойки и
  пропуски через `_`.
- Константы делают код безопаснее и читаемее.
