## Синтаксис

В Go преобразование записывается как вызов типа:

```go
var a int = 42
var b float64 = float64(a)
var c int64 = int64(a)
var d byte = byte(a)
```

Это **не** приведение ссылок: создаётся новое значение другого типа. Преобразование
возможно, если типы имеют совместимое представление (числа между собой, `rune` и
`int32`, `byte` и `uint8`, срезы байтов и строки).

```go
var r rune = 'A'
fmt.Println(int(r)) // 65
```

## Числовые преобразования и потери

При сужении типа значение **усекается**, и об этом не будет ошибки:

```go
var big int = 300
var small uint8 = uint8(big) // 44: 300 - 256
fmt.Println(small)
```

Дробное в целое — отбрасывание дробной части (не округление):

```go
fmt.Println(int(3.99)) // 3
fmt.Println(int(-3.99)) // -3
```

Если значение не помещается в `float64`, получите `+Inf`:

```go
var huge float64 = 1e400 // ошибка компиляции: constant overflows
x := 1e308 * 10          // +Inf во время выполнения
```

Проверяйте диапазон до преобразования, если данные приходят извне:

```go
func toInt8(n int) (int8, error) {
	if n < -128 || n > 127 {
		return 0, fmt.Errorf("%d не помещается в int8", n)
	}
	return int8(n), nil
}
```

## Целые и float

Деление целых даёт целое. Чтобы получить дробный результат, приводите **до**
деления:

```go
a, b := 7, 2
fmt.Println(a / b)                 // 3
fmt.Println(float64(a) / float64(b)) // 3.5
fmt.Println(float64(a / b))        // 3 — приведение уже после деления!
```

Последняя строка — классическая ошибка.

## Строки и числа: `strconv`

Преобразование между строками и числами делается не приведением, а пакетом
`strconv`:

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// число → строка
	text := strconv.Itoa(42)              // "42"
	text64 := strconv.FormatInt(9000, 10) // "9000"
	pi := strconv.FormatFloat(3.14159, 'f', 2, 64) // "3.14"

	// строка → число (всегда с ошибкой)
	number, err := strconv.Atoi("42")
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}

	ratio, err := strconv.ParseFloat("0.75", 64)
	fmt.Println(text, text64, pi, number, ratio, err)
}
```

Важно: `string(65)` даёт `"A"` (символ по коду), а не `"65"`. Для числа нужен
`strconv.Itoa`.

## Байты, руны и строки

```go
s := string([]byte{72, 105}) // "Hi"
b := []byte("Hi")            // [72 105]
r := []rune("Привет")        // [1055 1088 1080 1074 1077 1090]
s2 := string(r)              // "Привет"
```

Преобразование среза рун в строку корректно кодирует UTF-8. Некорректные байты
превращаются в символ замены `�`.

## `any` и утверждение типа

Интерфейс `any` может хранить значение любого типа. Чтобы получить обратно
конкретный тип, используют утверждение:

```go
var value any = "текст"
text, ok := value.(string)
if !ok {
	fmt.Println("это не строка")
}
fmt.Println(text)
```

О `type assertion` будет отдельный урок в модуле про интерфейсы.

## Частые ошибки

- **Приведение после деления.** `float64(a / b)` теряет дробную часть.
- **`string(number)`.** Даёт символ, а не число. Нужен `strconv.Itoa`.
- **Игнорирование ошибки `Atoi`.** Некорректная строка вернёт 0 и ошибку.
- **Молчаливое переполнение.** `uint8(300)` не паникует, а усекается.
- **`int("42")`.** Между строкой и числом преобразования типов не бывает.
- **Сравнение `float64` на равенство.** Используйте допуск: `math.Abs(a-b) < 1e-9`.

## Практика

**Задание.** Прочитайте из строковых переменных количество товаров и цену
(`"5"` и `"129.90"`), вычислите итог и выведите его с двумя знаками после
запятой. Ошибки разбора нужно обработать.

**Стартовый код:**

```go
package main

func main() {
	countText := "5"
	priceText := "129.90"

	// разберите значения и посчитайте итог
	// count, err := strconv.Atoi(countText)
	// fmt.Printf("Итог: %.2f\n", float64(count)*price)
	// добавьте импорты "fmt" и "strconv"
	_, _ = countText, priceText
}
```

**Ожидаемый вывод:**

```text
Итог: 649.50
```

**Подсказка.** `strconv.Atoi(countText)` для количества,
`strconv.ParseFloat(priceText, 64)` для цены. Итог —
`float64(count) * price`.

**Решение:**

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	countText := "5"
	priceText := "129.90"

	count, err := strconv.Atoi(countText)
	if err != nil {
		fmt.Println("количество:", err)
		return
	}
	price, err := strconv.ParseFloat(priceText, 64)
	if err != nil {
		fmt.Println("цена:", err)
		return
	}

	fmt.Printf("Итог: %.2f\n", float64(count)*price)
}
```

## Резюме

- Преобразование типа — `T(value)`; оно создаёт новое значение.
- Сужение типов усекает значение без предупреждения — проверяйте диапазон.
- Между строкой и числом используйте `strconv`, а не приведение.
- `[]byte` и `[]rune` — правильные способы работать с содержимым строки.
