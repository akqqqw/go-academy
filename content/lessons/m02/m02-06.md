## Базовый синтаксис

```go
if age >= 18 {
	fmt.Println("Доступ разрешён")
} else {
	fmt.Println("Доступ запрещён")
}
```

Отличия от C-подобных языков:

- **нет скобок** вокруг условия;
- фигурные скобки **обязательны** — даже для одной строки;
- `else` пишется на той же строке, что и закрывающая скобка `}`.

```go
if x > 0 {
	fmt.Println("положительное")
} else if x < 0 {
	fmt.Println("отрицательное")
} else {
	fmt.Println("ноль")
}
```

Если поставить `else` на новую строку, компилятор выдаст ошибку: автоматическая
вставка точки с запятой разорвёт конструкцию.

## Блок инициализации

В `if` можно объявить переменную прямо перед условием. Она живёт только внутри
`if`/`else if`/`else`:

```go
if value, err := parse(input); err != nil {
	fmt.Println("ошибка:", err)
} else {
	fmt.Println("значение:", value)
}
```

Это идиоматичный Go: проверка и обработка ошибки в одной строке, переменная не
«засоряет» остальную функцию. Именно так устроены почти все примеры в
стандартной библиотеке.

Синтаксис: `if <инициализация>; <условие> { ... }`. Условие обязательно, а
инициализация — нет.

## Ранний возврат

Вместо глубокой вложенности возвращайтесь как можно раньше:

```go
// Плохо: вложенность растёт
func process(user *User) error {
	if user != nil {
		if user.Active {
			if len(user.Email) > 0 {
				return send(user.Email)
			}
		}
	}
	return errors.New("пользователь не готов")
}

// Хорошо: проверки по одной, затем основная логика
func process(user *User) error {
	if user == nil {
		return errors.New("пользователь не указан")
	}
	if !user.Active {
		return errors.New("пользователь неактивен")
	}
	if user.Email == "" {
		return errors.New("не указан email")
	}
	return send(user.Email)
}
```

Правило «happy path слева» делает код линейным: читатель видит условия
отсечения и одну основную ветку.

## Область видимости

```go
if true {
	x := 1
	fmt.Println(x) // 1
}
fmt.Println(x) // ошибка: undefined: x
```

Переменная из инициализации `if` тоже ограничена блоком:

```go
if value, err := get(); err == nil {
	fmt.Println(value)
}
// value и err здесь недоступны
```

Часто это плюс, но иногда мешает: если значение нужно дальше, объявляйте его
заранее и используйте `=`.

## Логические условия

```go
if user != nil && user.Admin && !user.Blocked {
	grantAccess()
}
```

Благодаря ленивому `&&` обращение к полям происходит только после проверки на
`nil`. Порядок важен: сначала дешёвые и защитные условия.

## Пример: расчёт скидки

Скидка по сумме заказа:

```go
import "fmt"

func discount(total float64) float64 {
	switch {
	case total >= 5000:
		return 0.15
	case total >= 2000:
		return 0.10
	case total >= 1000:
		return 0.05
	default:
		return 0
	}
}

func main() {
	fmt.Println(discount(1200)) // 0.05
}
```

Здесь используется `switch` без условия — об этом следующий урок. Тот же результат
достигается через `if-else if`.

## Частые ошибки

- **Скобки вокруг условия.** `if (x > 0) { }` скомпилируется, но `gofmt` их
  удалит; стиль Go — без скобок.
- **`else` на новой строке.** Синтаксическая ошибка из-за `;`.
- **Забытая инициализация.** Использование переменной из `if` после блока.
- **Присваивание вместо сравнения.** `if x = 5` не скомпилируется: нужен `bool`,
  а не `int`.
- **Тернарный оператор.** В Go его нет: пишите `if` или функцию.
- **Пустая ветка `else`.** Лишний код; лучше ранний возврат.
- **Условие, которое всегда истинно.** `if err != nil { }` без `return` внутри —
  ошибка часто остаётся необработанной.

## Практика

**Задание.** Напишите функцию `checkAge(age int) string`, которая возвращает:

- `"ребёнок"` для возраста меньше 14;
- `"подросток"` для 14–17;
- `"взрослый"` для 18 и больше.

Для отрицательного возраста верните `"некорректный возраст"`.

**Стартовый код:**

```go
package main

import "fmt"

func checkAge(age int) string {
	// реализуйте проверки
	return ""
}

func main() {
	fmt.Println(checkAge(10), checkAge(15), checkAge(21), checkAge(-1))
}
```

**Ожидаемый вывод:**

```text
ребёнок подросток взрослый некорректный возраст
```

**Подсказка.** Начните с `if age < 0 { return "..."" }` — ранний возврат, затем
остальные условия.

**Решение:**

```go
package main

import "fmt"

func checkAge(age int) string {
	if age < 0 {
		return "некорректный возраст"
	}
	if age < 14 {
		return "ребёнок"
	}
	if age < 18 {
		return "подросток"
	}
	return "взрослый"
}

func main() {
	fmt.Println(checkAge(10), checkAge(15), checkAge(21), checkAge(-1))
}
```

## Резюме

- Условие пишется без скобок, фигурные скобки обязательны.
- В `if` можно объявить переменные — они видны только внутри ветки.
- Ранний возврат уменьшает вложенность и делает код линейным.
- В Go нет тернарного оператора.

Следующий урок — `switch`, в том числе без условия.
