## Четыре способа объявить переменную

```go
var age int          // объявление с типом, значение по умолчанию 0
var name string = "Анна" // тип указан явно
var score = 10       // тип выводится из значения
count := 5           // короткое объявление (только внутри функции)
```

Правила:

- `var` можно использовать и на уровне пакета, и внутри функции.
- `:=` работает **только внутри функции**. На уровне пакета это синтаксическая
  ошибка.
- После объявления переменная имеет тип, и он не меняется.

Несколько переменных сразу:

```go
var width, height int = 10, 20
x, y := 3, 4
```

## Нулевые значения

В Go нет «неинициализированных» переменных: каждая получает **нулевое значение**
своего типа.

| Тип | Нулевое значение |
| --- | --- |
| `int`, `int64`, `uint` | `0` |
| `float64` | `0` |
| `string` | `""` (пустая строка) |
| `bool` | `false` |
| указатель, срез, map, функция, интерфейс | `nil` |
| `struct` | структура с нулевыми полями |

```go
var name string
var count int
var items []string
var loaded bool

fmt.Printf("%q %d %v %t\n", name, count, items, loaded)
// "" 0 [] false
```

Это важное отличие от языков, где переменная может содержать «мусор». Нулевое
значение всегда предсказуемо, поэтому многие типы можно использовать без
конструктора.

## Краткая форма и переприсваивание

```go
count := 5
count = 7      // обычное присваивание
// count := 8  // ошибка: no new variables on left side of :=
```

`:=` требует хотя бы одну **новую** переменную слева:

```go
a, b := 1, 2
b, c := 3, 4   // b переприсвоена, c объявлена — допустимо
fmt.Println(a, b, c) // 1 3 4
```

## Область видимости

Переменная живёт в блоке, где объявлена: функция, `if`, `for`, `switch`.

```go
func example() {
	x := 1
	if x > 0 {
		x := 2       // новая переменная, «затеняет» внешнюю
		fmt.Println(x) // 2
	}
	fmt.Println(x)   // 1
}
```

Затенение (shadowing) — частая причина ошибок. Особенно коварна ситуация:

```go
var err error
if value, err := parse(); err == nil {
	// здесь err — новая переменная из блока if
}
fmt.Println(err) // всё ещё nil, хотя parse() вернул ошибку
```

Внутри `if` создан новый `err`, внешний не изменился. Решение — заранее объявить
переменные и использовать `=`:

```go
var err error
var value string
if value, err = parse(); err == nil { ... }
```

## Именование

- Имена пишут в `camelCase`: `userName`, `totalPrice`.
- Экспортируемые (видимые из других пакетов) — с заглавной буквы: `MaxRetries`.
- Короткие имена уместны в коротких областях: `i`, `n`, `ok`. В больших функциях
  лучше `index`, `count`.
- Аббревиатуры пишут одинаковым регистром: `userID`, `httpClient`, `HTTPServer`.
- Имена пакетов — строчные, без `_`: `storage`, `httpclient`.

## Пустой идентификатор `_`

Если значение нужно, но переменная не используется, применяют `_`:

```go
_, err := fmt.Scan(&name) // первое значение (количество) не нужно
for _, value := range items { ... }
```

`_` не хранит значение и не вызывает ошибку «declared and not used».

## Частые ошибки

- **`declared and not used`.** Go не разрешает неиспользуемые локальные
  переменные. Удалите её или примените `_`.
- **`:=` на уровне пакета.** Синтаксическая ошибка: используйте `var`.
- **Смена типа.** `var n int = 1; n = "one"` не скомпилируется: тип фиксирован.
- **Затенение в `if`/`for`.** Внешняя переменная не меняется — источник «странных»
  ошибок.
- **Сравнение с `nil` для строки.** Строка не бывает `nil`: пустая строка — это
  `""`. Для среза и map проверка на `nil` корректна.
- **Однобуквенные имена в большой функции.** Через 30 строк уже непонятно, что
  такое `x`.

## Практика

**Задание.** Объявите переменные для имени пользователя, возраста и баланса.
Выведите их в формате:

```text
Пользователь: Анна
Возраст: 28
Баланс: 1250.50
```

Возраст и баланс должны быть числами, а не строками.

**Стартовый код:**

```go
package main

func main() {
	// объявите три переменные
	var name string = "Анна"
	age := 28
	balance := 1250.5

	// напечатайте значения
	// fmt.Println("Пользователь:", name)
	// добавьте импорт "fmt"
	_, _, _ = name, age, balance
}
```

**Подсказка.** Для строки используйте `var name string = "Анна"`, для чисел —
`age := 28` и `balance := 1250.5`. Формат баланса — `%.2f`.

**Ожидаемый вывод:**

```text
Пользователь: Анна
Возраст: 28
Баланс: 1250.50
```

**Решение:**

```go
package main

import "fmt"

func main() {
	name := "Анна"
	age := 28
	balance := 1250.5

	fmt.Println("Пользователь:", name)
	fmt.Println("Возраст:", age)
	fmt.Printf("Баланс: %.2f\n", balance)
}
```

## Резюме

- `var` работает везде, `:=` — только внутри функций и требует новую переменную.
- Каждая переменная получает нулевое значение своего типа.
- Область видимости — блок; затенение опасно и легко упускается.
- `_` позволяет игнорировать ненужное значение.

Дальше — константы и `iota`.
