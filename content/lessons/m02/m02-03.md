## Зачем столько типов

Go требует явного выбора размера, поэтому в языке есть несколько целочисленных
типов. Выбор влияет на диапазон значений, размер в памяти и совместимость с
внешними системами (например, JSON и бинарными протоколами).

## Целые числа

| Тип | Размер | Диапазон |
| --- | --- | --- |
| `int8` | 1 байт | −128…127 |
| `int16` | 2 байта | −32 768…32 767 |
| `int32` | 4 байта | ≈ ±2,1 млрд |
| `int64` | 8 байт | ≈ ±9,2·10¹⁸ |
| `int` | 4 или 8 байт | зависит от платформы |
| `uint8`/`byte` | 1 байт | 0…255 |
| `uint16` | 2 байта | 0…65 535 |
| `uint32` | 4 байта | 0…≈4,3 млрд |
| `uint64` | 8 байт | 0…≈1,8·10¹⁹ |
| `uintptr` | — | для адресов и низкоуровневого кода |

- `int` — самый частый тип для счётчиков и индексов. На 64-битных платформах он
  занимает 8 байт.
- `uint` — беззнаковый; используйте, когда отрицательные значения действительно
  невозможны. Иначе арифметика вроде `0 - 1` даст огромное число, а не −1.
- `byte` — псевдоним `uint8`, удобен для работы с бинарными данными.
- `rune` — псевдоним `int32`, обозначает один Unicode-символ (кодовую точку).

```go
var small int8 = 127
// small = 128 // ошибка компиляции: overflow
var big uint64 = 18_446_744_073_709_551_615
```

Подчёркивания в числах разрешены для читаемости: `1_000_000`.

## Числа с плавающей точкой

| Тип | Точность |
| --- | --- |
| `float32` | ~7 значащих цифр |
| `float64` | ~15 значащих цифр |

По умолчанию литерал `3.14` имеет тип `float64`. Для денег и точных расчётов
`float` не подходит: `0.1 + 0.2` даёт `0.30000000000000004`. Используйте целые
копейки или пакет `math/big`.

```go
price := 19.99
fmt.Printf("%.2f\n", price) // 19.99
fmt.Println(0.1 + 0.2)      // 0.30000000000000004
```

## `bool`

```go
var ready bool        // false
ok := 10 > 3          // true
fmt.Println(!ok)      // false
```

Логические операторы: `&&` (и), `||` (или), `!` (не). В Go нет неявного
преобразования чисел в `bool`: `if 1 { }` не скомпилируется.

## Строки

Строка в Go — **неизменяемая последовательность байтов в UTF-8**:

```go
s := "Go"
fmt.Println(len(s)) // 2 байта
fmt.Println(s[0])   // 71 (байт, не символ)
```

Кириллица занимает больше одного байта:

```go
word := "Привет"
fmt.Println(len(word))         // 12 байт
fmt.Println(len([]rune(word))) // 6 символов
```

Строки нельзя менять по индексу:

```go
s := "hello"
// s[0] = 'H' // ошибка компиляции
s = "H" + s[1:] // создаём новую строку
```

Для конкатенации в циклах используйте `strings.Builder`.

## Байты и руны

```go
var b byte = 'A'   // 65 — байт
var r rune = 'Я'   // 1071 — кодовая точка Unicode
var emoji rune = '🙂' // 128578
```

Одиночные кавычки — это `rune` (или `byte` для ASCII), двойные — строка.
Итерация по строке с `range` даёт руны:

```go
for index, char := range "GoЯ" {
	fmt.Println(index, char, string(char))
}
// 0 71 G
// 1 111 o
// 2 1071 Я
```

Индекс — байтовый, поэтому он «прыгает» через 2 на кириллице.

## Составные типы (кратко)

- `[3]int` — массив фиксированной длины;
- `[]int` — срез, «динамический массив»;
- `map[string]int` — словарь;
- `struct{...}` — набор полей;
- `*int` — указатель;
- `func(int) error` — функция.

О них будут отдельные уроки.

## Сравнение и приведение

Сравнивать можно значения совместимых типов: числа, строки, `bool`, массивы,
структуры и указатели. Срезы и map — **нельзя** (только с `nil`).

Указатель на массив и указатель на срез? Только в рамках правил: слайсы не
сравнимы, потому что их содержимое разделяемое.

Неявных преобразований нет:

```go
var a int32 = 10
var b int64 = 20
// fmt.Println(a + b) // ошибка: mismatched types
fmt.Println(int64(a) + b) // 30
```

## Частые ошибки

- **`int` и `int64` в одной операции.** Явно приводите к одному типу.
- **`len()` для количества символов.** Возвращает байты; для рун — `utf8.RuneCountInString`.
- **Изменение строки по индексу.** Строки неизменяемы.
- **`float` для денег.** Накопление ошибок округления.
- **`uint` для разностей.** `a - b` при `b > a` даёт огромное число.
- **Сравнение срезов через `==`.** Компилятор не разрешит; используйте `slices.Equal`.
- **Ожидание ASCII в `s[0]`.** Для кириллицы это первый байт UTF-8, а не символ.

## Практика

**Задание.** Для строки `"Привет, Go!"` выведите: количество байт, количество
символов (рун) и первый символ как руну и как строку.

**Стартовый код:**

```go
package main

func main() {
	text := "Привет, Go!"

	// выведите байты, руны и первый символ:
	// fmt.Println("Байт:", len(text))
	// fmt.Println("Символов:", utf8.RuneCountInString(text))
	// добавьте импорты "fmt" и "unicode/utf8"
	_ = text
}
```

**Ожидаемый вывод:**

```text
Байт: 19
Символов: 10
Первый символ: 1055 (П)
```

**Подсказка.** `len(text)` — байты, `utf8.RuneCountInString(text)` — символы,
`[]rune(text)[0]` — первая руна.

**Решение:**

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "Привет, Go!"
	first := []rune(text)[0]

	fmt.Println("Байт:", len(text))
	fmt.Println("Символов:", utf8.RuneCountInString(text))
	fmt.Printf("Первый символ: %d (%s)\n", first, string(first))
}
```

## Резюме

- Для счётчиков берите `int`, для бинарных данных — `byte`, для символов —
  `rune`.
- `float64` — тип по умолчанию для дробных чисел, но не для денег.
- Строка — неизменяемая последовательность байтов UTF-8; `len` считает байты.
- Неявных преобразований нет: приводите типы явно.
