## `switch` по значению

```go
switch day {
case "mon":
	fmt.Println("Понедельник")
case "sat", "sun":
	fmt.Println("Выходной") // несколько значений в одном case
default:
	fmt.Println("Неизвестный день")
}
```

Особенности:

- `case` не требует `break`: после выполнения блока управление выходит из
  `switch`. Проваливание отключено по умолчанию — это одна из самых частых
  причин ошибок при переходе с C.
- `default` может стоять в любом месте, но читается лучше в конце.
- Значения в `case` должны быть сравнимыми с выражением `switch` и не
  повторяться.

## Проваливание: `fallthrough`

Если нужно выполнить следующий блок, его указывают явно:

```go
switch n {
case 1:
	fmt.Println("один")
	fallthrough
case 2:
	fmt.Println("после одного или двух")
}
```

`fallthrough` работает только в последней строке `case`, не работает в последнем
`case` и не учитывает условие следующего блока. В реальном коде он нужен редко —
чаще это признак того, что структуру стоит переписать.

## `switch` без условия

Если выражение опущено, сравнивают `true`, то есть каждый `case` — это условие:

```go
score := 87

switch {
case score >= 90:
	fmt.Println("отлично")
case score >= 75:
	fmt.Println("хорошо")
case score >= 60:
	fmt.Println("удовлетворительно")
default:
	fmt.Println("нужно повторить")
}
```

Порядок `case` важен: выполняется первый подходящий. Это аккуратная замена
длинным `else if`.

## Блок инициализации

```go
switch value := compute(); {
case value > 10:
	fmt.Println("много")
default:
	fmt.Println("мало")
}
```

Или с проверкой ошибки:

```go
switch err := save(); {
case err == nil:
	fmt.Println("сохранено")
case errors.Is(err, ErrPermission):
	fmt.Println("нет прав")
default:
	fmt.Println("ошибка:", err)
}
```

## `switch` по типу (type switch)

Используется с интерфейсами, о них будет отдельный модуль:

```go
func describe(value any) string {
	switch v := value.(type) {
	case int:
		return fmt.Sprintf("целое: %d", v)
	case string:
		return "строка длиной " + strconv.Itoa(len(v))
	case nil:
		return "nil"
	default:
		return fmt.Sprintf("тип %T", v)
	}
}
```

В каждом `case` переменная `v` имеет соответствующий тип.

## Сравнение с `if`

Что читается лучше:

```go
// switch
switch status {
case "new":
	...
case "paid":
	...
}

// if
if status == "new" {
	...
} else if status == "paid" {
	...
}
```

При 2–3 вариантах разница невелика. При 4+ вариантах `switch` короче: не нужно
повторять имя переменной, и сразу видно множество значений. Для составных условий
(`if a && b || c`) `if` остаётся естественнее.

## Частые ошибки

- **Ожидание проваливания.** `case` в Go не проваливается автоматически.
- **`break` в конце case.** Не нужен, но не вреден. Исключение — выход из
  `for` внутри `switch`: `break` выйдет только из `switch`, нужны метки.
- **Путаница с `fallthrough` в `switch` без условия.** Он игнорирует условие
  следующего блока — почти всегда не то, что нужно.
- **Дубликаты в `case`.** Ошибка компиляции: `duplicate case`.
- **Несравнимые значения.** Срезы и map нельзя использовать в `case`.
- **`default` вместо явной ошибки.** Для неизвестного значения лучше вернуть
  ошибку, а не молча продолжать.

## Практика

**Задание.** Напишите функцию `httpStatus(code int) string`, которая через
`switch` возвращает описание: 200 — «OK», 201 — «Created», 301 и 302 —
«Redirect», 404 — «Not Found», 500 — «Server Error», для остальных — «Unknown
status».

**Стартовый код:**

```go
package main

import "fmt"

func httpStatus(code int) string {
	// реализуйте switch
	return ""
}

func main() {
	fmt.Println(httpStatus(200), httpStatus(302), httpStatus(418))
}
```

**Ожидаемый вывод:**

```text
OK Redirect Unknown status
```

**Подсказка.** Несколько значений в `case` перечисляются через запятую:
`case 301, 302:`.

**Решение:**

```go
package main

import "fmt"

func httpStatus(code int) string {
	switch code {
	case 200:
		return "OK"
	case 201:
		return "Created"
	case 301, 302:
		return "Redirect"
	case 404:
		return "Not Found"
	case 500:
		return "Server Error"
	default:
		return "Unknown status"
	}
}

func main() {
	fmt.Println(httpStatus(200), httpStatus(302), httpStatus(418))
}
```

## Резюме

- `switch` в Go не проваливается: `break` не нужен.
- `switch` без условия работает как цепочка `if-else if`.
- Несколько значений перечисляются через запятую в одном `case`.
- `fallthrough` нужен редко и работает только явным указанием.
- `type switch` разбирает динамический тип интерфейса.

Следующий урок — единственный цикл Go: `for`.
