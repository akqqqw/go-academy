## Документация локально

```bash
go doc strings.Builder
go doc net/http.Handler
go doc -all encoding/json | less
```

`go doc` работает без интернета — важное преимущество в офлайне.

## Современные пакеты

`slices` и `maps` (Go 1.21+) заменяют ручные циклы: `slices.Sort`, `slices.Contains`,
`slices.Index`, `maps.Keys`. `log/slog` даёт структурное логирование.
`errors.Join` объединяет ошибки. `min`/`max` — встроенные функции.

## Чего в stdlib нет

БД-драйверов, ORM, роутеров с параметрами пути, CLI-фреймворков. Их берут
отдельными модулями или обходятся `http.ServeMux` с шаблонами (`GET /users/{id}`).

## Частые ошибки

- **Писать своё вместо `slices`/`strings`.** Больше кода и багов.
- **Импорт тяжёлого фреймворка ради роутинга.** С Go 1.22 `ServeMux` умеет
  методы и параметры.
- **Игнорирование `context`.** Отмены и таймауты обязательны в сетевом коде.

## Практика

**Задание.** Используя только стандартную библиотеку, отсортируйте срез и проверьте наличие элемента через `slices`, напечатав `true`.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"slices"
)

func main() {
	numbers := []int{5, 3, 9}
	// отсортируйте и проверьте наличие 3
	fmt.Println(slices.Contains(numbers, 3))
}
```

**Ожидаемый вывод:**

```text
[3 5 9] true
```

**Подсказка.** `slices.Sort(numbers)` и `slices.Contains(numbers, 3)`.

**Решение:**

```go
package main

import (
	"fmt"
	"slices"
)

func main() {
	numbers := []int{5, 3, 9}
	slices.Sort(numbers)
	fmt.Println(numbers, slices.Contains(numbers, 3))
}
```
