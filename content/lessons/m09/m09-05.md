## Типовая раскладка

```text
myservice/
├── cmd/
│   └── server/main.go
├── internal/
│   ├── api/        # HTTP-обработчики
│   ├── storage/    # доступ к данным
│   └── domain/     # бизнес-правила
├── migrations/
├── go.mod
└── README.md
```

- `cmd/` — точки входа, по каталогу на бинарник; здесь только сборка зависимостей.
- `internal/` — код, который нельзя импортировать извне модуля. Компилятор
  действительно запрещает импорт `internal` из других модулей.
- `pkg/` — необязателен; используют, когда библиотека публичная.

## Слои

Направление зависимостей: `cmd → api → domain ← storage`. Домен не знает про
HTTP и SQL — это делает его тестируемым и переносимым. Транспорт зависит от
домена, а не наоборот.

## Имена

- Каталог и пакет называются по тому, что предоставляют: `storage`, `api`.
- Избегайте `util`, `common`, `helpers`: туда складывают всё подряд.
- Не делайте пакет с именем `models`, если это просто набор структур без
  поведения.

## main — тонкий

```go
func main() {
	cfg := config.Load()
	store, err := storage.Open(cfg.DataDir)
	if err != nil {
		log.Fatal(err)
	}
	srv := api.New(store)
	log.Fatal(http.ListenAndServe(cfg.Addr, srv))
}
```

Никакой бизнес-логики в `main`: её нельзя протестировать.

## Частые ошибки

- **Всё в `main`.** Файл на тысячу строк, нулевая тестируемость.
- **`internal` ради красоты.** Если пакет нужен снаружи, `internal` заблокирует
  импорт.
- **Циклические зависимости слоёв.** Домен, импортирующий storage, ломает схему.
- **`utils` без границ.** Растёт бесконечно и тянет всё.

## Практика

**Задание.** Соберите «слои» в одном файле: функция `domainTotal(prices []int) int` и `handlerTotal(prices []int) string`, которая использует первую; напечатайте результат обработчика.

**Стартовый код:**

```go
package main

import "fmt"

func domainTotal(prices []int) int {
	return 0 // сложите цены
}

func handlerTotal(prices []int) string {
	return fmt.Sprintf("итого: %d", domainTotal(prices))
}

func main() {
	fmt.Println(handlerTotal([]int{100, 250}))
}
```

**Ожидаемый вывод:**

```text
итого: 350
```

**Подсказка.** `handlerTotal` форматирует результат `domainTotal` через `fmt.Sprintf("итого: %d", …)`.

**Решение:**

```go
package main

import "fmt"

func domainTotal(prices []int) int {
	total := 0
	for _, price := range prices {
		total += price
	}
	return total
}

func handlerTotal(prices []int) string {
	return fmt.Sprintf("итого: %d", domainTotal(prices))
}

func main() {
	fmt.Println(handlerTotal([]int{100, 250}))
}
```

## Резюме

- `cmd` — точки входа, `internal` — закрытый код, `pkg` — публичные библиотеки.
- Зависимости идут от транспорта к домену, а не обратно.
- `main` только собирает компоненты, бизнес-логика живёт в пакетах.
