## Паспорт модуля

```text
module goacademy

go 1.24

require (
	modernc.org/sqlite v1.34.0
)
```

- `module` — путь модуля, префикс для всех внутренних импортов.
- `go` — версия языка, доступная компилятору.
- `require` — зависимости и их версии (semver).

Все импорты внутри проекта начинаются с пути модуля:
`import "goacademy/internal/storage"`.

## Создание

```bash
mkdir myservice && cd myservice
go mod init example.com/myservice
go run .
```

`go mod init` создаёт `go.mod`. `go mod tidy` добавляет недостающие зависимости и
удаляет лишние, обновляя `go.sum`.

## Версии и replace

- `v1.2.3` — точная версия.
- `v0.x.y` — нестабильная ветка: обратная совместимость не гарантируется.
- `replace example.com/lib => ../lib` — локальная замена, удобна при разработке
  двух модулей рядом.

## go.sum

`go.sum` фиксирует контрольные суммы: он должен быть в репозитории, чтобы сборка
была воспроизводимой. Удалять его вручную нельзя.

## Частые ошибки

- **`go 1.24` и старый тулчейн.** Сборка упадёт с предложением обновить Go.
- **Импорт без пути модуля.** `import "internal/storage"` не скомпилируется.
- **Ручное редактирование require.** Версии лучше менять через `go get` или
  `go mod tidy`.
- **Коммит `vendor/` без нужды.** Вендоринг полезен для офлайн-сборки, но требует
  `go mod vendor` после изменений.

## Практика

**Задание.** В практике создайте функцию `ModulePath() string`, возвращающую `example.com/academy` — так модуль объявляет свой путь, — и напечатайте её.

**Стартовый код:**

```go
package main

import "fmt"

func ModulePath() string {
	return "" // верните путь модуля
}

func main() {
	fmt.Println(ModulePath())
}
```

**Ожидаемый вывод:**

```text
example.com/academy
```

**Подсказка.** Просто верните нужную строку и напечатайте результат в `main`.

**Решение:**

```go
package main

import "fmt"

func ModulePath() string {
	return "example.com/academy"
}

func main() {
	fmt.Println(ModulePath())
}
```

## Резюме

- `go.mod` объявляет путь модуля и версию языка, `go.sum` фиксирует суммы.
- `go mod init` создаёт модуль, `go mod tidy` синхронизирует зависимости.
- `replace` подменяет модуль локальным каталогом при разработке.

Зависимости: выбор библиотек, обновление и вендоринг.
