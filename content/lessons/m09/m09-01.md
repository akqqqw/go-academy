## Пакет — каталог с файлами

Все `.go` файлы одного каталога объявляют одно имя пакета и компилируются вместе.
Внутри пакета имена видны друг другу напрямую, без импорта:

```go
// файл mathx/add.go
package mathx

func Add(a, b int) int { return a + b }
```

```go
// файл mathx/mul.go
package mathx

func Mul(a, b int) int { return a * b }
```

Оба файла — один пакет `mathx`. Функции `Add` и `Mul` доступны друг другу.

## Экспорт

Заглавная первая буква делает имя публичным. Всё остальное — внутренняя
реализация:

```go
package mathx

var Version = "1.0"      // экспортировано
var buildNumber = 42     // видно только внутри mathx

func Add(a, b int) int { return a + b }
func helper() int        { return buildNumber }
```

Правило простое, но именно оно заменяет `public`/`private`.

## Имя пакета

Имя пишется строчными буквами без `_` и `-`: `mathx`, `httpclient`. При импорте
обращаются по имени пакета, а не по пути. Пакет `main` исполняемый, остальные —
библиотечные.

## Циклы импорта

Если `a` импортирует `b`, то `b` не может импортировать `a` — компилятор скажет
`import cycle not allowed`. Решение: вынести общий код в третий пакет или
инвертировать зависимость через интерфейс.

## Частые ошибки

- **Разные имена пакетов в одном каталоге.** Ошибка компиляции.
- **Пакет `main` в подкаталоге без нужды.** Библиотечный код не должен быть
  `main`.
- **Экспорт всего подряд.** Публичный API — обязательство; скрывайте лишнее.
- **Импорт собственного пути.** Создаёт цикл.

## Практика

**Задание.** Представьте пакет `mathx` (файл в одном каталоге): объявите экспортируемую функцию `Mul` и неэкспортируемую `double`, используя `double` внутри `Mul`. В практике объявите их в `package main` и напечатайте `Mul(3, 4)`.

**Стартовый код:**

```go
package main

import "fmt"

func double(n int) int {
	return n // удвойте значение
}

func Mul(a, b int) int {
	return 0 // используйте double
}

func main() {
	fmt.Println(Mul(3, 4))
}
```

**Ожидаемый вывод:**

```text
24
```

**Подсказка.** `double(n int) int { return n * 2 }`, `Mul(a, b int) int { return double(a * b) }`.

**Решение:**

```go
package main

import "fmt"

func double(n int) int {
	return n * 2
}

func Mul(a, b int) int {
	return double(a * b)
}

func main() {
	fmt.Println(Mul(3, 4))
}
```

## Резюме

- Пакет — каталог с файлами одного имени пакета, компилируется целиком.
- Экспорт определяется заглавной буквой имени.
- Циклические импорты запрещены; общий код выносят в отдельный пакет.

Импорты: псевдонимы, пустой импорт и группировка.
