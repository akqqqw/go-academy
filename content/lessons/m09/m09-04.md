## Добавление

```bash
go get modernc.org/sqlite@latest
go get example.com/lib@v1.2.3
go mod tidy
```

`go get` обновляет `go.mod` и `go.sum`. Импорт без `go get` тоже сработает в
режиме `-mod=mod`: `go build` сам подтянет модуль.

## Выбор версий

Go использует **minimal version selection**: берётся минимальная версия,
удовлетворяющая требованиям всех модулей. Это делает сборку предсказуемой.
`go list -m all` показывает итоговое дерево.

## Обновление и откат

```bash
go get -u ./...            # обновить до последних минорных
go get example.com/lib@v1.1.9
go mod tidy
go mod verify              # проверить контрольные суммы
```

Откат — установка точной версии, а не редактирование `go.sum` руками.

## Офлайн и vendor

`go mod vendor` копирует зависимости в `vendor/`; сборка с `-mod=vendor` не
обращается в сеть. В этом проекте именно так собирается backend.

## Как выбирать библиотеки

- Часто хватает стандартной библиотеки: `net/http`, `encoding/json`, `database/sql`.
- Смотрите на поддержку, лицензию и число транзитивных зависимостей.
- Проверяйте API до добавления: лишнюю зависимость потом трудно убрать.
- Тяжёлая зависимость ради одной функции почти всегда не оправдана.

## Частые ошибки

- **`go get` без `go mod tidy`.** В `go.mod` остаются лишние требования.
- **Игнорирование `go.sum` в git.** Сборка станет невоспроизводимой.
- **`latest` в CI.** Сборка может внезапно сломаться; фиксируйте версии.
- **Обновление всего проекта сразу.** Делайте это пошагово и с тестами.

## Практика

**Задание.** Реализуйте функцию `NormalizeVersion(tag string) string`, убирающую префикс `v` из тега версии, и напечатайте результат для `v1.2.3`.

**Стартовый код:**

```go
package main

import "fmt"

func NormalizeVersion(tag string) string {
	return tag // уберите префикс v
}

func main() {
	fmt.Println(NormalizeVersion("v1.2.3"))
}
```

**Ожидаемый вывод:**

```text
1.2.3
```

**Подсказка.** Используйте `strings.TrimPrefix(tag, "v")`.

**Решение:**

```go
package main

import (
	"fmt"
	"strings"
)

func NormalizeVersion(tag string) string {
	return strings.TrimPrefix(tag, "v")
}

func main() {
	fmt.Println(NormalizeVersion("v1.2.3"))
}
```

## Резюме

- `go get` добавляет зависимость, `go mod tidy` убирает лишнее.
- MVS выбирает минимальные подходящие версии, `go.sum` фиксирует суммы.
- `go mod vendor` позволяет собирать проект без сети.

Организация проекта: cmd, internal и раскладка пакетов.
