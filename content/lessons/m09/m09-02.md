## Блок импортов

```go
import (
	"bytes"
	"fmt"
	"os"

	"goacademy/internal/storage"
)
```

`gofmt` сортирует импорты внутри групп; принято отделять стандартную библиотеку
пустой строкой от сторонних пакетов.

## Псевдоним

Если имя пакета неудобно или конфликтует, его переименовывают:

```go
import (
	crand "crypto/rand"
	mrand "math/rand"
)
```

Тогда обращаются `crand.Read(...)`. Псевдоним `_` (blank import) импортирует пакет
только ради побочных эффектов — регистрации драйвера, инициализации:

```go
import _ "modernc.org/sqlite"
```

## Точка и неиспользуемые импорты

`import . "fmt"` вставляет имена в текущую область — почти всегда плохая идея:
непонятно, откуда взялась функция. Неиспользуемый импорт — ошибка компиляции:
Go заставляет держать зависимости чистыми.

## Импорт — это путь

Путь модуля (`goacademy/internal/storage`) определяет местоположение, имя пакета
может отличаться. Обращаются по имени пакета из строки `package`.

## Частые ошибки

- **Импорт для побочного эффекта без `_`.** Компилятор потребует использования.
- **Конфликт имён.** Два пакета `rand` требуют псевдонимов.
- **Импорт неиспользуемого пакета «на будущее».** Сборка упадёт.
- **Относительные импорты.** `import "./storage"` в модулях не работает.

## Практика

**Задание.** Импортируйте `strings` и `sort`, отсортируйте срез строк в обратном порядке и напечатайте результат.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"sort"
	"strings"
)

func main() {
	words := strings.Fields("груша яблоко банан")
	sort.Slice(words, func(i, j int) bool {
		return words[i] < words[j] // разверните порядок
	})
	fmt.Println(words)
}
```

**Ожидаемый вывод:**

```text
[яблоко груша банан]
```

**Подсказка.** `sort.Sort(sort.Reverse(sort.StringSlice(words)))` или `sort.Slice` с `>`.

**Решение:**

```go
package main

import (
	"fmt"
	"sort"
	"strings"
)

func main() {
	words := strings.Fields("груша яблоко банан")
	sort.Slice(words, func(i, j int) bool {
		return words[i] > words[j]
	})
	fmt.Println(words)
}
```

## Резюме

- Импорты группируются, стандартная библиотека отделяется пустой строкой.
- Псевдонимы решают конфликты имён, `_` — импорт ради побочного эффекта.
- Неиспользуемый импорт — ошибка компиляции.

`go.mod` — паспорт модуля и версия языка.
