## Файл `main.go`

Любая исполняемая программа на Go — это пакет `main` с функцией `main`. Минимальный
рабочий файл:

```go
package main

import "fmt"

func main() {
	fmt.Println("Первая программа на Go")
}
```

Строка `package main` стоит первой: до объявления пакета можно размещать только
комментарии. Затем идут импорты, затем — функции. Компилятор не требует
определённого порядка функций, но такой порядок читается лучше.

## `go run` и `go build`

```bash
go run main.go
```

Компилирует программу во временный каталог и сразу запускает. Удобно для
экспериментов: не остаётся мусорных файлов.

```bash
go build -o hello main.go
./hello
```

Создаёт настоящий исполняемый файл. Его можно запускать напрямую, передавать
другому человеку или копировать на сервер — Go SDK там не нужен.

Полезные варианты:

- `go run .` — собрать пакет в текущем каталоге (учитываются все `.go` файлы).
- `go build ./...` — проверить компиляцию всех пакетов модуля.
- `go vet ./...` — статический анализ: подозрительные конструкции, неверные
  форматы `Printf`.

## Программа с вычислением

Усложним пример: посчитаем сумму и среднее.

```go
package main

import "fmt"

func main() {
	var a, b, c int = 4, 7, 9
	sum := a + b + c
	// Приведение к float64 нужно, иначе деление будет целочисленным.
	average := float64(sum) / 3

	fmt.Println("Сумма:", sum)
	fmt.Printf("Среднее: %.2f\n", average)
}
```

Вывод:

```text
Сумма: 20
Среднее: 6.67
```

Разберём важные места:

- `var a, b, c int = 4, 7, 9` — объявление с явным типом. Можно короче:
  `a, b, c := 4, 7, 9`.
- `sum := a + b + c` — короткое объявление: тип выводится из правой части (`int`).
- `float64(sum)` — **явное** преобразование. Без него `sum / 3` дал бы `6`:
  в Go деление двух `int` всегда целочисленное.
- `fmt.Printf` использует формат: `%.2f` — число с плавающей точкой и двумя
  знаками после запятой, `\n` — перевод строки.

## Пошаговое выполнение

1. Пакет `main` компилируется в исполняемый файл.
2. При запуске ОС вызывает точку входа программы.
3. Go инициализирует пакеты (в нашем случае — `fmt`), затем вызывает `main()`.
4. Выполняются операторы сверху вниз.
5. После возврата из `main` программа завершается с кодом 0.

Если нужен ненулевой код завершения (например, при ошибке), используют
`os.Exit(1)`. Но в учебных программах достаточно возврата из `main`.

## Комментарии

```go
// Однострочный комментарий.

/*
Многострочный комментарий.
Используется редко: в Go принято писать короткие пояснения.
*/
```

Хороший комментарий объясняет **почему**, а не **что**: код уже показывает, что
происходит.

## Частые ошибки

- **`declared and not used`.** Go не разрешает неиспользуемые переменные. Уберите
  её или примените: `_ = x`.
- **`imported and not used`.** То же для импортов — компилятор строг.
- **Забыть `package main`.** Без него не собрать исполняемую программу.
- **`go run` без аргумента.** Нужно указать файл (`.`) или каталог.
- **Целочисленное деление.** `7 / 2` равно `3`. Для дробного результата
  преобразуйте один операнд в `float64`.
- **Ожидание точки с запятой.** Она ставится автоматически в конце строки; вручную
  писать `;` не нужно и не принято.

## Практика

**Задание.** Напишите программу, которая считает стоимость покупки: три товара по
120, 89 и 45 рублей. Выведите сумму и среднюю цену товара с двумя знаками после
запятой.

**Стартовый код:**

```go
package main

func main() {
	// объявите цены, сумму и среднее
	// prices := []int{120, 89, 45}
	// fmt.Println("Сумма:", sum)
	// добавьте импорт "fmt"
}
```

**Ожидаемый вывод:**

```text
Сумма: 254
Средняя цена: 84.67
```

**Подсказка.** Для среднего используйте `float64(sum) / float64(count)` или
`float64(sum) / 3`, затем `fmt.Printf("%.2f", average)`.

**Решение:**

```go
package main

import "fmt"

func main() {
	prices := []int{120, 89, 45}
	sum := 0
	for _, price := range prices {
		sum += price
	}
	average := float64(sum) / float64(len(prices))

	fmt.Println("Сумма:", sum)
	fmt.Printf("Средняя цена: %.2f\n", average)
}
```

Здесь уже используются срезы и `range` — им посвящён модуль 4. Пока достаточно
понимать, что `sum` накапливает значения, а `len(prices)` возвращает количество
элементов.

## Резюме

- Программа состоит из пакета, импортов и функции `main`.
- `go run` удобен для запуска, `go build` создаёт самостоятельный бинарник.
- Go строг: неиспользуемые переменные и импорты — ошибка компиляции.
- Деление целых чисел целочисленное; для дробного результата нужен `float64`.
