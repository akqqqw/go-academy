## Три способа вывести данные

Пакет `fmt` (format) — основной инструмент ввода-вывода в учебных программах.

```go
package main

import "fmt"

func main() {
	name := "Мир"
	attempts := 3

	fmt.Println("Привет,", name, "попыток:", attempts) // через пробелы и перевод строки
	fmt.Printf("Привет, %s! Попыток: %d\n", name, attempts)
	message := fmt.Sprintf("%s: %d", name, attempts) // вернуть строку
	fmt.Println(message)
}
```

Вывод:

```text
Привет, Мир попыток: 3
Привет, Мир! Попыток: 3
Мир: 3
```

- `Println` разделяет аргументы пробелами, добавляет `\n` и печатает значения «как
  есть».
- `Printf` подставляет значения в шаблон. Нужно следить за количеством и типами
  аргументов.
- `Sprintf` делает то же, что `Printf`, но **возвращает строку** — удобно для
  сообщений об ошибках и имён файлов.

Есть также `Sprintln` (строка с пробелами) и `Fprintf` (запись в `io.Writer`,
например в файл или `os.Stderr`).

## Глаголы формата

Глагол — часть шаблона, начинающаяся с `%`.

| Глагол | Для чего | Пример | Результат |
| --- | --- | --- | --- |
| `%v` | значение по умолчанию | `fmt.Printf("%v", 42)` | `42` |
| `%+v` | структура с именами полей | `fmt.Printf("%+v", user)` | `{Name:Анна Age:20}` |
| `%T` | тип значения | `fmt.Printf("%T", 42)` | `int` |
| `%d` | целое | `fmt.Printf("%d", 42)` | `42` |
| `%05d` | целое с ведущими нулями | `fmt.Printf("%05d", 42)` | `00042` |
| `%s` | строка | `fmt.Printf("%s", "go")` | `go` |
| `%q` | строка в кавычках | `fmt.Printf("%q", "go")` | `"go"` |
| `%f` | дробное | `fmt.Printf("%.2f", 3.14159)` | `3.14` |
| `%t` | логическое | `fmt.Printf("%t", true)` | `true` |
| `%p` | адрес указателя | `fmt.Printf("%p", &x)` | `0xc000012345` |
| `%%` | символ процента | `fmt.Printf("100%%")` | `100%` |

Ширина и точность задаются числами: `%8s` — строка шириной 8 с выравниванием
вправо, `%-8s` — влево, `%08.2f` — число с нулями и двумя знаками после точки.

## Пример с таблицей

```go
package main

import "fmt"

type Product struct {
	Name  string
	Price float64
	Count int
}

func main() {
	products := []Product{
		{Name: "Хлеб", Price: 45.5, Count: 2},
		{Name: "Молоко", Price: 89.9, Count: 1},
	}

	fmt.Printf("%-12s %8s %6s\n", "Товар", "Цена", "Кол-во")
	for _, p := range products {
		fmt.Printf("%-12s %8.2f %6d\n", p.Name, p.Price, p.Count)
	}
}
```

Вывод:

```text
Товар            Цена Кол-во
Хлеб            45.50      2
Молоко          89.90      1
```

Такой приём часто используют для консольных отчётов: ширина колонок задаётся
форматом, а не ручными пробелами.

## `%v` против `%+v`

```go
type User struct {
	Name string
	Age  int
}

user := User{Name: "Анна", Age: 20}
fmt.Printf("%v\n", user)   // {Анна 20}
fmt.Printf("%+v\n", user)  // {Name:Анна Age:20}
fmt.Printf("%#v\n", user)  // main.User{Name:"Анна", Age:20}
```

`%+v` — самый полезный глагол при отладке: сразу видно, какое поле какое.
`%#v` показывает валидный Go-синтаксис и помогает в логах тестов.

Для среза и map `%v` печатает элементы: `[1 2 3]`, `map[a:1 b:2]`. Порядок ключей
map при печати **не гарантирован** (в Go 1.12+ `fmt` их сортирует для
стабильности, но полагаться на порядок в логике нельзя).

## Чтение ввода

`fmt.Scan` и `fmt.Scanf` читают из стандартного ввода:

```go
package main

import "fmt"

func main() {
	var name string
	var age int

	fmt.Print("Имя и возраст: ")
	if _, err := fmt.Scan(&name, &age); err != nil {
		fmt.Println("не удалось прочитать:", err)
		return
	}
	fmt.Printf("Привет, %s! Через год вам будет %d.\n", name, age+1)
}
```

Аргументы передаются **по указателю** (`&name`), потому что функции нужно
записать значение в вашу переменную. Разбор строк удобнее делать через
`strconv` и `strings.Fields`.

## Частые ошибки

- **`%d` для строки.** Получите `%!d(string=go)`. Go не падает, а печатает
  диагностику — легко не заметить.
- **Несовпадение количества аргументов.** Лишние дают `%!(EXTRA ...)`,
  недостающие — `%!s(MISSING)`.
- **`Printf` без `\n`.** Следующий вывод склеится с текущим. `Println` добавляет
  перевод строки сам.
- **`fmt.Println` для формата.** `fmt.Println("%s", name)` напечатает
  `%s Анна`: `Println` не подставляет значения.
- **Собирать строки в цикле через `+`.** Для больших объёмов используйте
  `strings.Builder`; `Sprintf` в цикле тоже аллоцирует.
- **`%q` вместо `%s` в пользовательских сообщениях.** Кавычки хороши в отладке,
  но странно выглядят в интерфейсе.

## Практика

**Задание.** Выведите строку счёта: товар, цена с двумя знаками после запятой и
количество, выровненные по колонкам, а затем итоговую сумму с подписью.

**Стартовый код:**

```go
package main

func main() {
	name := "Ноутбук"
	price := 79990.5
	count := 2

	// напечатайте строку и итог
	// fmt.Printf("%-15s %8.2f x %d\n", name, price, count)
	// добавьте импорт "fmt"
	_, _, _ = name, price, count
}
```

**Ожидаемый вывод:**

```text
Ноутбук         79990.50 x 2
Итого: 159981.00 руб.
```

**Подсказка.** Для первой строки подойдёт `fmt.Printf("%-15s %8.2f x %d\n", ...)`,
для второй — `fmt.Printf("Итого: %.2f руб.\n", price*float64(count))`.

**Решение:**

```go
package main

import "fmt"

func main() {
	name := "Ноутбук"
	price := 79990.5
	count := 2

	fmt.Printf("%-15s %8.2f x %d\n", name, price, count)
	fmt.Printf("Итого: %.2f руб.\n", price*float64(count))
}
```

## Резюме

- `Println` — быстрый вывод с пробелами, `Printf` — форматирование,
  `Sprintf` — форматирование в строку.
- `%v`, `%+v` и `%T` — три главных глагола при отладке.
- Ширина и точность (`%-12s`, `%.2f`, `%05d`) выравнивают вывод в колонки.
- Go не падает на ошибках формата, а печатает `%!d(...)` — проверяйте вывод.
