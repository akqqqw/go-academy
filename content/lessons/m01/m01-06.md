## Сигнатура

```go
func main() {
	// тело программы
}
```

У `main` **нет параметров и нет возвращаемого значения**. Попытка объявить
`func main() int` — ошибка компиляции:

```text
func main must have no arguments and no return values
```

Если нужно вернуть код завершения, используют `os.Exit`.

## Что происходит при запуске

1. Операционная система запускает бинарник.
2. Go инициализирует пакеты в порядке зависимостей: сначала импортируемые,
   затем импортирующие. Выполняются их `init()` и инициализация глобальных
   переменных.
3. Вызывается `main()` пакета `main`.
4. Когда `main` возвращается, программа завершается с кодом 0.

`init()` — особая функция без параметров, которая вызывается автоматически
перед `main`. Используют её редко: явная инициализация в `main` читается лучше.

## Аргументы командной строки

`os.Args` — срез строк: первым идёт путь к программе, дальше — переданные
аргументы.

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println("Всего аргументов:", len(os.Args))
	for index, arg := range os.Args {
		fmt.Printf("%d: %s\n", index, arg)
	}
}
```

Запуск:

```bash
go run main.go привет 42
```

Вывод (путь к временному файлу будет своим):

```text
Всего аргументов: 3
0: /tmp/go-build123/b001/exe/main
1: привет
2: 42
```

Обратите внимание: `os.Args[0]` — имя программы, поэтому полезные аргументы
начинаются с индекса 1. Все они строки, даже `42`. Чтобы получить число,
используют `strconv.Atoi`.

## Коды завершения

Код 0 — успех, ненулевой — ошибка. Так с программой общаются shell и CI.

```go
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	if len(os.Args) != 2 {
		fmt.Println("использование: program <число>")
		os.Exit(2)
	}

	number, err := strconv.Atoi(os.Args[1])
	if err != nil {
		fmt.Println("это не число:", os.Args[1])
		os.Exit(1)
	}

	fmt.Println("квадрат:", number*number)
}
```

Проверка кода завершения в bash:

```bash
go run main.go abc; echo "код: $?"
```

`os.Exit` **немедленно** завершает процесс: отложенные вызовы `defer` не
выполняются, буферы не сбрасываются. Поэтому в библиотеках `os.Exit` не вызывают,
а возвращают ошибку — решение принимает `main`.

## `main` как обычная функция

Внутри `main` можно вызывать любые функции, создавать переменные, обрабатывать
ошибки. Правило хорошего тона: **`main` должен быть коротким**. Часто пишут так:

```go
func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "ошибка:", err)
		os.Exit(1)
	}
}

func run() error {
	// вся логика, которую можно протестировать
	return nil
}
```

Такая структура позволяет покрыть `run()` тестами: обычную функцию вызвать в
тесте проще, чем `main`.

## Частые ошибки

- **Параметры или возвращаемое значение у `main`.** Компилятор откажется
  собирать программу.
- **`main` в библиотечном пакете.** Точка входа бывает только в `package main`.
- **Забыть проверить длину `os.Args`.** Программа паникует при обращении к
  отсутствующему элементу.
- **`os.Exit` в середине логики.** Пропускаются `defer` и очистка ресурсов;
  лучше вернуть ошибку наверх.
- **Вывод ошибок в stdout.** Сообщения об ошибках принято писать в `os.Stderr`,
  чтобы их можно было отделить от полезного вывода.

## Практика

**Задание.** Программа принимает одно число из командной строки и печатает его
удвоенное значение. Если аргумент не передан или это не число, она выводит
понятное сообщение и завершается с кодом 1.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintln(os.Stderr, "использование: program <число>")
		os.Exit(1)
	}

	fmt.Println("Аргумент:", os.Args[1])
	// преобразуйте аргумент в число (понадобится импорт "strconv")
	// и напечатайте удвоенное значение
}
```

При запуске из редактора аргументов нет, поэтому программа напечатает подсказку
и завершится — это ожидаемо: аргументы передаются в терминале.

**Ожидаемый вывод для `go run main.go 21`:**

```text
42
```

**Подсказка.** `strconv.Atoi(os.Args[1])` вернёт число и ошибку. Проверьте
`err != nil` и напечатайте `number * 2`.

**Решение:**

```go
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintln(os.Stderr, "использование: program <число>")
		os.Exit(1)
	}

	number, err := strconv.Atoi(os.Args[1])
	if err != nil {
		fmt.Fprintln(os.Stderr, "не число:", os.Args[1])
		os.Exit(1)
	}

	fmt.Println(number * 2)
}
```

## Резюме

- `main()` — точка входа без параметров и без возвращаемого значения.
- Перед `main` выполняются инициализация пакетов и `init()`.
- Аргументы командной строки доступны в `os.Args`, начиная с индекса 1.
- Код завершения задают через `os.Exit`; ошибки печатают в `os.Stderr`.
- Держите `main` коротким: логику выносите в отдельную функцию.
