## Зачем отдельный SDK

Go — компилируемый язык, поэтому для работы нужен **набор инструментов (SDK)**:
компилятор `compile`, сборщик `go`, форматтер `gofmt`, линтер `go vet` и
стандартная библиотека. Всё это ставится одним архивом или пакетом.

Проверить, установлен ли Go, можно так:

```bash
go version
```

Если команда не найдена, переходим к установке.

## Установка по системам

### macOS

Самый простой путь — Homebrew:

```bash
brew install go
```

Либо скачайте установщик `.pkg` с официального сайта `go.dev/dl` и запустите его.

### Linux

Скачайте архив для своей архитектуры с `go.dev/dl` и распакуйте в `/usr/local`:

```bash
wget https://go.dev/dl/go1.23.4.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.23.4.linux-amd64.tar.gz
```

Затем добавьте `/usr/local/go/bin` в `PATH` в `~/.profile` или `~/.bashrc`:

```bash
export PATH=$PATH:/usr/local/go/bin
```

В дистрибутивах также есть пакеты (`apt install golang-go`, `dnf install golang`),
но они часто отстают от актуальной версии. Для обучения подойдёт и они — главное,
чтобы версия была не ниже 1.21.

### Windows

Скачайте установщик `.msi` с `go.dev/dl` и пройдите мастер установки. Он сам
пропишет `PATH`. После установки откройте новый терминал.

### Проверка

```bash
go version
```

Ожидаемый вывод выглядит так:

```text
go version go1.23.4 darwin/arm64
```

Версия и платформа у вас будут свои.

## Переменные окружения, которые важно знать

`go env` показывает настройки инструментов:

```bash
go env GOROOT GOPATH GOMODCACHE
```

- **GOROOT** — где лежит сам SDK и стандартная библиотека. Менять вручную нужно
  редко.
- **GOPATH** — каталог по умолчанию для кеша и установленных бинарников
  (`~/go`).
- **GOMODCACHE** — кеш скачанных модулей (`~/go/pkg/mod`).

Перенастроить можно через `go env -w`, например:

```bash
go env -w GOPATH=$HOME/work/go
```

## Редактор

В VS Code установите расширение **Go** (официальное, от Go Team). Оно приносит
подсветку, автодополнение `gopls`, запуск тестов и автоматическое форматирование
при сохранении. Достаточно открыть папку проекта — расширение подскажет, чего не
хватает, и предложит установить инструменты.

Для других редакторов есть официальный `gopls` (language server) и `gofmt`.

## Проверяем установку программой

Создайте каталог `hello`, внутри файл `main.go`:

```go
package main

import (
	"fmt"
	"runtime"
)

func main() {
	fmt.Println("Go установлен и работает")
	fmt.Println("Версия:", runtime.Version())
	fmt.Println("Платформа:", runtime.GOOS+"/"+runtime.GOARCH)
}
```

Запуск из каталога с файлом:

```bash
go run main.go
```

Пример вывода:

```text
Go установлен и работает
Версия: go1.23.4
Платформа: darwin/arm64
```

`runtime.Version()` возвращает версию, с которой собрана программа, а
`runtime.GOOS` и `runtime.GOARCH` — операционную систему и архитектуру. Это
удобно для диагностики на разных машинах.

## Частые ошибки

- **`command not found: go`.** Обычно не обновлён `PATH` или не открыт новый
  терминал после установки.
- **Две версии Go в системе.** Проверьте `which -a go` (Linux/macOS) и
  `where go` (Windows). Иногда старая версия из пакетного менеджера перекрывает
  новую.
- **Ожидание, что `go run` работает без файла.** Команда требует путь к `.go`
  файлу или каталогу с пакетом.
- **Установка «просто компилятора».** Нужен весь SDK: только с `gcc` программы
  на Go не собрать.

## Практика

**Задание.** Напишите программу, которая печатает сообщение «Окружение готово» и
версию Go, с которой она собрана. Запустите её через `go run`.

**Стартовый код:**

```go
package main

func main() {
	// выведите сообщение и версию Go
	// fmt.Println("Окружение готово")
	// fmt.Println("Версия:", runtime.Version())
	// добавьте импорты "fmt" и "runtime"
}
```

**Ожидаемый вывод (версия может отличаться):**

```text
Окружение готово
Версия: go1.23.4
```

**Подсказка.** Используйте `fmt.Println("Окружение готово")` и
`fmt.Println("Версия:", runtime.Version())`.

**Решение:**

```go
package main

import (
	"fmt"
	"runtime"
)

func main() {
	fmt.Println("Окружение готово")
	fmt.Println("Версия:", runtime.Version())
}
```

## Резюме

- Для работы нужен Go SDK: компилятор, `go`, `gofmt` и стандартная библиотека.
- Установка занимает минуту, проверка — команда `go version`.
- `go env` объясняет, где SDK (`GOROOT`), кеш модулей (`GOMODCACHE`) и рабочий
  каталог (`GOPATH`).
- Первую программу запускают командой `go run main.go`.

Дальше разберёмся, как устроен проект и зачем нужен файл `go.mod`.
