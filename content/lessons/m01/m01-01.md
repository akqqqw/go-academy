## Коротко о языке

**Go** (часто говорят «Golang») — компилируемый, статически типизированный язык
программирования, созданный в Google в 2007 году Робертом Гриземером, Робом
Пайком и Кеном Томпсоном. Открытым он стал в 2009 году.

Авторы решали вполне практическую проблему: большие серверные программы на C++
и Java собирались долго, а конкурентность (одновременная обработка множества
запросов) требовала сложных библиотек. Go задумывался как язык, на котором
**быстро пишут, быстро собирают и легко запускают** сетевые сервисы.

Сегодня на Go написаны Docker, Kubernetes, Terraform, Prometheus, части
инфраструктуры Twitch, Uber и многих банков. Типичные области применения:

- backend-сервисы и API;
- консольные утилиты и DevOps-инструменты;
- сетевые прокси, балансировщики, сборщики метрик;
- обработка данных, где важна простота поддержки.

## Ключевые свойства

1. **Компиляция в один бинарник.** `go build` создаёт исполняемый файл, внутри
   которого уже есть всё нужное. Его можно скопировать на сервер без установки
   Go и зависимостей.
2. **Статическая типизация.** Тип проверяется компилятором. Опечатка в имени
   переменной или несовпадение типов — ошибка сборки, а не сюрприз в проде.
3. **Сборка мусора.** Память освобождается автоматически, но при этом язык
   остаётся быстрым и предсказуемым.
4. **Простая конкурентность.** Горутины и каналы позволяют описывать
   параллельную работу без ручного управления потоками.
5. **Минимализм.** В языке около 25 ключевых слов. Один способ сделать цикл,
   один способ объявить переменную в функции, форматирование кода единое
   (`gofmt`).
6. **Богатая стандартная библиотека.** HTTP-сервер, JSON, тесты, работа с
   файлами и криптография уже включены.

> Go — не «ещё один объектно-ориентированный язык». В нём нет классов и
> наследования: вместо них используются структуры, интерфейсы и композиция. Это
> осознанное решение, а не ограничение.

## Первая программа

Вот как выглядит простейшая программа на Go:

```go
package main

import "fmt"

func main() {
	fmt.Println("Привет, Go!")
}
```

Запустить её можно командой `go run main.go` — компилятор соберёт программу во
временный файл и сразу выполнит. Вывод:

```text
Привет, Go!
```

## Как читать этот пример

- `package main` объявляет пакет. Пакет — это набор файлов, которые
  компилируются вместе. Пакет с именем `main` особенный: из него собирается
  исполняемая программа.
- `import "fmt"` подключает пакет форматированного ввода-вывода из стандартной
  библиотеки. Именно в нём живёт `Println`.
- `func main()` — точка входа. Программа начинает выполнение с этой функции.
- `fmt.Println("Привет, Go!")` выводит строку и переводит курсор на новую строку.

Порядок объявлений в файле не важен: сначала может идти `main`, потом `import`.
Компилятор разберётся. Важно лишь то, что все импортированные пакеты
используются, а переменные не остаются без применения — иначе будет ошибка
компиляции.

## Чем Go отличается от Python и Java

| Вопрос | Go | Python | Java |
| --- | --- | --- | --- |
| Исполнение | компиляция в бинарник | интерпретация | JVM-байткод |
| Типизация | статическая | динамическая | статическая |
| Точка входа | `func main()` в `package main` | любой скрипт | `public static void main` |
| Конкурентность | горутины и каналы в языке | потоки/async | потоки, executor |
| Форматирование | `gofmt` без настроек | PEP 8 + линтеры | соглашения IDE |

Если вы писали на Python, непривычными будут явные типы и обязательные фигурные
скобки. Если на Java — отсутствие классов и очень маленький набор конструкций.

## Частые ошибки новичков

- **Искать классы.** В Go нет `class`, `extends` и конструкторов. Есть
  структуры (`struct`) и методы на них.
- **Считать Go интерпретируемым.** `go run` — это удобная обёртка: под капотом
  всё равно компиляция, поэтому ошибки типов видны до запуска.
- **Путать пакет и модуль.** Пакет — каталог с файлами, модуль — набор пакетов с
  файлом `go.mod`. Об этом будет отдельный урок.
- **Ожидать неявного приведения типов.** `int` и `float64` нельзя сложить без
  явного преобразования.

## Практика

**Задание.** Напишите программу, которая выводит две строки:

1. ваше имя;
2. фразу «Я учу Go».

Используйте `fmt.Println` два раза.

**Стартовый код:**

```go
package main

func main() {
	// выведите две строки — по одной в каждой строке
	// fmt.Println("Анна")
	// fmt.Println("Я учу Go")
	// не забудьте импортировать "fmt"
}
```

Стартовый код специально компилируется как есть: раскомментируйте строки и
добавьте импорт, когда будете готовы.

**Ожидаемый вывод (пример):**

```text
Анна
Я учу Go
```

**Подсказка.** Строка в Go заключается в двойные кавычки: `"Анна"`.

**Решение:**

```go
package main

import "fmt"

func main() {
	fmt.Println("Анна")
	fmt.Println("Я учу Go")
}
```

## Резюме

- Go — компилируемый статически типизированный язык для быстрых и простых
  сервисов.
- Программа собирается в один бинарник и не требует установленного Go на
  сервере.
- Минимализм языка сочетается с мощной стандартной библиотекой и удобной
  конкурентностью.
- Любая программа начинается с `package main`, `import` нужных пакетов и
  функции `main`.

Дальше установим Go и убедимся, что инструменты работают.
