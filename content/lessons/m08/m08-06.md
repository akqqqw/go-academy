## Два интерфейса, на которых стоит стандартная библиотека

```go
type Reader interface {
	Read(p []byte) (n int, err error)
}

type Writer interface {
	Write(p []byte) (n int, err error)
}
```

Файлы, сокеты, сжатие, HTTP-тела, буферы — всё это `Reader` и/или `Writer`. Функция
с таким параметром работает с любым источником:

```go
package main

import (
	"io"
	"os"
	"strings"
)

func copyTo(dst io.Writer, src io.Reader) error {
	_, err := io.Copy(dst, src)
	return err
}

func main() {
	src := strings.NewReader("поток байт\n")
	if err := copyTo(os.Stdout, src); err != nil {
		os.Stderr.WriteString(err.Error())
	}
}
```

`strings.Reader`, `bytes.Buffer` и `bytes.Reader` реализуют оба интерфейса.

## Композиция потоков

- `io.Copy(dst, src)` — перекачка без ручного буфера.
- `io.TeeReader(r, w)` — читает и одновременно пишет копию.
- `io.MultiWriter(w1, w2)` — пишет в несколько приёмников.
- `io.LimitReader(r, n)` — ограничивает объём.

## Тесты без файлов

В тестах подменяйте реальный вывод на `bytes.Buffer`:

```go
var buf bytes.Buffer
err := writeReport(&buf)
if err != nil {
	t.Fatal(err)
}
if !strings.Contains(buf.String(), "итого") {
	t.Fatal("нет итога")
}
```

Это одна из причин, почему функции принимают `io.Writer`, а не `*os.File`.

## Частые ошибки

- **Забыть, что Read может вернуть 0, nil.** Такое допустимо; полагайтесь на
  ошибку и на `io.EOF`.
- **Считать, что один Write записывает всё.** Проверяйте `n` или используйте
  `io.Copy`/хелперы.
- **Не закрывать тела HTTP-ответов.** Они тоже `ReadCloser`.
- **Читать дважды из `Reader`.** Поток одноразовый; для повтора нужен `Seek` или
  буфер.

## Практика

**Задание.** Скопируйте содержимое строкового ридера в `bytes.Buffer` через `io.Copy` и напечатайте результат.

**Стартовый код:**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"strings"
)

func copyTo(dst io.Writer, src io.Reader) error {
	return nil // перекачайте данные через io.Copy
}

func main() {
	var buf bytes.Buffer
	src := strings.NewReader("поток данных")
	if err := copyTo(&buf, src); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(buf.String())
}
```

**Ожидаемый вывод:**

```text
поток данных
```

**Подсказка.** `var buf bytes.Buffer`, затем `io.Copy(&buf, strings.NewReader("…"))`.

**Решение:**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"strings"
)

func main() {
	var buf bytes.Buffer
	src := strings.NewReader("поток данных")
	if _, err := io.Copy(&buf, src); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(buf.String())
}
```

- Замена вывода на `bytes.Buffer` делает код тестируемым.
