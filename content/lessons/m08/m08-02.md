## Запись целиком

```go
path := filepath.Join(dir, "notes.txt")
err := os.WriteFile(path, []byte("строка 1\nстрока 2\n"), 0o600)
if err != nil {
	return err
}
```

`os.WriteFile` создаёт файл или **обрезает** существующий. Третий аргумент —
права (обычно `0o644` для файлов, доступных всем, `0o600` — только владельцу).

## Потоковая запись

`os.Create` открывает файл на запись, возвращая `*os.File`, который реализует
`io.Writer`. Писать можно через `fmt.Fprintf`, `bufio.Writer` или `json.Encoder`:

```go
file, err := os.Create(path)
if err != nil {
	return err
}
defer file.Close()

writer := bufio.NewWriter(file)
for i := 0; i < 3; i++ {
	fmt.Fprintf(writer, "строка %d\n", i+1)
}
if err := writer.Flush(); err != nil {
	return err
}
```

`bufio.Writer` копит данные в памяти: без `Flush()` файл останется пустым.

## Флаги открытия

`os.OpenFile(path, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)` добавляет в конец
и не обрезает файл. Комбинация флагов — единственный способ дописывать.

## Безопасное обновление

Запись поверх важного файла может оставить его полусломанным. Надёжный приём:
писать в `file.tmp`, затем `os.Rename(tmp, target)` — переименование в пределах
одной файловой системы атомарно.

## Частые ошибки

- **Забытый `Flush`.** Буферизованная запись не доходит до диска.
- **Права 0777.** Слишком широкий доступ; используйте минимально необходимые.
- **Забытый `Close`.** Данные и дескриптор освобождаются при закрытии.
- **`O_APPEND` без `O_WRONLY`.** Файл откроется не для записи — вернётся ошибка.

## Практика

**Задание.** Запишите во временный файл три строки через `bufio.Writer`, затем прочитайте файл и напечатайте его содержимое без лишних переводов строк.

**Стартовый код:**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	path := filepath.Join(os.TempDir(), "go-academy-write.txt")
	file, err := os.Create(path)
	if err != nil {
		fmt.Println(err)
		return
	}
	defer os.Remove(path)
	defer file.Close()

	writer := bufio.NewWriter(file)
	for i := 1; i <= 3; i++ {
		fmt.Fprintf(writer, "строка %d\n", i)
	}
	// не забудьте Flush
}
```

**Ожидаемый вывод:**

```text
строка 1
строка 2
строка 3
```

**Подсказка.** После цикла вызовите `writer.Flush()`, затем `os.ReadFile` и `fmt.Print(string(data))`.

**Решение:**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	path := filepath.Join(os.TempDir(), "go-academy-write.txt")
	file, err := os.Create(path)
	if err != nil {
		fmt.Println(err)
		return
	}
	defer os.Remove(path)
	defer file.Close()

	writer := bufio.NewWriter(file)
	for i := 1; i <= 3; i++ {
		fmt.Fprintf(writer, "строка %d\n", i)
	}
	if err := writer.Flush(); err != nil {
		fmt.Println(err)
		return
	}

	data, err := os.ReadFile(path)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Print(string(data))
}
```

## Резюме

- `os.WriteFile` перезаписывает файл, `os.OpenFile` с `O_APPEND` дописывает.
- Буферизованную запись нужно завершать `Flush`.
- Атомарная замена — запись во временный файл и `os.Rename`.
