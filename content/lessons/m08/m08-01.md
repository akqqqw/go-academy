## Файл целиком

Для небольших файлов достаточно `os.ReadFile`: он открывает, читает, закрывает
файл и возвращает срез байт:

```go
package main

import (
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	path := filepath.Join(os.TempDir(), "go-academy-read.txt")
	if err := os.WriteFile(path, []byte("первая строка\nвторая строка\n"), 0o600); err != nil {
		fmt.Println("запись:", err)
		return
	}
	defer os.Remove(path)

	data, err := os.ReadFile(path)
	if err != nil {
		fmt.Println("чтение:", err)
		return
	}
	fmt.Printf("%d байт: %q\n", len(data), string(data))
}
```

Ошибку проверяйте сразу: файла может не быть, прав может не хватать.

## Построчно

Большой файл в память целиком не нужен. `bufio.Scanner` читает по строкам:

```go
file, err := os.Open(path)
if err != nil {
	return err
}
defer file.Close()

scanner := bufio.NewScanner(file)
for scanner.Scan() {
	fmt.Println(scanner.Text())
}
if err := scanner.Err(); err != nil {
	return err
}
```

`defer file.Close()` гарантирует закрытие при любом выходе.

## Разбор текста

Прочитанные байты часто превращают в строку (`string(data)`) и режут через
`strings.Split`, `strings.Fields` или `strings.SplitSeq` в Go 1.24+.

## Частые ошибки

- **Забытый Close.** Утечка файловых дескрипторов; используйте `defer`.
- **Игнорирование ошибки Scan.** `scanner.Err()` нужно проверять после цикла.
- **`os.ReadFile` для гигабайтных логов.** Читайте потоково.
- **Сборка пути через конкатенацию.** Используйте `filepath.Join`.

## Практика

**Задание.** Создайте во временном каталоге файл с двумя строками, прочитайте его построчно и напечатайте количество строк.

**Стартовый код:**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	path := filepath.Join(os.TempDir(), "go-academy-lines.txt")
	if err := os.WriteFile(path, []byte("раз\nдва\nтри\n"), 0o600); err != nil {
		fmt.Println(err)
		return
	}
	defer os.Remove(path)

	file, err := os.Open(path)
	if err != nil {
		fmt.Println(err)
		return
	}
	defer file.Close()

	lines := 0
	scanner := bufio.NewScanner(file)
	for scanner.Scan() {
		_ = scanner.Text() // посчитайте строки
	}
	fmt.Println(lines)
}
```

**Ожидаемый вывод:**

```text
3
```

**Подсказка.** Запишите файл через `os.WriteFile`, откройте `os.Open`, обойдите `bufio.NewScanner` и считайте строки.

**Решение:**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	path := filepath.Join(os.TempDir(), "go-academy-lines.txt")
	if err := os.WriteFile(path, []byte("раз\nдва\nтри\n"), 0o600); err != nil {
		fmt.Println(err)
		return
	}
	defer os.Remove(path)

	file, err := os.Open(path)
	if err != nil {
		fmt.Println(err)
		return
	}
	defer file.Close()

	lines := 0
	scanner := bufio.NewScanner(file)
	for scanner.Scan() {
		lines++
	}
	fmt.Println(lines)
}
```

## Резюме

- `os.ReadFile` читает файл целиком, `bufio.Scanner` — построчно.
- Ошибки чтения и `scanner.Err()` нужно проверять.
- `defer file.Close()` закрывает файл при любом исходе.

Запись: `os.WriteFile`, `os.Create` и безопасное обновление файлов.
