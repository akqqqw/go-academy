## Создание

`os.MkdirAll(path, 0o755)` создаёт каталог вместе с родителями и не падает, если
каталог уже есть:

```go
dir := filepath.Join(os.TempDir(), "go-academy", "lesson")
if err := os.MkdirAll(dir, 0o755); err != nil {
	fmt.Println(err)
	return
}
fmt.Println(dir)
```

`os.Mkdir` создаёт только один уровень и требует, чтобы родитель существовал.

## Чтение каталога

```go
entries, err := os.ReadDir(dir)
if err != nil {
	return err
}
for _, entry := range entries {
	fmt.Println(entry.Name(), entry.IsDir())
}
```

`os.ReadDir` возвращает отсортированный по имени список. Чтобы узнать размер и
права, нужен `entry.Info()`.

## Обход дерева

`filepath.WalkDir` рекурсивно обходит каталог и передаёт путь и `DirEntry`:

```go
err := filepath.WalkDir(root, func(path string, d os.DirEntry, err error) error {
	if err != nil {
		return err
	}
	if !d.IsDir() {
		fmt.Println(path)
	}
	return nil
})
```

Возврат ошибки из колбэка останавливает обход. Каталог можно пропустить,
вернув `filepath.SkipDir`.

## Пути

- `filepath.Join` склеивает части с правильным разделителем.
- `filepath.Ext` даёт расширение, `filepath.Base` — имя файла.
- `filepath.Clean` нормализует путь.

## Частые ошибки

- **`path.Join` вместо `filepath.Join`.** `path` — для URL и слэшей, `filepath` —
  для файловой системы.
- **Конкатенация путей.** `dir + "/" + name` ломается на Windows.
- **Забыть про права.** Каталог, созданный с `0o600`, не откроется для обхода.
- **Удаление через `os.Remove`.** Для непустого каталога нужен `os.RemoveAll` —
  и осторожность.

## Практика

**Задание.** Создайте каталог `go-academy-demo` во временном каталоге, два файла в нём и напечатайте число файлов через `os.ReadDir`.

**Стартовый код:**

```go
package main

import (
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	dir := filepath.Join(os.TempDir(), "go-academy-demo")
	if err := os.MkdirAll(dir, 0o755); err != nil {
		fmt.Println(err)
		return
	}
	defer os.RemoveAll(dir)

	// создайте два файла в dir
	entries, err := os.ReadDir(dir)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(len(entries))
}
```

**Ожидаемый вывод:**

```text
2
```

**Подсказка.** После `os.MkdirAll` запишите два файла `os.WriteFile` и посчитайте `len(entries)`.

**Решение:**

```go
package main

import (
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	dir := filepath.Join(os.TempDir(), "go-academy-demo")
	if err := os.MkdirAll(dir, 0o755); err != nil {
		fmt.Println(err)
		return
	}
	defer os.RemoveAll(dir)

	for _, name := range []string{"a.txt", "b.txt"} {
		if err := os.WriteFile(filepath.Join(dir, name), []byte("data"), 0o600); err != nil {
			fmt.Println(err)
			return
		}
	}

	entries, err := os.ReadDir(dir)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(len(entries))
}
```

## Резюме

- `os.MkdirAll` создаёт дерево каталогов, `os.ReadDir` читает содержимое.
- `filepath.WalkDir` обходит дерево, ошибка из колбэка останавливает обход.
- Пути собирайте через `filepath.Join`, а не конкатенацией.
