## Чтение

`csv.Reader` умеет заголовки, кавычки и настройки разделителя:

```go
package main

import (
	"encoding/csv"
	"fmt"
	"strings"
)

func main() {
	text := "name,age\nАнна,30\nБорис,25\n"
	reader := csv.NewReader(strings.NewReader(text))
	reader.Comma = ','

	rows, err := reader.ReadAll()
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	for _, row := range rows[1:] {
		fmt.Printf("%s — %s лет\n", row[0], row[1])
	}
}
```

`ReadAll` читает всё сразу; для больших файлов используйте `Read` в цикле и
проверяйте `io.EOF`.

## Запись

```go
var builder strings.Builder
writer := csv.NewWriter(&builder)
if err := writer.Write([]string{"name", "age"}); err != nil {
	return err
}
writer.Flush()
if err := writer.Error(); err != nil {
	return err
}
fmt.Print(builder.String())
```

`Writer` буферизует: без `Flush` данные потеряются.

## Практические замечания

- Читайте в структуры сразу: `csv` не умеет теги, поэтому преобразование
  (`strconv.Atoi`) делает разработчик.
- Всегда сравнивайте `len(row)` с ожидаемым: битые строки ломают индексацию.
- `LazyQuotes` и `FieldsPerRecord` позволяют пережить нестандартный экспорт, но
  ослабляют проверки.

## Частые ошибки

- **Индексы без проверки длины.** `row[1]` паникует на короткой строке.
- **Забытый `Flush` или `writer.Error()`.** Ошибка записи останется незамеченной.
- **Точка с запятой в Excel-экспорте.** Задайте `reader.Comma = ';'`.
- **Ожидание автоматического типа.** CSV — только строки.

## Практика

**Задание.** Разберите CSV из двух колонок `name,score`, сложите баллы и напечатайте сумму.

**Стартовый код:**

```go
package main

import (
	"encoding/csv"
	"fmt"
	"strconv"
	"strings"
)

func main() {
	text := "name,score\nАнна,10\nБорис,15\n"
	reader := csv.NewReader(strings.NewReader(text))
	rows, err := reader.ReadAll()
	if err != nil {
		fmt.Println(err)
		return
	}

	total := 0
	for _, row := range rows[1:] {
		score, err := strconv.Atoi(row[1])
		if err != nil {
			fmt.Println("битая строка:", row)
			return
		}
		_ = score // сложите баллы в total
	}
	fmt.Println(total)
}
```

**Ожидаемый вывод:**

```text
25
```

**Подсказка.** Прочитайте через `csv.NewReader(...).ReadAll()`, преобразуйте второй столбец `strconv.Atoi`.

**Решение:**

```go
package main

import (
	"encoding/csv"
	"fmt"
	"strconv"
	"strings"
)

func main() {
	text := "name,score\nАнна,10\nБорис,15\n"
	reader := csv.NewReader(strings.NewReader(text))
	rows, err := reader.ReadAll()
	if err != nil {
		fmt.Println(err)
		return
	}

	total := 0
	for _, row := range rows[1:] {
		score, err := strconv.Atoi(row[1])
		if err != nil {
			fmt.Println("битая строка:", row)
			return
		}
		total += score
	}
	fmt.Println(total)
}
```

## Резюме

- `encoding/csv` читает и пишет табличные данные без внешних зависимостей.
- `ReadAll` для небольших файлов, `Read` в цикле — для больших.
- Запись требует `Flush` и проверки `writer.Error()`.

`io.Reader` и `io.Writer` — общий язык всей стандартной библиотеки.
