## Структура в JSON

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	ID      int    `json:"id"`
	Name    string `json:"name"`
	Email   string `json:"email,omitempty"`
	private string
}

func main() {
	user := User{ID: 1, Name: "Анна", private: "скрыто"}
	data, err := json.Marshal(user)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(string(data))
}
```

Экспортируются только поля с заглавной буквы. Тег `json:"name"` задаёт ключ,
`omitempty` пропускает нулевые значения.

## JSON в структуру

```go
var parsed User
if err := json.Unmarshal([]byte(`{"id":2,"name":"Борис"}`), &parsed); err != nil {
	fmt.Println(err)
	return
}
```

Аргумент — указатель. Неизвестные поля игнорируются, если не включить
`Decoder.DisallowUnknownFields()`.

## Потоки

Для HTTP и больших файлов удобнее `json.NewEncoder(w).Encode(v)` и
`json.NewDecoder(r).Decode(&v)`: без промежуточного `[]byte`.

## Частые ошибки

- **`json.Unmarshal` без `&`.** Ошибка компиляции: нужен указатель.
- **Неэкспортированные поля.** Молча отсутствуют в выводе.
- **Числа как float64.** При декодировании в `map[string]any` все числа —
  `float64`; используйте `json.Number` или структуру.
- **`Marshal` ошибки игнорируется.** Функции и каналы внутри структуры ломают
  кодирование.

## Практика

**Задание.** Опишите структуру `Book` с полями `Title` и `Pages` и тегами JSON, сериализуйте `Book{Title: "Go", Pages: 350}` и напечатайте JSON.

**Стартовый код:**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Book struct {
	Title string `json:"title"`
	Pages int    `json:"pages"`
}

func main() {
	data, err := json.Marshal(Book{})
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(string(data))
}
```

**Ожидаемый вывод:**

```text
{"title":"Go","pages":350}
```

**Подсказка.** `json.Marshal` вернёт `[]byte`, напечатайте через `fmt.Println(string(data))`.

**Решение:**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Book struct {
	Title string `json:"title"`
	Pages int    `json:"pages"`
}

func main() {
	data, err := json.Marshal(Book{Title: "Go", Pages: 350})
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(string(data))
}
```

## Резюме

- `json.Marshal`/`Unmarshal` работают со структурами через теги полей.
- Декодирование требует указателя, экспортируются только заглавные поля.
- Для потоков есть `json.Encoder` и `json.Decoder`.
