реализации; проверки указаны те, которые реально запускались.

## Ограничения окружения, влияющие на проверки

- Go SDK в песочнице отсутствует: `go test` локально не запускается. Компиляцию
  и тесты backend выполняет CI-job `backend` (зелёный); форматирование
  выправлено wasm-версией `gofmt`, финальную проверку делает `gofmt` из CI.
- Docker в песочнице нет: образ `coderunner` не собирался, `go test` внутри
  контейнера не запускался.
- Нет доступа к App Store / Play Console и нет устройства: мобильная сборка
  проверяется статически (`tsc`, конфигурация), запуск EAS — на стороне владельца.
- Публикация в сторах требует учётных данных владельца: в репозитории только
  заглушки конфигурации и инструкции.
